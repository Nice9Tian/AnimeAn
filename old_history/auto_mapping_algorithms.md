# Auto Mapping 与 Auto Mapping 2 的算法比较

**——两种中轴线引导形变映射的微分几何分析及其病态性来源**

> **归档说明**：本文写于两种算法并存时期，正文保持原样、以当时的现在时口吻叙述。
> 此后 AM1（脊柱旋转）已按本文结论从软件中移除——`build_mapper` 不再有

> AM1 的代码快照见同目录 `auto_mapping_1.py`；文中指向 `pyfile/auto_mapping.py`

## 摘要

AnimeAn 的 Auto Mapping 工具族将 `child_paint_view` 中绘制的图案，经由两组"中轴线"（H/V center line）所定义的参考架，重建到 `main_paint_view` 中。工具提供两个变体：**Auto Mapping**（下称 AM1）与 **Auto Mapping 2**（下称 AM2）。二者共享同一套坐标分解与重参数化前端，仅在**法向位移的合成方式**上分歧：AM1 将位移置于脊线的**局部随动标架**中（随切向旋转），AM2 则采用**纯平移扫掠**（Boolean sum 形式）。

本文给出两者的完整数学表达，并通过雅可比行列式分析证明：**AM1 的映射在离脊线曲率半径处结构性奇异**，其单射域被 $\rho_{\min} = 1/\kappa_{\max}$ 严格限制；且其位置误差随离轴距离**线性放大**。AM2 的雅可比与离轴距离无关，恒不退化。数值实验（第 5 节）以机器精度确认了全部解析预言。据此，AM1 频繁出现"拓扑混乱""远端形变异常"等缺陷并非实现瑕疵，而是其构造本身的固有属性。

**关键词**：中轴线映射；Coons 曲面；平移扫掠；渐屈线；雅可比退化；单射性

---

## 1. 引言

设用户在子视图中绘制图案 $\mathcal{P} \subset \mathbb{R}^2$，并绘制两条中轴线 $C_h, C_v$（折线，一般不正交、可弯曲）；在主视图中绘制对应的两条中轴线 $M_h, M_v$。工具需构造映射

$$\Phi : \mathbb{R}^2 \to \mathbb{R}^2$$

使得 $\Phi$ 将子系参考架"贴合"到主系参考架，从而 $\Phi(\mathcal{P})$ 是图案在目标姿态下的形变结果。

两个变体在实现上由单一布尔开关 `spine_rotation` 区分（`build_mapper`，[`auto_mapping.py:391`](../pyfile/auto_mapping.py)），但其微分性质差异是本质的。

## 2. 共用前端

### 2.1 子系坐标分解

记子系两轴线交点为 $O_c$（`_polyline_intersection`，`:340`），取两轴线的**半弦向量**

$$\mathbf{e}_h = \tfrac{1}{2}\bigl(C_h(1) - C_h(0)\bigr), \qquad
\mathbf{e}_v = \tfrac{1}{2}\bigl(C_v(1) - C_v(0)\bigr)$$

其中 $C(0), C(1)$ 为折线首末端点。定义

$$\Delta = \det[\mathbf{e}_h, \mathbf{e}_v] = e_{h,x}e_{v,y} - e_{h,y}e_{v,x}$$

对任一点 $p$，将 $p - O_c$ 在斜基 $(\mathbf{e}_h, \mathbf{e}_v)$ 下展开，由 Cramer 法则：

$$u(p) = \frac{\det[\,p - O_c,\ \mathbf{e}_v\,]}{\Delta}, \qquad
v(p) = \frac{\det[\,\mathbf{e}_h,\ p - O_c\,]}{\Delta} \tag{2.1}$$

**退化守卫**：以**夹角**而非绝对面积判据拒绝近平行轴

$$\frac{|\Delta|}{\|\mathbf{e}_h\|\,\|\mathbf{e}_v\|} = |\sin\theta| < 0.05 \;(\approx 3^\circ) \;\Longrightarrow\; \text{拒绝}$$

（对长轴线而言，绝对面积阈值会放行近平行架，导致 (2.1) 的分解爆炸。）

转为**带符号弧长量纲**：

$$\xi = u\,\|\mathbf{e}_h\|, \qquad \eta = v\,\|\mathbf{e}_v\| \tag{2.2}$$

### 2.2 端点锚定的分段线性重参数化

交点将每条轴线**一分为二**。设子系弦长 $L^c$ 被交点分为 $a^-, a^+$（`_chord_sides`，`:372`），主系弧长 $L^m$ 被交点分为 $b^-, b^+$（`_arc_sides`，`:386`），两者均以 $0.01L$ 为下限截断（防 T 形交叉除零）。逐侧标定：

$$\sigma^- = \frac{b^-}{a^-}, \qquad \sigma^+ = \frac{b^+}{a^+} \tag{2.3}$$

若某侧塌缩至下限（交点落于端点），则**复用对侧标定**，避免以 1% 下限作除数产生约 $100\times$ 的放大器（`side_scales`，`:441`）。

重参数化算子为**分段线性**：

$$\mu(x) = \begin{cases}
\sigma^+ x, & x \ge 0\\[2pt]
\sigma^- x, & x < 0
\end{cases} \tag{2.4}$$

由此得主系弧长坐标：

$$s = s_\times + \mu_h(\xi), \qquad t = t_\times + \mu_v(\eta) \tag{2.5}$$

其中 $s_\times, t_\times$ 为主系交点处的弧长。

> **设计取舍**：该"端点锚定"方案保证子系轴线端点**恰好**落到主系轴线端点（图案严格张满所绘轴线），代价是当两组交点的相对位置不同时 $\sigma^- \ne \sigma^+$，使 $\mu$ 在原点仅 $C^0$（见 §6.1）。

### 2.3 主系弧长求值

$H(s)$、$V(t)$ 为主系折线的**弧长参数化**求值（`_point_at_arc`，`:263`），线性内插，越界时以端点切向线性外推。定义法向位移

$$\boldsymbol{\delta}(t) = V(t) - O_m \tag{2.6}$$

至此，两变体的输入完全一致。

## 3. 两个变体的构造

### 3.1 Auto Mapping 2：平移扫掠（Boolean sum）

$$\boxed{\;\Phi_2(p) = H(s) + \boldsymbol{\delta}(t) = H(s) + V(t) - O_m\;} \tag{3.1}$$

此即以 $H$、$V$ 为骨架的**平移扫掠面**（translational sweep），亦为双线性混合 Coons 曲面在"对边互为平移"退化情形下的闭式：位移沿脊线**只平移、不旋转**。

### 3.2 Auto Mapping 1：脊线随动标架

以 $H$ 为**脊线**，取窗口中央差分切向（`_tangent_at_arc`，`:283`）

$$T(s) = \frac{H(s+w) - H(s-w)}{\|H(s+w) - H(s-w)\|}, \qquad w = \max(2\,\text{POLY\_STEP},\ 0.03\,L_h^m)$$

记 $T_0 = T(s_\times)$，$\alpha(s)$ 为 $T_0$ 转到 $T(s)$ 的有向夹角：

$$\cos\alpha = T(s)\!\cdot\!T_0, \qquad \sin\alpha = \det[T_0,\,T(s)]$$

则

$$\boxed{\;\Phi_1(p) = H(s) + R\bigl(\alpha(s)\bigr)\,\boldsymbol{\delta}(t)\;},\qquad
R(\alpha) = \begin{pmatrix}\cos\alpha & -\sin\alpha\\ \sin\alpha & \cos\alpha\end{pmatrix} \tag{3.2}$$

脊线为直线时 $\alpha \equiv 0$，$R = I$，(3.2) 退化为 (3.1)，两变体重合。

---

## 4. 微分分析

以 $(s,t)$ 为中间参数（$p \mapsto (s,t)$ 由 (2.1)–(2.5) 给出，是**分段仿射**的，其雅可比在各象限内为常数，故不影响以下退化性讨论）。

### 4.1 雅可比行列式

**AM2**：由 (3.1)，

$$\frac{\partial \Phi_2}{\partial s} = T(s), \qquad \frac{\partial \Phi_2}{\partial t} = N(t)$$

（$N(t)$ 为 $V$ 在 $t$ 处的单位切向），故

$$\det J_2 = \det[\,T(s),\ N(t)\,] = \sin\angle\bigl(T(s), N(t)\bigr) \tag{4.1}$$

**仅当两主轴线的局部切向平行时退化**，与离轴距离 $\|\boldsymbol\delta\|$ **无关**。

**AM1**：由 (3.2)，注意 $R'(\alpha) = JR(\alpha)$（$J$ 为 $90^\circ$ 旋转），且 $\mathrm{d}\alpha/\mathrm{d}s = \kappa(s)$（脊线有向曲率）：

$$\frac{\partial \Phi_1}{\partial s} = T(s) + \kappa(s)\,J R(\alpha)\,\boldsymbol\delta
= R(\alpha)\bigl[\,T_0 + \kappa(s)\,J\boldsymbol\delta\,\bigr]$$

$$\frac{\partial \Phi_1}{\partial t} = R(\alpha)\,N(t)$$

因 $\det R = 1$：

$$\det J_1 = \det\bigl[\,T_0 + \kappa(s) J\boldsymbol\delta,\ N(t)\,\bigr] \tag{4.2}$$

在正交标架下（$T_0 = (1,0)$，$N = (0,1)$，$\boldsymbol\delta = (0,d)$，$d$ 为指向曲率中心一侧的带符号偏移）：

$$\boxed{\;\det J_1 = 1 - \kappa(s)\,d\;} \tag{4.3}$$

### 4.2 单射域与渐屈线

由 (4.3)：

$$\det J_1 = 0 \iff d = \frac{1}{\kappa(s)} = \rho(s)$$

即映射在**曲率中心轨迹（渐屈线，evolute）上奇异**。这是经典**法向偏移曲线**的退化：AM1 本质上是"沿脊线的法向同余映射"，其单射域被脊线的最小曲率半径严格限制：

$$\boxed{\;\Phi_1 \text{ 单射} \iff \|\boldsymbol\delta\|_{\text{凹侧}} < \rho_{\min} = 1/\kappa_{\max}\;} \tag{4.4}$$

**凡在凹侧离脊线超过 $\rho_{\min}$ 的图案内容，必定发生翻折（fold-over）与自相交**——线序倒置、笔画穿插，即用户观察到的"拓扑混乱"。

AM2 无此项：(4.1) 不含 $\boldsymbol\delta$，任意远的图案内容都不会因离轴距离而退化。

### 4.3 误差放大

设切向估计存在角误差 $\varepsilon$（手绘轴线抖动、折线离散、窗口平滑残差）。由 (3.2)，位置误差

$$\|\Delta\Phi_1\| \approx \|\boldsymbol\delta\|\cdot\varepsilon \tag{4.5}$$

**与离轴距离成正比**。AM2 的 (3.1) 不含 $R$，切向误差**完全不进入**位置误差：

$$\|\Delta\Phi_2\| = O(\text{弧长求值误差}), \quad \text{与} \|\boldsymbol\delta\| \text{无关} \tag{4.6}$$

### 4.4 对称性

AM2 的 (3.1) 关于 $H \leftrightarrow V$ **完全对称**。AM1 的 (3.2) 则**指定 $H$ 为脊线**，破坏对称：交换两条中轴线的命名会得到不同结果。这与用户"两条对等中轴线"的心智模型相悖。

## 5. 数值验证

**装置**：主系脊线取半径 $R = 300\,\text{px}$、弧长 $400\,\text{px}$ 的圆弧（$\kappa \equiv 1/300$，曲率中心在 $(0,-R)$），主系 V 轴为直线；子系两轴为等长直线且交于中点（故 $\sigma^\pm = 1$，映射"近似恒等"）。以中央差分数值估计雅可比。

## 6. AM1 病态性的来源归纳

综合第 4、5 节，AM1 的缺陷**并非实现错误，而是构造的固有属性**，按严重度排列：

1. **结构性奇异（根本原因）**。由 (4.4)，单射域被 $\rho_{\min}$ 封死。用户画一条曲率较大的主脊线（这恰恰是使用 AM1 的**动机**——想要弯曲变形），$\rho_{\min}$ 随之变小，而图案的离轴范围通常固定，于是极易越界。**越想要强变形，越容易崩坏**——这是一个内建的反向激励。

2. **误差随离轴距离线性放大**（4.5 节，实测 6.0 倍）。手绘轴线不可避免带抖动，而 AM1 把角误差乘以力臂 $\|\boldsymbol\delta\|$。图案越大、离脊线越远，抖动越被放大成可见的错位。代码中的窗口中央差分（$w = \max(2\,\text{POLY\_STEP}, 0.03L)$）是对该问题的**缓解**而非消除，且引入新的副作用（下条）。

3. **切向场自身仅 $C^0$**。窗口中央差分在 $s$ 上分段线性，故 $\alpha'(s) = \kappa(s)$ **分片常值且跳变**；越过轴线端点后切向被冻结，$\alpha$ 变为常数，映射在端点处导数不连续。于是 (3.2) 的旋转项在整条脊线上都是分片的，形变带有肉眼可辨的"折角"。AM2 的 (3.1) 不含该项。

4. **破坏 H/V 对称性**（5.4 节，74.22 px）。同一组四条线，仅因命名不同得到不同结果，违反用户心智模型，且使问题难以复现和描述。

5. **局部面积尺度非常值**。由 (4.3)，面积缩放 $1-\kappa d$ 随位置变化，而线宽采用**单一全局几何均值**
   $$w' = w\sqrt{\frac{L_h^m}{L_h^c}\cdot\frac{L_v^m}{L_v^c}}$$
   在 AM1 下该近似的失配随 $d$ 增大而恶化（AM2 的面积尺度为常数，同一近似更贴合）。

6. **与共模缺陷的耦合放大**。§7 所列的分段线性折角、弧长求值的 $C^0$ 性等，在 AM2 中只影响位置，在 AM1 中会先进入 $\alpha(s)$、再乘以力臂放大。

## 7. 共模缺陷（两变体均有）

以下问题源自共用前端，二者同等承受，不构成选择依据：

- **逐侧标定折角**：$\sigma^- \ne \sigma^+$ 时 (2.4) 在原点仅 $C^0$，跨越中轴线的笔画在此产生有界角度的折弯。代码在失配比 $>1.5$ 时打印提示。
- **弦基分解的近似性**：(2.1) 用**弦**而非弧定义子系基，故子系轴线弯曲时分解只是近似。
- **弧长求值 $C^0$**：$H(s)$ 在折线顶点处切向跳变。
- **手性（镜像）**：映射在两轴向均"起点对起点、端点对端点"，故当子系与主系参考架**旋向相反**时结果必为镜像。判据
  $$\operatorname{sgn}\det[\mathbf{e}_h,\mathbf{e}_v] \ne \operatorname{sgn}\det[T(s_\times), N(t_\times)]$$
  代码据此在 `info["mirrored"]` 报告并提示用户"反向重画其中一条主轴线"。
- **越界外推**：图案超出轴线张成范围时以端点切向线性外推，无几何依据。
- **线宽单一全局缩放**（见 §6.5）。

## 8. 结论与建议

1. **AM2 应为默认选择**。其雅可比 (4.1) 与离轴距离无关、对切向噪声免疫、关于 H/V 对称，且在直脊线情形与 AM1 完全等价——即 AM1 相对 AM2 的**全部增益仅存在于弯曲脊线**，而正是该情形触发 AM1 的奇异性。

2. **AM1 的适用域应显式限定**为
   $$\max_{p \in \mathcal{P}} \|\boldsymbol\delta(p)\|_{\text{凹侧}} < \rho_{\min} = 1/\kappa_{\max}$$
   建议实现：在 `build_mapper` 中由主脊线估计 $\kappa_{\max}$，与图案的最大凹侧离轴距离比较，越界时**拒绝或降级到 AM2**，而非输出翻折结果。这与既有的"轴线不相交则拒绝映射"守卫是同一设计哲学——**拒绝优于输出垃圾**。

3. **若需保留弯曲脊线的旋转效果**，可考虑将 (3.2) 的刚性旋转替换为对离轴距离做衰减的插值
   $$R_\lambda(s,\boldsymbol\delta) = R\bigl(\lambda(\|\boldsymbol\delta\|)\,\alpha(s)\bigr),\qquad \lambda(r) = \max\!\left(0,\ 1 - \frac{r}{\rho_{\min}}\right)$$
   使映射在接近渐屈线时连续退化为平移扫掠，从而恒保单射。此为待验证的设计提案，非当前实现。
