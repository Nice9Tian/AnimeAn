# 斥力板（repulsion_pad）

面板窗 **Repulsion Pad**（Windows 菜单，默认隐藏）。用一个手柄把当前帧里重叠或贴太近的线推开。

## 在哪

- **Windows ▸ Repulsion Pad**：一个带十字坐标和圆形手柄的板子。标题栏显示它作用于哪块板（Repulsion Pad - main / child），随活动板切换。

## 怎么用

1. 先在要整理的板上点一下让它成为活动板，选好帧。
2. 按住手柄拖：横向、纵向分别是 X、Y 方向的推力大小和方向。当前帧所有可见图层里靠得太近或重叠的线按彼此远近被推开；同一条线折返靠在一起的两段也互推，沿线相邻的点不推。拖动时实时预览。
3. 松手：结果提交，手柄停在原处表示当前推力。再拖是从原始位置重新算，拖回中心就完全还原。
4. 只点不拖不会有任何改动。

## 会看到什么

- 预览期间被推的线暂时显示在一个临时层上，源图层暂时隐藏；松手后恢复。
- 每次松手一条 Repulsion 历史记录。

## 边界

- 推的是顶点位置，不改变线的拓扑：不重采样、不拆分、不改锚点数。
- 锁定的图层只参与产生斥力，自己不动。
- 板上内容改了（画线、擦除、撤销、切帧）后基线重算，手柄回中心。
