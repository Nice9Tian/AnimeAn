## 1. 用户定的语义（2026-10-30）

1. **流程。** 外部交互：纹理板上原本有一个矩形，用户在主画板画一个矩形。内部计算：根据主画板的矩形立刻算出 H/V 轴线和额外辅助线（或还没做的 Coons 曲面）。**纹理板的轴线是已有的，矩形只示意范围，调它不动轴线；要计算的只有主画板的轴线**（用户 2026-10-30 确认）。纹理板上的图案同样不随矩形动。
2. **不计算镜像。** 按软件的语义，只有绕到背面才需要镜像，绕到背面是折叠的事。矩形是顺时针还是逆时针画的不携带意图，两种绕向都按同一朝向处理。
3. **旋转权重 λ = 1.0，平移和缩放的代价为 0。** 变换范围是相似变换：两块板的尺寸和位置没有共同含义，允许均匀缩放。
4. **每次改动都重算。** 对应关系不存进 Auto-Mapping 单元。代价是矩形转过临界角时图案会突然换一条标签（§4 的表），这是用户知情的取舍。

用户 2026-10-30 确认了平移和缩放的代价取 0，取代 #7 最初设想的「平移缩放代价小」。

## 2. 算法

输入是两个四边形的四个角。先检查能不能用：角数不是 4、坐标不是有限数、相邻两角重合、自交、面积与周长平方之比不超过 $10^{-6}$ 的拒绝，并给出原因。一个角恰好落在对边上不算自交，手绘碰不到这种情况。

1. **定阅读顺序。** 两个四边形都排成正的有向面积，再从「出边最接近 +x」的角开始；出边方向相同时比较 y 分量，再相同（共线的两条边）比较角的位置。方向先归一化，再取到小数点后 9 位比较。这一步之后，起点和绕向都不再影响结果，平局也一样。
2. **归一化。** 减去重心，除以 $\sqrt{\sum|z-\bar z|^2}$，得到 $a_i, b_i$。平移和缩放因此不进入比较。
3. **四种循环标签** $k\in\{0,1,2,3\}$：

$$Z_k=\sum_{i=0}^{3}\overline{a_i}\,b_{(i+k)\bmod 4},\qquad \theta_k=\arg Z_k$$

$$E_k=\underbrace{(1-|Z_k|^2)}_{\text{最优相似变换的相对残差}}+\lambda\,\underbrace{(1-\cos\theta_k)}_{\text{旋转代价}}$$

4. **取 $E_k$ 最小的 $k$。** 差距在 $10^{-9}$ 以内算平局，取正角（例如正方形转 45°）；角度也相同时取阅读顺序下靠前的标签。$|Z_k|\le10^{-9}$ 时 $\arg$ 没有意义，按 $\theta=\pi$ 计。

全程是闭式解，没有迭代，不依赖 numpy。

### 为什么形状项不够

- 矩形绕中心转 180° 还是自己，形状项对两种标签完全相等，只能靠旋转代价区分。
- 镜像同理，形状项也分不开，所以镜像不能由损失函数决定。
- 平移不影响标签：重心差与标签无关。
- 缩放代价如果不为 0，只会让临界角随画的大小移动：$\log s_k=\log(\text{常数})+\log|Z_k|$，缩放项里含一个随板面尺寸线性变化的交叉项，没有实际好处。

## 3. 常量

| 常量 | 值 | 含义 |
|---|---|---|
| `ROTATION_WEIGHT`（λ） | 1.0 | 用户 2026-10-30 定 |
| `_DEGENERATE_AREA` | $10^{-6}$ | \|有向面积\| / 周长² 不超过它视为退化 |
| `_TINY_CORRELATION` | $10^{-9}$ | $|Z_k|$ 低于它时 $\arg$ 是噪声 |
| `_COST_TIE` | $10^{-9}$ | 代价差在它以内算平局 |
| `_SKEW_TOLERANCE` | $10^{-6}$ | 纹理侧四角偏差 / 邻边长度和超过它就不算平行四边形 |
| `_AXIS_SAMPLES` | 32 | 纹理轴线每段带到主画板时的采样段数 |

## 4. λ = 1.0 的后果

主画板的矩形是纹理矩形转 90° 时，形状项是 $c=\left(\frac{r^2-1}{r^2+1}\right)^2<1$（$r$ 是长宽比），所以任何长宽比都保持图案朝向，把图案压进新的比例，不转 90°。

矩形转过角 φ 时，标签在 $\sin\varphi-\cos\varphi=c$ 处换，也就是 $\varphi=45°+\arcsin(c/\sqrt2)$：

| 长宽比 | 换标签的角度 |
|---|---:|
| 1:1 | 45.0° |
| 3:2 | 51.0° |
| 2:1 | 59.7° |
| 4:1 | 78.4° |

矩形倒过来（转 180°）算没有转：矩形自身没有上下。

## 5. 轴线和边

`guides` 的输入是两个四边形和纹理板自己的 H、V 轴线，输出主画板的 H、V 轴线和四条边。纹理侧必须是平行四边形（四角偏差与边长之和的比不超过 $10^{-6}$），否则拒绝。同族同下标的边是一对，起点和终点都落在对应的角上。四边形歪得厉害时，边的走向不一定和所属族的轴线同向，配对以角点为准。

- **主画板轴线由纹理轴线带过去。** 纹理轴线上的点先算出它相对纹理矩形的位置 $(u,v)$，再放到主画板四边形的双线性曲面 $S(u,v)$ 上；矩形外的点用同一公式外推。纹理轴线每段取 32 段采样。与矩形边平行的轴线带过去仍是直线，比例不变；斜的轴线在非平行四边形上会弯。
- **纹理轴线是矩形中线时，主画板轴线就是四边形的中线。** 任意四边形的两条中线互相平分（Varignon），所以交点把两条轴都分成等长两段，`auto_mapping_2_spec.md` §4.2 的逐侧标定没有折角。
- **残差就是四边形的扭转量。** 轴线是矩形中线时，令 $d=\tfrac14(q_0-q_1+q_2-q_3)$，$\mathrm{HV}[M]$ 与双线性曲面只差 $d\,uv$（$u,v\in[-1,1]$）：边中点上为 0，四个角上恰为 $|d|$。
- **主画板的四边形不需要是矩形。** 对齐时矩形不变形，只用来决定对应关系；图案最终往哪落由轴线和轮廓约束决定。

## 6. 留给其他 issue 的事实

- **对齐量进不了曲面。** `build_mapper` 只读轴线，流场解线性方程，没有「初始形态」这个输入。`rotation`、`scale`、`offset` 只作诊断。
- **#8：直边四边形不需要放弃 Coons。** 中线作轴、边界残差用调和场吸收、轴钉住，结果与双线性 Coons 曲面的差不超过 $6\times10^{-10}$ px，因为 $d\,uv$ 本身调和且在轴上为零。这是在均匀拉普拉斯替身上量的，轴线是直线，还没在 `_FlowFieldWarp` 上验证。同日的 Coons 必要性评估用别的样本独立得到了同样的结论。
- **#11、#12：边弯了不能再钉轴。** 边鼓起 8% 时，钉住的轴上有约 24 px 的折痕，放开时 0.02 px。
- **四条边只当附加线不够。** 附加线只引导流向。真实流场上强梯形的边上最大偏差从 75 px 降到 58 px，轮廓到不了；竖向的边穿过 H 轴处还会折出尖角（一步最大 104°）。四条边要当地线，见 `ground_line.md`。
