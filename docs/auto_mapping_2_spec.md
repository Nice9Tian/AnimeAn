# Auto Mapping 2 算法说明书

**——基于双中轴线参考架的平移扫掠形变映射：完整规格**

---

## 摘要

本文给出 AnimeAn 中 **Auto Mapping 2**（下称 AM2）的完整算法规格。AM2 将 `child_paint_view` 中绘制的矢量图案，经由两组用户绘制的"中轴线"所定义的参考架，重建到 `main_paint_view` 中。

算法分五个阶段：参考架采集、映射器构造、曲线重建、区域裁剪、结果输出。其核心是一个**可分离**的平移扫掠映射 $H(s) + V(t) - O_m$，等价于对边互为平移时的双线性混合 Coons 曲面（§5.1 定理 1，数值验证偏差 $6.4\times10^{-14}$）。

该重建函数对**两块板共用**（4.0），子系坐标由它在子系上的逆给出（弧长，非弦投影），映射写成"子系残差 + 主系重建"的解耦形式 (4.6)。由此得到一条旧公式不具备的性质：两块板画同一组轴线时映射**逐位恒等**，与轴线形状无关（§5.6 定理 6）。

由于该映射非线性，逐顶点变换后直接连直线会丢失顶点间的形变，故第三阶段提供三种曲线重建模式（polyline / spline / bezier），均遵循"原始顶点为锚点、仅对插值采样点降采样"的约束；映射失去仿射性的位置（**结构折点**）由参考架的累积弧长表解析枚举，而非靠探针发现（§6.2）。区域裁剪同样是解析求交而非采样（§7）。

本文所有公式均与实现一一对应（附录 B 按函数名索引），全部数学论断均经数值验证（§10）。AM2 现在是本软件**唯一的** automapping（工具栏按钮 `Auto Mapping`）；被淘汰的 Auto Mapping 1（脊柱旋转）的代码与两算法比较分析归档于 [`../old_history/auto_mapping_algorithms.md`](../old_history/auto_mapping_algorithms.md) 与 `../old_history/auto_mapping_1.py`。

## 3. 阶段 I：参考架采集

### 3.1 资产模型

中轴线与映射区域**不进入图层栈**。用户用 `H Center Line` / `V Center Line` 工具绘制的笔画，在 `linefinish` 钩子中被**立即移出场景模型**，转存入 Python 侧会话字典 `_MAPPING_ASSETS[view][property]`，并通过通用 C++ 叠加显示服务（`ui.set_overlay`）绘制。

**轴线保留真实曲线**（2026-08-17）。C++ 平滑器产出的笔画路径是**直线段与贝塞尔段的混合链**（binomial 打磨后过中点的二次样条，切向连续）。捕获同时保存两份几何：`points` 是 4 px 展平（叠加显示、求交种子），`commands` 是真实混合路径——参考架此后在**曲线本身**上求值（§4.3），不再依赖展平密度。旧资产 / 轴线快照只有 `points`，自动退回折线模式，算术与旧版逐位一致。

设计后果：

- 不出现在 Layers / Assets 面板，不参与油漆桶边界检测
- 每视图每类型**唯一**，重画即替换
- 序列化进 `scriptData`（含 `commands`），随撤销/重做快照走（`historyrestore` 钩子重建）

### 3.2 方向语义

映射在两轴向均为**起点对起点、终点对终点**。因此主系轴线的绘制方向直接决定结果朝向：反向绘制主 H 轴 $\Rightarrow$ 水平翻转，反向绘制主 V 轴 $\Rightarrow$ 垂直翻转。为使该语义可见，每条轴线终点绘制方向箭头，其方向取**窗口平滑末端切向**（窗口 $=\max(2\cdot\texttt{POLY\_STEP},\ 5\%\text{ 弧长})$，即短轴线上不小于 8 px），避免手绘收笔钩导致箭头乱指。

## 4. 阶段 II：映射器构造

### 4.1 共用的重建函数与子系坐标

两块板走**同一个**重建函数（`_Frame.hv`）。对任一参考架 $G$（两条相交轴线 + 交点 $O_G$）：

$$\mathrm{HV}[G](\ell_h,\ell_v) \;=\; G_h\bigl(s^G_\times + \ell_h\bigr) \;+\; G_v\bigl(t^G_\times + \ell_v\bigr) \;-\; O_G
\tag{4.0}$$

其中 $\ell$ 是**自交点起算的带符号弧长**，$s^G_\times,t^G_\times$ 是该参考架交点在两条轴线上的绝对累积弧长，$G_h(\cdot)$ 按 (4.5)（绝对弧长）求值。**两种弧长原点务必分清**：$\ell$ 以交点为原点，(4.5) 的 $H(s)$ 以折线起点为原点，二者差一个 $s_\times$ 平移；漏掉该平移会使 $\mathrm{HV}$ 在 $\ell=0$ 处给出 $G_h(0)+G_v(0)-O_G$ 而非 $O_G$（实测偏差数百 px）。

子系坐标定义为该函数在**子系**上的逆：

$$(\ell_h,\ell_v) \;=\; \mathrm{HV}[C]^{-1}(p)$$

折线轴线上 $\mathrm{HV}$ 分段仿射（弧长查表 + 线性内插），其逆在每个单元内亦为仿射，Newton 一步即落到解；曲线轴线（§4.3 混合段）上 $\mathrm{HV}$ 分段 $C^\infty$、整体 $C^1$，Newton 二阶收敛。两种情形 Jacobian 的两列都是轴线在 $\ell$ 处的**单位切向**（曲线模式为精确切向）。

**初值**取斜基分解——即旧版本的坐标定义。取两轴线的半弦向量

$$\mathbf e_h = \tfrac12\bigl(C_h(1) - C_h(0)\bigr),\qquad
\mathbf e_v = \tfrac12\bigl(C_v(1) - C_v(0)\bigr),\qquad
\Delta = \det[\mathbf e_h,\mathbf e_v]$$

将 $p - O_c$ 在斜基 $(\mathbf e_h,\mathbf e_v)$ 下展开，Cramer 法则给出

$$u(p) = \frac{\det[\,p-O_c,\ \mathbf e_v\,]}{\Delta},
\qquad
v(p) = \frac{\det[\,\mathbf e_h,\ p-O_c\,]}{\Delta}
\tag{4.1}$$

转为带符号弧长量纲（$u,v$ 以半弦为单位，故乘半弦长）：

$$\xi = u\,\|\mathbf e_h\|,
\qquad
\eta = v\,\|\mathbf e_v\|
\tag{4.2}$$

> **子系轴线为直线时弦即弧**，初值本身就是精确解（Newton 首次残差检查即退出），整个映射器逐位退化为 2026-08 以前的实现——300 组随机直线配置实测最大偏差 $10^{-13}\!-\!10^{-12}$ px 量级（随机种子不同取值在 $3.4\times10^{-13}$ 到 $4.1\times10^{-12}$ 之间浮动，均为浮点舍入而非算法差异）。轴线弯曲时初值只是起点，Newton 典型 2–3 步收敛到真正的弧长坐标。

> **非单射的退化**：子系轴线弯到两切向局部平行时 $\mathrm{HV}[C]$ 不再单射，逆不存在。求解器因此写成"退化而非发散"——迭代点无条件前进，但步长按参考架尺度阻尼、只**记录**使残差下降的迭代、残差劣化到 4 倍即停并返回记录中的最优点；第 0 次迭代就是上面的弦估计，故结果**永不劣于旧实现**。剩余偏差由 (4.6) 的残差项承载，使映射在整个平面上有定义。

### 4.2 端点锚定的逐侧标定

交点将每条轴线一分为二。**两块板都按弧长分侧**（`_arc_sides`），均以 $1\%$ 全长为下限截断：

$$a^- = \max(s^c_\times,\ 0.01L^c),\qquad a^+ = \max(L^c - s^c_\times,\ 0.01L^c)$$

$$b^- = \max(s_\times,\ 0.01L^m),\qquad b^+ = \max(L^m - s_\times,\ 0.01L^m)$$

逐侧标定系数：

$$\sigma^- = \frac{b^-}{a^-},\qquad \sigma^+ = \frac{b^+}{a^+}
\tag{4.3}$$

**塌缩侧的连续回退**：若某侧的**未截断**长度 $\tilde a$ 逼近 0（T 形交叉，交点落在端点），该侧无实际延展，以 $1\%$ 下限作除数会产生约 $100\times$ 的放大器。旧版用硬判据直接换用对侧系数，代价是映射在阈值处**不连续**——交点沿 600 px 弦挪动 $10^{-7}$ px 越过阈值，一个映射点跳变 198 px。现按未截断长度在 $[0,\text{floor}]$ 上线性混合：

$$w = \min\!\left(1,\ \frac{\tilde a^-}{\text{floor}}\right),
\qquad
\sigma^- \;\leftarrow\; (1-w)\,\sigma^+ + w\,\sigma^-$$

（$\sigma^+$ 对称处理）。两端行为与旧版一致（$\tilde a=0$ 时退为对侧系数，$\tilde a\ge\text{floor}$ 时退为原始比值），中间连续。

**实测**：子系 H 长 600 px（$\text{floor}=6$）、交点沿其扫过阈值，测点取塌缩侧。旧版在 $\pm10^{-7}$ px 的相邻两次取样间跳变 **197.98 px**；本版同处 **0.0000 px**，全程最大相邻跳变即 sweep 步长本身的连续变化量（步长 0.01 px 时为 0.83 px，随步长趋零而趋零）。

重参数化算子（**分段线性**）：

$$\mu(x) = \begin{cases}\sigma^+x,& x\ge0\\ \sigma^-x,& x<0\end{cases}
\qquad\Longrightarrow\qquad
s = s_\times + \mu_h(\ell_h),\quad t = t_\times + \mu_v(\ell_v)
\tag{4.4}$$

> $\mu$ 的自变量是 §4.1 解出的**弧长坐标** $\ell$，不是初值 $\xi,\eta$。$\xi,\eta$ 只作为 Newton 的起点，此后不再进入任何公式。

该方案保证子系轴线端点**恰好**落到主系轴线端点（图案严格张满所绘轴线）。代价：$\sigma^-\ne\sigma^+$ 时 $\mu$ 在原点仅 $C^0$，跨中轴线的笔画在此产生有界折角；失配比 $>1.5$ 时打印提示。

### 4.3 弧长求值（两块板同规则）

轴线是**混合段链** $\{g_k\}$（直线段或三次贝塞尔段，`_Curve`）。弧长表逐段建立：直线段取弦长（任何对常数精确的求积都返回它），三次段将 $t\in[0,1]$ 均分 16 片，每片用 **8 节点高斯–勒让德求积**：

$$\lvert g_k \rvert \;=\; \sum_{j=0}^{15}\ \frac{1}{32}\sum_{i=1}^{8} w_i\,
\bigl\lVert g_k'\bigl(\tfrac{2j+1+x_i}{32}\bigr)\bigr\rVert
\tag{4.5a}$$

（$x_i, w_i$ 为 GL(8) 节点/权重；单片多项式次数 $\le15$ 内精确，光滑段上求积误差远低于任何相关尺度。）

$H(s)$：先在段表上二分定位段 $k$，再在该段的 16 片弧长子表内**线性反查** $t(s)$，于真实曲线上求值 $g_k(t)$；$s<0$ 或 $s>L_h^m$ 时沿端点切向线性外推：

$$H(s) = \begin{cases}
g_0(0) + s\,\mathbf d_0, & s\le0\\
g_k\bigl(t_k(s)\bigr), & 0<s<L_h^m\\
g_{n-1}(1) + (s-L_h^m)\,\mathbf d_{end}, & s\ge L_h^m
\end{cases}
\tag{4.5}$$

**误差结构**：返回的点**恒在曲线上**；子表线性反查只造成"沿曲线的参数化偏差"，量级 $<10^{-3}$ px（实测 GL 表对近真值弧长误差 $\sim10^{-4}$ px）。旧实现的 4 px 展平则是**几何**误差：点落在弦上而非曲线上，且弦长和系统性低估弧长（实测 $-0.03\sim-0.13$ px，见 §10.6）。

$V(t)$ 同理。纯折线轴线（旧资产、轴线快照）退化为原线性内插公式，逐位一致。定位 $O(\log n)$。

### 4.4 核心：解耦的平移扫掠合成

$$\boxed{\;\Phi_2(p) \;=\; \underbrace{p - \mathrm{HV}[C](\ell_h,\ell_v)}_{\text{残差 }\mathbf r(p)}
\;+\; \mathrm{HV}[M]\bigl(\mu_h(\ell_h),\ \mu_v(\ell_v)\bigr)\;}
\tag{4.6}$$

即：把 $p$ 在**子系**参考架上重建一次，得到的残差原样搬到**主系**重建结果上。展开主系那一项就是 $H(s) + V(t) - O_m$——沿 H 轴（脊线）走到弧长 $s$，再叠加 V 轴在 $t$ 处相对交点的位移，**位移只平移、不旋转**。

两块板走同一个 (4.0)，差别只在喂进去的点表，这正是"解耦"的含义：**坐标指派**（4.1）与**参考架重建**（4.0）是两件独立的事。

**残差项的两个作用**：

1. **恒等性**（定理 6）。$\mathrm{HV}[C]^{-1}$ 精确时残差为零，$\Phi_2 = \mathrm{HV}[M]\circ\mathrm{HV}[C]^{-1}$；两块板画同一组轴线时 $\mathrm{HV}[M]\equiv\mathrm{HV}[C]$、$\mu=\mathrm{id}$，故 $\Phi_2 = \mathrm{id}$ 逐位成立。
2. **兜底**。逆不收敛处（非单射区）残差非零，把坐标指派的误差原样保留而不是丢弃，使映射在整个平面上有定义且不会突然发散。

> **为何必须解耦**：旧版本用**子系弦**分解、用**主系弧**重建，两侧不对称。后果是子系轴线的弯曲既被丢弃、又被当作离轴位移注入主系——两块板画完全相同的曲线轴线时映射本应是恒等，实测却整体错位（振幅 10 时 28 px，振幅 60 时 157 px）。

### 4.5 线宽缩放

$$w' = \max\left(0.5,\ w\cdot\underbrace{\sqrt{\frac{L_h^m}{L_h^c}\cdot\frac{L_v^m}{L_v^c}}}_{\text{width\_scale}}\right)
\tag{4.7}$$

单一全局几何均值，**两侧均取弧长全长**（旧版子系取弦长，曲线子系轴线因此按弦缩放）。当 $\sigma^-\ne\sigma^+$ 时这仍是近似（不同象限面积缩放不同）。

## 5. 映射的数学性质

### 5.1 定理 1（Coons 退化）

> $\Phi_2$ 是**对边互为平移**时的双线性混合 Coons 曲面的闭式。

**陈述**：设 Coons 曲面
$$S(s,t) = (1-t)C_b(s) + tC_t(s) + (1-s)C_l(t) + sC_r(t) - \text{(双线性角点项)}$$
若 $C_t = C_b + \boldsymbol\delta_v$、$C_r = C_l + \boldsymbol\delta_h$（对边互为平移），则双线性修正项恰好抵消重复计数，$S$ 化简为 Boolean 和 $C_b(s) + C_l(t) - O$。

**验证**（§10.1）：4000 组随机 $(s,t)$，最大偏差 $6.4\times10^{-14}$ px。去掉平移前提（令上边界额外弯曲）后偏差达 $30.0$ px，说明该前提是**本质的**，非退化巧合。

### 5.2 定理 2（可分离性）

由 (4.6) 直接得

$$\frac{\partial\Phi_2}{\partial s} = T(s) \;\;(\text{与 } t \text{ 无关}),
\qquad
\frac{\partial\Phi_2}{\partial t} = N(t) \;\;(\text{与 } s \text{ 无关})$$

**验证**：固定 $s$、取四个不同 $t$ 计算 $\partial\Phi/\partial s$，最大离散度 $6.4\times10^{-14}$。

**推论（工程意义）**：主系某条轴线的绘制误差**不会**经由另一轴向传播放大；映射对轴线抖动的敏感度与离轴距离无关（对比 AM1 在离轴 300 px 处放大 6.0 倍）。

### 5.3 定理 3（雅可比与单射性）

解耦形式下，$\ell$ 对 $p$ 的导数是 $J_{\mathrm{HV}[C]}^{-1}$，残差项的两个 $I$ 相消，故

$$J_2 = J_{\mathrm{HV}[M]}\cdot\operatorname{diag}(\sigma_h,\sigma_v)\cdot J_{\mathrm{HV}[C]}^{-1},
\qquad
\det J_2 = \sigma_h\sigma_v\,\frac{\sin\angle\bigl(T_m,N_m\bigr)}{\sin\angle\bigl(T_c,N_c\bigr)}
\tag{5.1}$$

两种退化，来源不同：

- **分子归零**（两**主**轴线局部切向平行）：映射本身退化，与离轴距离 $\|\boldsymbol\delta\|$ **无关**。故 AM2 不存在 AM1 那种"离脊线超过曲率半径即翻折"的结构性奇异。
- **分母归零**（两**子**轴线局部切向平行）：$\mathrm{HV}[C]$ 不可逆，坐标本身失去意义（§4.1、§12.1）。子系轴线为直线时 $\sin\angle(T_c,N_c)$ 为常数，该分母不起作用，(5.1) 退化为旧版形式。

实测（直线子系架、圆弧脊线 $R=300$、离轴 $d\in[-400,400]$）：$\det J_2$ 沿离轴方向恒定。

### 5.4 定理 4（仿射退化）

**两系**四条轴线均为直线时，$T,N$ 皆为常向量，$\mathrm{HV}[C]^{-1}$ 全局仿射，(4.6) 化为分象限仿射映射；若进一步 $\sigma^-=\sigma^+$（两轴向皆然），则 $\Phi_2$ 是全局仿射（旋转 + 各向异性缩放 + 剪切 + 平移）。

> 子系轴线弯曲时该结论**不成立**：即便主系两轴线是直线、且 $\sigma^-=\sigma^+$，$\mathrm{HV}[C]^{-1}$ 仍只是分段仿射（在子系折线顶点处换单元），故 $\Phi_2$ 只分段仿射。这是弧长坐标相对弦基分解的必然代价——弦基永远全局仿射，但也永远不精确。

### 5.5 定理 5（方向保真与手性）

映射在两轴向严格满足"子系起点 $\mapsto$ 主系起点、终点 $\mapsto$ 终点"。零容差审计（不对称字母 F 图案，全部方向组合）：

| 情形 | 结果 | 偏差 | `mirrored` |
|---|---|---:|:---:|
| 两系方向一致 | 恒等 | 0.00 | false |
| 仅反转主 H | 水平镜像 | 0.00 | true |
| 仅反转主 V | 垂直镜像 | 0.00 | true |
| 两者均反转 | $180°$ 旋转 | 0.00 | false |
| 旋转架（均"自然"绘制） | 转置 = **镜像** | 0.00 | true |
| 旋转架 + 反转一条 | 真 $90°$ 旋转 | 0.00 | false |

**手性判据**：结果为镜像 $\iff$ 两参考架**旋向相反**

$$\operatorname{sgn}\det\bigl[T_c(s^c_\times),N_c(t^c_\times)\bigr] \;\ne\; \operatorname{sgn}\det\bigl[T_m(s_\times),N_m(t_\times)\bigr]
\tag{5.2}$$

这是"每轴向各自方向保真"的**数学必然**，非符号错误。注意陷阱：子系 H 画成竖线、主系 H 画成横线时，每对箭头单独看都正常，但组合旋向翻转 $\Rightarrow$ 必为镜像。修正方法：反向重画**任意一条**主轴线。代码据 (5.2) 在 `info["mirrored"]` 报告并提示。

> 实现上 (5.2) 两侧**都**取各自交点处的切向 $\det[T,N]$（`_Frame.jacobian(0,0)`）。旧版左侧用子系**弦基** $\det[\mathbf e_h,\mathbf e_v]$、右侧用主系切向，是弦与弧的混用。

### 5.6 定理 6（恒等性）

> 两块板的参考架完全相同时，$\Phi_2$ 是恒等映射——**与轴线形状无关**。

**证明**：$M\equiv C$ 时 $b^\pm = a^\pm$ 故 $\sigma^\pm = 1$、$\mu = \mathrm{id}$，于是 (4.6) 的两个 $\mathrm{HV}$ 项是同一函数在同一自变量上的取值，相消后 $\Phi_2(p) = p$。注意该论证**不依赖** $\mathrm{HV}[C]^{-1}$ 是否精确：即便逆在非单射区只解到最优迭代，两项仍在同一坐标上求值。

**验证**（正弦轴线，振幅 $0/10/30/60/100$，$21\times21$ 网格）：

| 振幅 | 旧实现 $\max\|\Phi_2(p)-p\|$ | 本版 |
|---:|---:|---:|
| 0（直线） | 0.0000 | 0.0000 |
| 10 | 28.5837 px | $4.0\times10^{-14}$ |
| 30 | 77.7644 px | $4.0\times10^{-14}$ |
| 60 | 156.6258 px | $4.0\times10^{-14}$ |
| 100 | 293.2112 px | $8.0\times10^{-14}$ |

**推论**：子系轴线上的点映到主系轴线上（弧长坐标使该性质在弯曲轴线上也成立）。实测子系 H 上的点到主系 H 的距离中位数由旧版的 7.7 / 17.8 / 31.4 px（振幅 10/30/60）降为 **0.0000**。

## 6. 阶段 III：曲线重建

### 6.1 问题陈述

$\Phi_2$ **非线性**（$H,V$ 按弧长求值于折线，(4.4) 分段线性）。故对源笔画上一条直线段 $\overline{p_1p_2}$：

$$\Phi_2(\overline{p_1p_2}) \;\ne\; \overline{\Phi_2(p_1)\,\Phi_2(p_2)}$$

左边是曲线，右边只是它的**弦**。若仅变换顶点再连直线，顶点间的形变被整体丢弃——用户观察到"点映射了，但连线还是直的"。实测：4 px 采样的源折线经含波浪主轴的映射后，真实像与弦偏离达 **35 px**。

### 6.2 锚点自适应采样（三模式共用）

**约束（用户规定）**：原始顶点是锚点，**永不被降采样**；只有原始顶点**之间**插入的采样点参与降采样。

**前置：源侧补点。** C++ 展平器只细分曲线元素，一条 `lineTo` 无论多长都只贡献两个顶点。故映射前先按 `POLY_STEP` 填补长直线段（`_densify`，用 `round` 不用 `ceil`，已按 4 px 展平的曲线因此不受影响）。缺此步时一条 500 px 直线只有两个锚点，源侧区域裁剪（逐顶点判内外）看不见中间的边界，采样器也只能靠探针把整段形变猜出来。

**结构折点（先劈开，再探测）**：$\Phi_2$ 由 (4.0) 在两块板上按弧长重建。折线轴线上它沿源段**唯一**失去仿射性的位置，是某个坐标越过一个轴线**段边界**——子系边界（坐标本身在此断裂）或经 $\mu$ 折算后的主系边界；曲线轴线上段内亦光滑弯曲，折点从"唯一可能的拐点"降级为"曲率集中的候选位置"，段内的连续弯曲由探针与（折叠切分的）中点采样承接，且每个源片长至多一个 `POLY_STEP`，为漏检幅度设界。边界位置由两个参考架的段弧长表直接枚举：

$$\mathcal K = \Bigl\{\tau:\ \ell_h(\tau)\in \mathrm{cum}^c_h - s^c_\times\Bigr\}
\ \cup\ \Bigl\{\tau:\ \ell_h(\tau)\in \mu_h^{-1}\bigl(\mathrm{cum}^m_h - s_\times\bigr)\Bigr\}
\ \cup\ (\text{V 轴同理})$$

（累积弧长表以折线起点为原点，$\ell$ 以交点为原点，故须减去交点弧长——与 (4.0) 是同一个平移。首末两个端点不计入：那里 (4.5) 是 $C^1$ 线性延拓，不是折点。）

`_structural_knots` 对每个原始区间的两端各解一次 §4.1 的坐标，在两端坐标之间线性内插取出落在区间内的 $\tau$；`_adaptive_map_polyline` **先**在这些 $\tau$ 处劈开，**再**在每个光滑子段上跑探针。

> 内插假定 $\ell(\tau)$ 在整个区间上仿射。一个区间内跨越多个折点时，除第一个外的位置只是近似——这也是保留探针的原因之一。

```
_adaptive_map_polyline(W, points) → [(映射点, is_original), ...]
  对每个原始区间 [a, b]:
      在 _structural_knots(W, a, b) 处劈开（插入点，非锚点）
      对每个子段递归细分 (深度上限 8):
          m ← mid(a,b);  g ← lerp(a,b,φ)          φ = 0.381966
          若 |W(a)-W(b)| > FORCE_STEP            (16 px 强制弦长)
          或 |W(m) - mid(W(a),W(b))| > tol       (0.4 px 中点平坦度)
          或 |W(g) - lerp(W(a),W(b),φ)| > tol    (黄金分割探测)
              则插入 W(m) 并对两半递归
```

**抗混叠**：单靠中点平坦度会被周期性形变欺骗——一条直线段横跨波浪主轴的**整数个周期**时，中点恰好落在弦上，偏差为零，该弯的地方完全不弯（实测：周期 200、幅度 ±30 的正弦下输出退化为直线）。黄金分割探测点（与中点永不成有理比）+ 强制最大输出弦长是**探测侧**的补救；结构折点则从**结构侧**消除该问题——折点是解出来的，不是探出来的，周期性无从欺骗。

**实测**（同一份补点后的源，仅折点开关不同；装置见附录 D）：

| 主轴线 | 源 | 仅探针 | +结构折点 |
|---|---|---:|---:|
| 温和 | 长直线 | 0.0544 px | 0.0132 px |
| 强 | 长直线 | 0.1300 px | 0.0533 px |
| 极端 | 长直线 | 0.3026 px | **0.0029 px** |
| 极端 | 4 px 弧 | 0.3418 px | **0.0030 px** |
| **子系振幅 80（近非单射）** | — | **37.3168 px** | **0.4338 px** |

最后一行是折点的主要理由：弧长坐标使弯曲的子系轴线**开始有意义**（§4.4），而仅靠探针时那类输入的误差是 37 px 量级。

**为何不做完整解析劈开**：折点集只在 $\mathrm{HV}[C]^{-1}$ 成立处才是完整的。子系参考架折叠（非单射）时坐标只是最优近似，"分段仿射"的前提不再成立，按折点直接发射会给出精确但错误的几何。故保留探针作为兜底：**定理成立处用解析，不成立处用探测**，两者都不劣于对方。`_MAX_KNOTS_PER_SPAN` 在折叠架扫过数百个顶点时均匀抽稀（而非截断），剩余由探针覆盖。

**输出规模**：折点以**非锚点**插入，故照常参与 §6.3 的降采样。降采样**前**点数约 $2\!-\!3\times$（90→200、909→1951），降采样**后**基本持平——同一测点集上折点版 / 探针版的最终点数之比为 $1.000\!-\!1.018$（最坏 $+1.8\%$；近非单射那档 294→298）。**两侧必须都取降采样后的口径**：拿探针版的降采样前点数（909）比折点版的降采样后点数（298）会得出"点数减少 3 倍"的错误结论。

代价主要在时间：每笔画 $1.4\!-\!4.9\times$（91 点直线子系源 0.85 → 3.5 ms；近非单射档 100 → 142 ms）。

### 6.3 区间内降采样

```
_decimate_between_anchors(flagged, ε):
    knots ← [首点]
    对每段「锚点→锚点」的采样序列 span:
        knots += RDP(span, ε)[1:]        # RDP 必保端点 ⇒ 锚点必存活
```

RDP 容差 $\varepsilon$ 由工具选项滑条 `RDP (×0.1px)` 控制，范围 $0.1\text{–}2.0$ px，默认 $0.3$ px。**该滑条仅在采样类模式（spline / polyline）下显示**，bezier 模式不使用 RDP，故隐藏（`visible_when` 通用机制）。

> **距离度量必须取到线段而非其所在直线。** $\sigma^-\ne\sigma^+$ 时映射会折叠（§4.2），折回的点离两端连线所在**直线**很近却离**线段**很远，用直线垂距会把它静默删掉：`_rdp([(0,0),(120,0.1),(-40,-0.1),(10,0)], 0.3)` 曾塌缩为两个端点，真实偏差 110 px。

### 6.4 三种输出模式

| 模式 | 源表示 | 重建方式 | 输出几何 |
|---|---|---|---|
| **spline**（默认） | 4 px 展平折线 | 锚点采样 → 区间 RDP → **向心 Catmull-Rom** 插值 | 三次贝塞尔路径 |
| **bezier** | 笔画**自身**的路径命令 | 每段三次曲线：锚点变换 + **控制柄方向导数传输** + 自适应细分 | 三次贝塞尔路径 |
| **polyline** | 4 px 展平折线 | 锚点采样 → 区间 RDP | 直线段路径 |

#### 6.4.1 spline 模式

对降采样后的结点序列作**向心** Catmull-Rom（$\alpha = 0.5$）插值，转为三次贝塞尔：

$$t_{i+1} = t_i + \|P_{i+1}-P_i\|^{\alpha},\qquad
\mathbf m_i = \frac{P_i - P_{i-1}}{t_i - t_{i-1}} - \frac{P_{i+1}-P_{i-1}}{t_{i+1}-t_{i-1}} + \frac{P_{i+1}-P_i}{t_{i+1}-t_i}$$

$$C_1 = P_1 + \tfrac13\mathbf m_1(t_2-t_1),\qquad C_2 = P_2 - \tfrac13\mathbf m_2(t_2-t_1)$$

**为何用向心而非均匀参数化**：结点来自 RDP，间距**高度不均**；均匀 Catmull-Rom 在不均结点上会过冲甚至自交，向心形式（$\alpha=0.5$）可证明无自交、无尖点。

#### 6.4.2 bezier 模式

保留艺术家自己的贝塞尔结构，对每段三次曲线 $(p_0,c_1,c_2,p_3)$：

$$p_0' = \Phi_2(p_0),\qquad p_3' = \Phi_2(p_3)$$

$$c_1' = p_0' + D_{\mathbf h_1}\Phi_2(p_0),\qquad c_2' = p_3' + D_{\mathbf h_2}\Phi_2(p_3)
\tag{6.1}$$

其中 $\mathbf h_1 = c_1-p_0$、$\mathbf h_2 = c_2-p_3$ 为控制柄向量，$D_{\mathbf v}\Phi$ 为**沿该向量的单侧方向导数**（差分步长 $\min(0.5,\ 0.25\|\mathbf v\|)$ px）。

**为何用单侧方向导数而非完整雅可比矩阵**：$\Phi_2$ 只是**分片光滑**——折线顶点处切向跳变、(4.4) 在 $\xi=0/\eta=0$ 处斜率跳变。完整雅可比的中心差分会**跨越**这些折角而得到无意义的平均值；沿控制柄自身方向的单侧导数则不会跨越锚点处的折角，且无需矩阵求逆（各向异性或奇异情形天然安全）。

**一阶精确性**：三次贝塞尔端点切向为 $3(c_1-p_0)$，光滑映射把切向量 $\mathbf v$ 送到 $D_{\mathbf v}\Phi$，系数 3 两侧抵消，故 (6.1) 一阶精确。

误差控制：在 $t$ 上取 $\max(3,\min(17,\ \text{输出弦长}/16))$ 个均布探测点 + 一个黄金分割点，比较变换后曲线与真实像；超差则 de Casteljau **对半细分源曲线**并递归（深度上限 6）。源锚点恒为输出锚点（细分只增不减）。

### 6.5 输出笔画构造

曲线模式经通用绑定 `vectorlogic.make_stroke_object_from_path(commands, points, ...)` 构造：`commands` 携带三次曲线段，`points` 为稠密展平（命中测试、橡皮擦、`subStroke` 均依赖 `stroke.points`）。序列化已验证可往返三次曲线段（`projectio.cpp` 的 `CurveToElement → cubicTo`），存档重载不会退化为折线。

## 7. 阶段 IV：区域裁剪

`Mapping Area` 工具以油漆桶方式（Python 侧区域检测）在任一视图产生封闭多边形集合，语义：

- **子系区域**：筛选参与映射的**源**内容
- **主系区域**：裁剪映射**结果**

裁剪对不同模式采用不同表示，均保持"内部为真"的偶奇判定：

| 模式 | 源侧裁剪 | 果侧裁剪 |
|---|---|---|
| spline / polyline | `_clip_polyline`（折线，**解析求交**） | `_clip_flagged`（带锚点标记，**边界切点标为锚点**） |
| bezier | `_clip_cubics`（**解析求根** + de Casteljau 分割） | `_clip_cubics` |

**穿越点是解出来的，不是采样出来的。**

- **折线 × 多边形边**：每条边一个 $2\times2$ 线性解（`_segment_polygon_crossings`）。
- **三次曲线 × 多边形边**：曲线到该边所在直线的有向距离**本身是三次的**，且其 Bernstein 系数恰为四个控制点各自的有向距离，故凸包判据先筛掉绝大多数边；剩余者由导数（二次）的根把 $[0,1]$ 隔离成至多三个**单调**区间，每区间至多一根，二分到机器精度（`_bernstein_cubic_roots`）。命中后再验交点落在边的实际范围内。

穿越点排序后，相邻两点之间的内外属性不可能改变，故每段只需一次中点判定；de Casteljau 提取内部子曲线，裁剪**不破坏曲线性**。

> **旧版是采样式裁剪**：只在发射点（或曲线上 $\le 64$ 个采样）判内外，边界由内外两点之间二分求得，故裁剪分辨率等于**采样密度**而与区域几何无关。后果：比顶点间距更窄的区域整段丢失（20 px 采样下 15 px 宽的区域保留 **0.000 px**），长三次段对 2 px 区域同样漏切。这也是 `_FORCE_STEP` 除抗混叠外承担的第二个未记载职责——解析求交后该职责解除。

**实测**（保留长度 vs 真值）：

| 用例 | 旧 | 本版 | 真值 |
|---|---:|---:|---:|
| 15 px 区域夹在 20 px 采样之间 | 0.000 | 15.000 | 15.000 |
| 2 px 区域 vs 900 px 长三次段 | 0.000 | 2.108 | 2.106 |
| 常规密集源 + 大区域 | 236.6683 | 236.6683 | 236.6683 |

## 9. 守卫与诊断

| 条件 | 动作 | 理由 |
|---|---|---|
| 任一轴线点数 $<2$ | 拒绝 | 无法定义弦 |
| $\dfrac{\lvert\Delta\rvert}{\|\mathbf e_h\|\|\mathbf e_v\|} < 0.05\ (\approx3°)$ | 拒绝 | 近平行架使 (4.1) 分解爆炸。以**角度**而非绝对面积判定——长轴线下绝对阈值会放行近平行架 |
| **任一系**轴线弧长 $\le 10^{-9}$ | 拒绝 | 退化（子系亦查，因坐标现在由子系弧长定义） |
| H/V 在任一视图**不相交** | 拒绝 | 猜测的原点在逐侧标定下产生无界垃圾；**拒绝优于输出垃圾** |
| 子系无图案笔画 | 拒绝 | 无输入 |
| 侧标定失配 $>1.5$ | 提示 | 跨轴笔画将在此折弯 |
| 旋向相反 (5.2) | 提示 | 结果为镜像，建议反向重画一条主轴线 |
| 输出笔画数 $=0$ | 回滚 + 提示 | 全被裁剪区裁掉 |

图案采集会跳过属性为 `h_center_line`、`v_center_line`、`mapping_area`、`auto_mapped`、`auto_mapping`、`auto_mapping_2` 的笔画（避免把工具自身的产物或残留笔画当作图案）。

## 11. 复杂度

设主系轴线各 $n$ 点、图案 $K$ 条笔画共 $V$ 个采样顶点、裁剪多边形共 $E$ 条边。

| 步骤 | 复杂度 | 备注 |
|---|---|---|
| 轴线求交 | $O(n^2)$ | 逐段暴力；refer-rect 网格因此**按视图缓存** |
| 单次 $\Phi_2$ 求值 | $O(k\log n)$ | 弧长二分 $\times$ Newton 迭代数 $k$；**直线**子系轴线 $k=0$（弦估计即精确解，首次残差检查即退出），弯曲时典型 $k=2\!-\!3$，近非单射处可打满上限 24 |
| 结构折点枚举 | $O(n)$ 每源段 | 两端各一次坐标解 + 扫两张累积弧长表；`_MAX_KNOTS_PER_SPAN` 封顶 |
| 自适应采样 | $O(V\cdot 2^{D})$ 最坏，实测 $\approx O(V)$ | $D=8$；深度上限亦是折角处的收敛保险 |
| RDP | $O(V\log V)$ 平均 | 最坏 $O(V^2)$ |
| 裁剪 | $O(V\cdot E)$ | 每条边一个 $2\times2$ 解（折线）或一次凸包判据 + 至多一次三次求根 |
| 输出 | $O(V)$ | — |

单点求值由弦基分解的 $O(\log n)$ 升为含 Newton 的 $O(k\log n)$：**弯曲**子系架实测 $\approx8\times$（1.10 → 8.62 µs/点），直线子系架仅 $\approx2.6\!-\!2.8\times$。叠加结构折点后每笔画 $1.4\!-\!4.9\times$（91 点直线子系源 0.85 → 3.5 ms；近非单射档 100 → 142 ms）。映射是单次点击操作，该量级不可感知。

## 11.5 Additional line：Third 空间影响场（`_AdditionalWarp`）

在 H/V 轴线之上，用户可在任一画板追加**Additional line**（粉色细化引导线），局部修形 Child↔Main 对应关系。

**Third 空间**。子系弧坐标平面 $(\ell_h,\ell_v)$ 即所需的标准笛卡尔空间：两条轴线在其中被拉直。Child→Third 为 `coords`（§4.1 逆解），Main→Third 为主系弧坐标除以逐侧转移比 $\sigma^\pm$（`main_coords` 为主系镜像逆解，弦基种子同 §4.1）。两画板的 Additional line 由此落入**同一平面**。

**影响函数**。贴合物体表面的线，其表面测地线与之正交；在拉平的 Third 平面中测地线是直线，方向即该线**首尾连线（弦）的法向** $\mathbf n$。据此，整个影响场在弦架 $(\mathbf o,\mathbf u,\mathbf n)$ 中构造：

1. 每条线是**一对** $(C, M)$（child 版、main 版）。两者重采样到等弧长参数后，差值仅取法向分量：$\delta(s) = (M(s)-C(s))\cdot\mathbf n$，$s$ 为弦参数——**变形只发生在弦的正交方向**；
2. 剖面 $\delta(s)$ 沿 $\mathbf n$ **平移掠扫**（全程不使用脊线坐标，掠扫方向恒为 $\mathbf n$）：位移 $w\bigl(|r - r_C(s)|/R\bigr)\,\delta(s)\,\mathbf n$，其中 $r_C(s)$ 为**所画线自身**在 $s$ 处的法向偏移——衰减以所画线为中心而非以弦为中心（对抗审查实测：以弦为中心时矢高 50 的弓形线只收到一半修正、U 形线颗粒无收）；
3. 衰减 $w$ 为工具菜单选项（Additional Line Falloff）：线性 $1-x$ 或二次 $(1-x)^2$，$R = 0.5\,\max(|\text{弦}|,\ \text{弧长})$；弦参数越界处剖面再按 $R$ 线性锥灭，影响在各方向平滑归零；
4. $\delta$ 与 $r_C$ 表先做 $[1,2,1]$ 平滑，收敛判据按**局部**键距（弦投影会把钩形/S 形线的分支交错成伪斜率，实测虚增 900 倍并吞噬全预算；平滑是尽力而为——单调斜坡是 $[1,2,1]$ 不动点——余下斜率全额计费，绝不假设被平滑掉）；两侧重采样按弦点积对齐方向（反向重绘同一形状曾伪造 13.5 px 剪切）；多条线求和。每对位移是 $F(s,r)\,\mathbf n$（秩一），算子范数恰为 $\sqrt{F_s^2+F_r^2}$，预算照此**正交合成**计费：$F_r \le |w'|_{\max}\cdot\text{峰值}/R$（$|w'|_{\max}$：线性 1、二次 2——初版漏计 2 倍导致二次衰减在声明包络的 25% 处折叠 warp）；$F_s$ 全额收剖面斜率、**端部锥灭自身的斜率**（可达峰值/$R$——初版漏计后，两条 135° 相接的直线在预算恰满时 det=−0.03）与 $r_C$ 漂移项（不设钳制——min(drift,2) 曾把发夹线低收 10 倍）。先按对钳制（PAIR_MARGIN 0.70）再全局钳制（TOTAL_MARGIN 0.85），保证场为压缩映射——warp 可由不动点迭代求逆，且 Jacobian 行列式恒正、**自身不产生新折叠**。

**管线接入**。映射为 $\Phi(p) = p - \mathrm{HV}[C](\ell) + \mathrm{HV}[M]\bigl(S(\Psi(\ell))\bigr)$（$\Psi$=warp，$S$=逐侧缩放）。位置一致性法则（折痕=位置场）要求所有消费弧坐标的部件看到同一个弧空间：`_orientation`（正/背面符号，$\det D\Psi>0$ 故符号公式不变）、`_arc_of_point`（深度计数）、`_emit_seals` 的图案弧界、`_child_of_arcs` / `_child_cutters`（$\Psi^{-1}$ 逆路线，折缝探针与填充 cutter 落在 warped 映射真实折叠处）、`inverse`（main→child 同步）、遮蔽预览（`_current_mapper` 带 pair、扫描逐格过 $\Psi$）全部经由 warp。无 Additional line 时 warp 为 `None`，全部路径与旧算术逐位一致。

**同步与编辑**。任一侧画完，另一侧立即合成镜像。pair 以 **id** 配对（跨板一致；一板 undo 产生的孤儿半对被忽略并提示，绝不按位置错配——实测位置 zip 会把幸存线错配出 120 px 伪形变；载入旧工程时按位置补齐显式 id，删除操作不再让无 id 半对错位），并携带**权威 Third 坐标**：新 pair 的搭档 Third **逐字复制**画侧（$\delta\equiv 0$ 按构造成立——经完整映射重推导曾在折叠主系上因原像分支歧义伪造 278 px 差值，经含 warp 映射合成曾把既有形变二次编码翻倍）；搭档的**显示**位置取**基映射**（无 warp）的像，与其 Third 描述同一参考架——按完整映射显示曾让搭档首次被编辑时把既有 warp 再编码进 pair（1 px 微调实测挪动映射 9 px）。**编辑 H/V 轴线会使全部 Third 失效**（Third 平面即子系弧平面），坐标在下次构建时从画布点重推导并提示。**在某板已有线附近重绘即替换该板的该条**（阈值 $\max(20,\ \min(0.15\,\text{已存线弧长},\ 0.5\,\text{新线弧长},\ 100))$——初版无绝对上限，2000 px 长线曾吞掉 280 px 外的独立短线；亚军距离过近时视为歧义改为追加），重绘侧的 Third 用被替换线的旧 Third 按弧长分数播种求解（反向重绘按端点就近倒序取种）——编辑保持在 pair 原本的原像分支上。Overlay 上删除任一侧即按 id 删除整个 pair，两板各自提交历史。资产存于两板 `scriptData`（`additional_line: {lines: [{points, width, id, third, commands?}]}`），随历史快照与工程保存往返。

## 12. 已知局限

1. **子系参考架可能非单射**：子系轴线弯到两切向局部平行时 $\mathrm{HV}[C]$ 不可逆，坐标退化为最优近似，残差项承载其余（§4.1）。此时"分段仿射"不成立，结构折点集不完整，精度由探针兜底——实测子系振幅 80 时最大误差 0.43 px（旧版同输入 37 px）。这是弧长坐标换来的新边界：旧版的弦基分解从不奇异，但也从不正确。
2. **$C^0$ 折角**：$\sigma^-\ne\sigma^+$ 时 (4.4) 在轴线处仅 $C^0$；$H(s)$ 在折线顶点处切向跳变。曲线重建现在**先在这些位置解析劈开**再细分（§6.2），但折角本身不会被抹平。
3. **轴线是折线而非曲线**：参考架捕获时按 `POLY_STEP` 展平（`_capture_mapping_item` 取 `polylines`），艺术家画的 $C^1$ 二次链被降为 $C^0$ 折线。结构折点数因此由展平密度决定，而非由几何决定。
3. **越界外推**：图案超出轴线张成范围时按 (4.5) 线性外推，无几何依据。
4. **线宽单一缩放**：(4.7) 为全局几何均值，$\sigma^-\ne\sigma^+$ 时各象限失配。
5. **不映射填充与栅格**：仅笔画被映射（Python 侧无添加填充区域的 API）。
6. **图层可见性**：mapped layer 仅在其映射所在帧持有单元格，故其他帧的图层面板不列出它。
7. **油漆桶不一致**：Python 侧区域检测跳过 `auto_mapped` 笔画，C++ 内建填充工具不过滤——多次映射堆叠后普通填充可能被切碎（已记录为待决事项）。

def auto_mapping_2():
    mode = curve_mode()                       # spline | bezier | polyline

    # ---- I 参考架 ----
    for view in (child, main):
        absorb_legacy_items(view)             # 兼容旧版存于图层的资产
        assert has_H_and_V(view)              # 否则拒绝

    pattern = collect_pattern_strokes(        # 跳过工具自身属性的笔画
        child, child_frame, want_commands=(mode == "bezier"))
    assert pattern                            # 否则拒绝

    for view in (child, main):
        assert H_crosses_V(view)              # 相交守卫在图案采集之后

    # ---- II 映射器 ----
    W, width_scale = build_mapper(C_h, C_v, M_h, M_v)   # Coons 是唯一算法
    assert W                                  # 角度 / 退化守卫
    warn_if(side_scale_mismatch > 1.5)
    warn_if(mirrored)                         # 旋向相反 (5.2)

    # ---- V 输出层（先建，便于失败回滚）----
    layer = create_mapped_layer(main, main_frame)   # 新建 + 置顶

    added = 0
    for stroke in pattern:
        color, width = stroke.color, max(0.5, stroke.width * width_scale)

        if mode == "bezier":
            for sub in commands_to_subpaths(stroke.commands):
                for src in clip_cubics(sub, child_area):        # IV 源侧裁剪
                    out = []
                    for cubic in src:
                        out += warp_cubic(W, cubic)             # III (6.1) + 细分
                    for piece in clip_cubics(out, main_area):   # IV 果侧裁剪
                        emit_curved(piece); added += 1
        else:
            for poly in map(densify, stroke.polylines):         # 长直线段补点 §6.2
                for src in clip_polyline(poly, child_area):     # IV 源侧裁剪（解析求交）
                    flagged = adaptive_map_polyline(W, src)     # III §6.2 折点 + 探针
                    for piece in clip_flagged(flagged, main_area):
                        knots = decimate_between_anchors(piece, rdp_eps())
                        if mode == "spline":
                            emit_curved(catmull_rom(knots))     # §6.4.1
                        else:
                            emit_polyline(knots)
                        added += 1

    if added == 0:
        discard_mapped_layer(main, layer)     # 事务性回滚
        return False

    ui.refresh()
    ui.history_commit("Auto Mapping", "main")
    return True
