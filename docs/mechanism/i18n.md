# 界面语言

三级机制。从属于 `../architecture.md`，与它冲突时以它为准。代码：`webui/src/i18n/`。承诺在 `../product_features.md`「画板与工作区」。

## 原文是英文

C++ 和 Python 发给网页的菜单、选项、历史标签和状态栏文字都是英文，它们不知道语言这回事。翻译只发生在网页把文字显示出来的那一刻：

- 发回后端的永远是原文。`layer.contextAction` 的 `title`、`menu.trigger` 的 `id` 都不经过翻译，所以后端和 `pyfile/` 不用为语言改任何判断。
- 设计文件 `webui/design/ui/scene.json` 里的文字也保持英文。`main.ts` 包一层组件，把 `text`、`label`、`title` 三个属性翻好再交给组件，组件和 VibeFrontend 编辑器都不用知道语言。Dock 标题在 `player.ts` 的 `getDockTitle` 翻译。
- `webui/vf/src/dock.ts` 是上游副本，停靠按钮的提示写死在里面，`player.ts` 在同步标题栏后用 `DOCK_ACTION_TIPS` 覆盖，不改副本。

## 词条

| 文件 | 内容 |
|---|---|
| `zh-CN.json`、`ja.json` | 全部词条，键是英文原文。两个文件的键必须一一对应 |
| `en.json` | 只放原文本身不是英文、或者是内部名字的条目：`补全拓扑`、`约束外轮廓 / Constrain Outline`、`draw_settings` 这类 |

键里带 `{0}`、`{1}` 的是模板。模板有两种用法：

- 网页自己拼的文字：`t("Frame {0}", name)`。
- 后端拼好发来的整句：`Undo in main: Add Layer` 匹配 `Undo in {0}: {1}`。抓到的部分只查逐字词条，所以 `main` 能译，文件名这类数据原样留下，叫 `Frame 12.anproj` 也不会被当成模板。例外是撤销、重做一句里的历史标签，它本身可能是模板（`Delete Group (3 layers)`），由 `index.js` 的 `LABEL_SLOTS` 标出。

多个模板都能匹配时，字面文字最长的优先：`AnimeAn - {0} [texture: {1}]` 排在 `AnimeAn - {0}` 前面。

## 哪些不翻译

| 内容 | 原因 |
|---|---|
| 图层名、资产名、文件名 | 是文档数据，存在工程文件里，用户可以改，也要在不同语言的机器之间共享。所以 `mapped layer`、`Auto-Mapping Layer` 这些程序起的缺省名字也不翻译 |
| Python Debug 里的输出 | 给开发者看的脚本输出 |
| 时间轴速率格里的 `1s×2` | 是记号，格子按等宽字符算宽度；完整名字（一拍二、2コマ打ち）在弹出的速率菜单里 |
| 状态栏错误里的异常原文 | 只翻前缀，`{0}` 是 Python 或 C++ 的异常文字 |
| `makeError` 的错误 | 现在只进控制台，不显示给用户 |
| Qt 桌面版界面 | Qt 界面的代码还在仓库里，但发布形态是 Tauri，翻译只做在 `webui/` |

## 切换

`setLanguage(id)` 写 `localStorage` 的 `animean.language`，改 `<html lang>`，再通知订阅者。选择是机器级偏好，不进工程文件，不经过后端；缺省英文，不跟随系统语言，和 `../user-workflow.md`「界面文案以英文为主」一致。`index.html` 的 `lang` 因此是 `en`，不再是原来的 `zh-CN`；菜单里的 ✓ 这类 Segoe UI 没有的符号走的回退字体会跟着变，宽度差不到 1 像素。

`lang` 不能省：界面字体 Segoe UI 没有中日文字形，简体中文和日文共用的汉字字形又不同，浏览器靠它选回退字体。

切换不重新加载页面，界面状态、画板和后端连接都不动。留在屏幕上的文字分两种更新：

- `label(el, 原文, fit)` 和 `tip(el, 原文)` 把原文记在 `data-i18n`、`data-i18n-tip` 上，换语言时统一重写。`fit` 在每次重写后运行，给要按文字调宽度的控件用。
- 从后端状态画出来的内容（菜单栏、历史记录、状态栏、窗口标题）用 `onLanguage` 重画。

弹出的菜单、提示和对话框是打开时才生成的，直接调 `t()`。

## 宽度

`panels.js`、`panels2.js`、`timeline.js` 里的宽度表是 Qt 量出来的英文宽度，只在英文时使用，其他语言用画布量文字。New Project 对话框的输入框从最宽的标签右边开始，和 `QFormLayout` 一样。时间轴的 GUIDE LINE、AM LAYER 标签按 Qt 宽度算字距，其他语言字距为 0。

同一个英文词在两处要译成不同的词时，键写成 `LINE (guide)` 这样，`en.json` 再映射回原文。

`popupMenu` 现在会把菜单挪回窗口内：译文更长时，贴着右边的右键菜单不再被裁掉。

## To 3D

To 3D 写一个独立的 HTML 文件，用系统浏览器打开，文字只能在写文件时定。网页通过 `tool.option`（`hook` 是 `ui_language`）把语言告诉 Python，C++ 只转发；`pyfile/ui_language.py` 记下语言，`_export_three_html` 用它的文字表替换模板里的 `__T_*__` 占位符。网页在收到第一个 `window` 状态时和每次换语言时各发一次。

## 新增界面文字

新文字用英文写，再往 `zh-CN.json`、`ja.json` 各加一条。下面两个检查会报漏掉的词条：

| 检查 | 查什么 |
|---|---|
| `webui/tests/i18n.test.ts` | 两份词条的键和占位符一一对应；C++ 的历史标签、状态栏、菜单，Python 的 `title` 和 `history_commit`，`tool_controls/*.json`，`scene.json`，`webui/src/ui/` 的固定文字都有词条 |
| `backend/tests/i18n_coverage.mjs <AnimeAnBackend.exe>` | 启动真实后端，取走菜单、每个工具的选项、设置窗和图层右键菜单，确认每句都翻得出来。Python 运行时才拼出来的文字只有这里查得到 |

译名以 `../glossary.md` 为准，Auto Mapping、Mapping Area 不翻译。
