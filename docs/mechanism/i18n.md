# 界面语言

三级机制。从属于 `../architecture.md`，与它冲突时以它为准。代码：`webui/src/i18n/`。承诺在 `../product_features.md`「画板与工作区」。

## 原文是英文

C++ 和 Python 发给网页的菜单、选项、历史标签、状态栏文字和错误都是英文，它们不知道语言这回事。翻译只发生在网页把文字显示出来的那一刻：

- 发回后端的永远是原文。`layer.contextAction` 的 `title`、`menu.trigger` 的 `id` 都不经过翻译，所以后端和 `pyfile/` 不用为语言改任何判断。
- 设计文件 `webui/design/ui/scene.json` 里的文字也保持英文。`main.ts` 包一层组件，把 `text`、`label`、`title` 和 Tools 按钮悬停提示的 `tipTitle`、`tip` 翻好再交给组件，组件和 VibeFrontend 编辑器都不用知道语言。Dock 标题在 `player.ts` 的 `getDockTitle` 翻译。
- `webui/vf/src/dock.ts` 是上游副本，停靠按钮的提示写死在里面，`player.ts` 在同步标题栏后用 `DOCK_ACTION_TIPS` 覆盖，不改副本；独立窗口里那个「恢复停靠」按钮由 `panelwindows.js` 改写，用的是同一句 `Dock panel`。
- `messageBox` 收英文的标题、正文和按钮，显示时翻译，用户点的按钮仍以英文交回，调用处照旧比较 `"Yes"`。

## 词条

| 文件 | 内容 |
|---|---|
| `zh-CN.json`、`ja.json` | 全部词条，键是英文原文。两个文件的键必须一一对应 |
| `en.json` | 只放原文本身不是英文、或者是内部名字的条目：`补全拓扑`、`约束外轮廓 / Constrain Outline`、`draw_settings` 这类 |

键里带 `{0}`、`{1}` 的是模板。模板有两种用法：

- 网页自己拼的文字：`t("Frame {0}", name)`。
- 后端拼好发来的整句：`Undo in main: Add Layer` 匹配 `Undo in {0}: {1}`。抓到的部分只查逐字词条，所以 `main` 能译，文件名这类数据原样留下，叫 `Frame 12.anproj` 也不会被当成模板。例外是撤销、重做一句里的历史标签，它本身可能是模板（`Delete Group (3 layers)`），由 `index.js` 的 `LABEL_SLOTS` 标出。

多个模板都能匹配时，字面文字最长的优先：`AnimeAn - {0} [texture: {1}]` 排在 `AnimeAn - {0}` 前面。

## 哪些不翻译

| 内容 | 原因 |
|---|---|
| 图层名、资产名、文件名 | 是文档数据，存在工程文件里，用户可以改，也要在不同语言的机器之间共享。所以 `mapped layer`、`Auto-Mapping Layer` 这些程序起的缺省名字也不翻译 |
| Python Debug 里的输出 | 给开发者看的脚本输出 |
| 时间轴速率格里的 `1s×2` | 是记号，格子按等宽字符算宽度；完整名字（一拍二、2コマ打ち）在弹出的速率菜单里 |
| 状态栏错误里的异常原文 | 只翻前缀，`{0}` 是 Python 或 C++ 的异常文字 |
| 打开、保存、导入、导出失败时消息框里的系统错误 | 消息框的标题和固定句子有词条（`Failed to save file:
{0}`、`Unsupported project file.` 这类，出自 `backendsession.cpp` 的这几个调用、`animeanbusiness.cpp`、`projectio.cpp`、`clipreader.cpp`）；`{0}` 里的文件系统错误、Python 异常、网页和后端之间的连接错误原样显示 |
| 其他调用的 `makeError` | 只进控制台，不显示给用户：未知方法、缺参数这类是程序的错，不是用户能遇到的 |
| 探针页 `pen_probe.html` | 只给开发者测笔输入，用环境变量 `ANIMEAN_START_PAGE` 打开，不在用户界面里 |

## 切换

`setLanguage(id)` 写 `localStorage` 的 `animean.language`，改 `<html lang>`，再通知订阅者。选择是机器级偏好，不进工程文件，不经过后端；缺省英文，不跟随系统语言，和 `../user-workflow.md`「界面文案以英文为主」一致。`index.html` 的 `lang` 因此是 `en`，不再是原来的 `zh-CN`；菜单里的 ✓ 这类 Segoe UI 没有的符号走的回退字体会跟着变，宽度差不到 1 像素。

`lang` 不能省：界面字体 Segoe UI 没有中日文字形，简体中文和日文共用的汉字字形又不同，浏览器靠它选回退字体。

切换不重新加载页面，界面状态、画板和后端连接都不动。留在屏幕上的文字分三种更新：

- `label(el, 原文, fit)` 和 `tip(el, 原文)` 把原文记在 `data-i18n`、`data-i18n-tip` 上，换语言时统一重写。`fit` 在每次重写后运行，给要按文字调宽度的控件用。
- 从后端状态画出来的内容（菜单栏、历史记录、状态栏、窗口标题）用 `onLanguage` 重画。菜单栏只在标题变了时重建，换语言也算标题变了。状态栏记着当前那句的原文，Python 忙时的 `Python busy...` 也一样。
- 纹理面板和子控件框没有地方显示时停在页面外，统一重写够不到它们，所以它们自己在 `onLanguage` 里调 `relabel(root)` 并重画菜单栏和标题。

弹出的菜单、提示和对话框是打开时才生成的，直接调 `t()`。对话框的文字由 Python 给出（`pyfile/dialogs.py`、`file_menu.py`），也是英文原文，对话框页（`dialog.html`）显示时翻译；它和独立面板窗口一样经 `storage` 事件跟着换语言。语言从 Settings ▸ Language 换：菜单是 Python 的（`pyfile/ui_settings.py`），选了以后 Python 广播 `py/preferences`，主窗口页调 `setLanguage`，存进 `localStorage`。

面板拖出去成了独立窗口，就是另一个页面。它和主窗口同源，共用 `localStorage`，靠 `storage` 事件跟着主窗口换语言；把语言告诉 Python 只由主窗口做。

## 宽度

`panels.js`、`panels2.js`、`timeline.js` 里的宽度表是 Qt 量出来的英文宽度，只在英文时使用，其他语言用画布量文字。New Project 对话框的输入框从最宽的标签右边开始，和 `QFormLayout` 一样。时间轴的 GUIDE LINE、AM LAYER 标签按 Qt 宽度算字距，其他语言字距为 0。

同一个英文词在两处要译成不同的词时，键写成 `LINE (guide)` 这样，`en.json` 再映射回原文。

`popupMenu` 现在会把菜单挪回窗口内：译文更长时，贴着右边的右键菜单不再被裁掉。

## To 3D 和折叠气泡

有两处文字不经过网页显示：To 3D 写一个独立的 HTML 文件，用系统浏览器打开，文字只能在写文件时定；折叠气泡（`_fold_note_items`）是覆盖层上的文字，由后端画成路径再发给网页。网页通过 `tool.option`（`hook` 是 `ui_language`）把语言告诉 Python，C++ 只转发；网页在收到第一个 `window` 状态时和每次换语言时各发一次。

`pyfile/ui_language.py` 记下语言。`_export_three_html` 用它的文字表替换模板里的 `__T_*__` 占位符；折叠气泡用 `ui_language.text(英文, …)` 取字，键也是英文原文。语言变了，`ui_language.on_change` 通知 `auto_mapping.py`，画板上已有的气泡按新语言重画。后端画字时按 Segoe UI、Microsoft YaHei UI、Yu Gothic UI 的顺序找字形，中日文都画得出来。

## 新增界面文字

新文字用英文写，再往 `zh-CN.json`、`ja.json` 各加一条。下面两个检查会报漏掉的词条：

| 检查 | 查什么 |
|---|---|
| `webui/tests/i18n.test.ts` | 两份词条的键和占位符一一对应；C++ 的历史标签、状态栏、菜单、窗口名和会进消息框的错误（`String`、`ANIME_STR`，旧的 `QStringLiteral` 也认），Python 的 `title` 和 `history_commit`，`tool_controls/*.json`，`scene.json`（含 `tipTitle`、`tip`），`webui/src/ui/`、`main.ts`、`player.ts` 的固定文字、菜单项、消息框和文件过滤器都有词条 |
| `backend/tests/i18n_coverage.mjs <AnimeAnBackend.exe>` | 启动真实后端，取走菜单、纹理面板的菜单和按钮、窗口标题和状态栏、历史记录、每个工具的选项、设置窗和图层右键菜单，确认每句都翻得出来。Python 运行时才拼出来的文字只有这里查得到 |

译名以 `../glossary.md` 为准，Auto Mapping、Mapping Area 不翻译。
