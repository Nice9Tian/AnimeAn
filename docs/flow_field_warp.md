## 1. 范式转换

| | 旧（_AdditionalWarp） | 新（_FlowFieldWarp） |
|---|---|---|
| 线的语义 | 绝对位移约束：δ(s) = M(s) − C(s) 全矢量剖面沿弦法向扫掠 | **引导纹理流向**：逐站相似变换 J = τ_M / τ_C（复数比：旋转+缩放） |
| 多线关系 | 按绘制顺序**链式复合**，先画者锁死后画者的施展空间 | 距离加权**混合成一个全局目标梯度场 G**，绘制顺序无关 |
| 求解 | 逐段查表 + 端部锥灭 + 模糊金字塔 | **加权泊松积分**：min ∬ ω‖∇U − G‖²，一次共轭梯度 |
| 折叠 | 有意折叠是特性（det_sign 宇称、fold_loci、正背/深度） | 正常情况下**无折叠**（能量折中天然保正向）；极端请求下的折叠如实上报，同一套 det/loci 机器处理 |
| 平移线对 | 全强度位移 | **惰性**（切向平行 ⇒ J=I ⇒ 无请求）——位移只能由弯曲/旋转的流向差表达 |
| 带外 | 影响半径外**精确归零** | 平滑谐波衰减（Dirichlet 界内、轴线钉扎，实测远地 <1px） |

## 2. 三阶段管线（规格）与工程落地

### 阶段 I：动态边界扩展与预拉伸（帐篷）

越界扫描取所有线点（child+main third）超出参考架 Third 窗（版心）的量 → 每侧平移量 T。帐篷位移分段：`(|t|/B)^α` 升至原边缘处全量 T（α=2），**保持全量直到求解域边缘**（Dirichlet 边界携带完整平移），再在 ≥2T 的跨度上 smoothstep **衰减回零**——钳制式剖面曾把边缘外任意远的地面（实测 3000px 外的探针）永久平移整个 T；衰减斜率 ≥−0.75 保持单调、一维逆良定义。**与规格公式的两个偏离**：(a) 规格的可分离式 `T_V·W_V(y)` 会把 V 轴上的点沿轴滑动（实测 (0,150) 滑 19px），违反"轴线绝对稳定"——每个分量再乘**对另一条轴的 smoothstep 渐入**（护罩区，见 §3，且在钉扎带内严格为零）；帐篷逆因此改用阻尼 2D 牛顿（网格外精确）。(b) **线的影响权重在原始 Third 坐标上度量**，不在拉伸后的位置——对抗审查的头号发现：在拉伸位置度量时，帐篷一有实际越界，影响带就落到离画线一个帐篷位移远的地方（25° 请求蒸发成 1.6°、场峰值离线 125px）；`apply` 以原始坐标查询，权重必须在同一空间度量。

### 阶段 II：全局目标流场

- 每条线重采样 65 站（等弧分数），逐站 `J = τ_M/τ_C` 复数比（[1,2,1] 两遍平滑）。**站位配对前按弦点积对齐方向**（两侧弦反向时倒转 main 侧）——反向重绘的线对否则被读成 ~180° 请求（实测 71px 漂移）；
- **中性线完全出场**：ask 处处为恒等（纯平移对、刚画完等待编辑的直线）的线不进入场——留在场里，它的 J=I 站位会在带重叠处与别的线的请求竞争（实测把已调带扰弯 64.6px）。"未编辑的线不得扰动映射"契约由此按构造成立；
- 权重 `w_k` = 现行衰减选项（linear `1−x` / quadratic `(1−x)²`），`R = 0.5·max(弦, 弧)`（工具菜单 Falloff 沿用）；
- **环境场是 ∇U_base 而非 I**：空白区积分回 U_base 本身，带边缘连续混入（裸 Σw·J/Σw 在 w→0 处跳变到 I）；环境权 `w_amb = max(0, 1−Σw)`；
- G = (Σ w_k J_k + w_amb ∇U_base) / (Σ w_k + w_amb)。

### 阶段 III：加权泊松积分

解 `∇·(ω∇U) = ∇·(ωG)`，Dirichlet `U|∂Ω = U_base|∂Ω`（消元式，以修正量 D = U − U_base 求解、边界 D=0），numpy 向量化 CG（5 点模板、矩阵自由，默认 96 格、短轴下限 48、~几十 ms；numpy 经 `pydeps.ensure` 装载）。**通量在边上精确装配**：线部分分子按边平均、环境项取 U_base 的精确边差分，`G_edge − ∇U_base|_edge` 闭式化为 `(n_edge − wsum_edge·∇U_base|_edge)/total_edge`——节点中心的环境梯度平均到边后与被减的精确基项不一致，曾在无线地面留下伪残余通量。

**ω = 1 + 24·(带影响占比)** —— 加权方向是本实现最重要的工程结论：
- 未加权时局部旋转请求（不可积）被全域谐波稀释，25° 请求线上只剩 4°；
- 反向加权（空白区加劲压尾部）更糟：顺从跌至 3.7°——**顺从与紧支撑是真实的取舍**，画下的意图优先；
- 带内拟合权大：线的地盘上匹配 G 占优；空白区最软，不可积矛盾在空旷处以平滑弯曲消化。

**割线助推**（≤3 轮）：解后在线站上量实测 ∇U 对切向的复数比，与**原始混合场 G**（固定参照）比较，按 `a* = a·target/achieved` 乘性修正（上限 4×）。参照必须是 G 而非各线自身 ask（向 ask 助推 = 冲突线军备竞赛、实测互顶成折叠），且必须是**原始** G（向已助推的 G 追赶 = 水涨船高，25° 超冲到 46°）。

**保真回撤**：助推后若 det 出现负值（擦零口袋，实测 −0.02），把助推向原始 ask 折半退让重解（≤3 次）——纯混合折中对冲突请求可证不折叠（规格承诺）；退无可退仍折者（如贴着钉死轴线的强请求）是诚实的能量答案，如实保留并由 det_sign/fold_loci 一致处理。

## 3. 轴线神圣（用户 2026-08-25 追加）

"H/V 轴线附近不要有权重（不要飘逸）"，三重落实：

1. **权重护罩**：每条线的 w 乘 `min(smoothstep(|x|/z_x), smoothstep(|y|/z_y))`，z = 12% 窗宽——两条轴线附近线权平滑归零；
2. **硬钉扎**：跨骑 x=0 与 y=0 的**两列/两行**网格节点为内部 Dirichlet（D=0）——只钉最近一列时轴线连续体在钉列与自由列间插值、仍飘 19px；
3. **帐篷交叉阻尼**（§2 阶段 I）。

实测全场景轴线漂移 ≤ 0.001px。助推对护罩内的站位随护罩渐出（否则会顶着护罩把目标顶上限）。**代价**（有意）：画在轴线附近的线让出轴线附近的话语权；紧贴轴线的强请求可能在护罩边缘折叠（y=50 处 25° 旋转实测 det min −0.57 的小口袋）——布料钉在缝线上被拽的褶皱，机器如实报告。

## 4. 接口面与消费端

保持旧插入点：`apply` / `unapply`（一个全局场及其逆——**首步起全程护卫**的牛顿/阻尼定点混合 + 多种子重试：裸定点在带内梯度 >1 处必发散；折叠带内为尽力分支、**右逆**到机器精度，带外精确；网格外走帐篷及其精确逆，种子越界时钳入网格照常迭代——真原像可在网格内）、`det_sign` / `fold_loci`（**四个单侧模板的逐点最小** det——中央差分会把被钉扎行夹住的单行折叠平均掉，审查实测节点 det 认证单射而公开 API 可测折叠、保真回撤永不触发；阈值 `DET_FOLD_TOL` 免擦零幻影；全正时 O(1)；等值线每次调用新副本供 id() 注册）、`.pairs`（每线一条，含 "radius"）、`.notes`（中性线与护罩吞没线的提示，并入 `additional_notes`——静默无效果不可接受）、`has_faces`（恒 False）/`face_at`（恒 0）。`displacement`/`jacobian` 保留为薄工具。`_current_mapper` 按**内容指纹缓存** mapper（自校验、无失效钩子）——导线拖拽逐帧重建时泊松解从 ~175ms 降到 0.01ms。`_bilinear` 的界判在分数上（`int()` 向零截断曾让低边外一格被负权外插而非回落帐篷）。近闭合线（弦 <5% 弧长）按端点邻近对齐，弦点积只用于普通线。

消费端不动：`main_of_third`、`inverse_point`、`_child_of_arcs`、`_arc_of_point`、`_with_warp_loci` 注册表、`_fold_depth`、遮蔽预览、3D、工具入口的搭档合成（弦仍在**渲染空间**取——把 child 画线推过现行场后取弦，锚定论证与场形无关）。third 缓存契约（存储 third 权威、长度不匹配才重推导）、分支连续性裁剪（`_branch_window`）、`additional_notes` 原样保留。

**终门修复（第三轮）**：帐篷上升段含**死区**（钉扎带内位移严格为零——上升在钉扎行上非零时轴线插值出 1-3px 漂移）且至少跨 6 格（微型版心的陡上升曾让双线性网格跟不上精确帐篷）；域 margin 提高到 1.5×半径（带缘压住 Dirichlet 边界曾在小版心上撕出 138px 的缝）；`apply` 在网格边界内 3 格边缘带向精确帐篷 smoothstep 交接（实测缝 <0.001px）；det 阈值贯通 `det_sign`/`fold_loci`；缓存指纹含 commands 内容；无 numpy 时优雅降级（警示 note、warp 惰性）。**缓存的诚实说明**：内容指纹只消除同内容重复构建（同帧两次调用、刷新重绘）；导线拖拽每帧内容都变，仍付一次完整求解（~160-220ms/帧）——异步预览留作后续。

## 6. 已知取舍

1. **平移惰性**：想"平移"纹理的用户需画弯线/转向线（流向差才是语言）——范式代价，规格原文"不再产生绝对的位移差"；
2. **尾部非紧支撑**：谐波衰减 + 轴线钉扎 + Dirichlet 界，实测远地 <1px，但不是数学零；
3. **近轴让权**（§3）；
4. **非可积请求部分顺从**：孤立旋转线实测 ~23°/25°（助推后），紧贴轴线时更低；
5. **网格分辨率**：96 格双线性（短轴下限 48）；亚格结构不可表达；`det` 以单侧模板逐点最小报告（对双线性场是紧的）；
6. **病态设定无顺从保证**：版心极小而线在其许多倍距离之外（如 30px 高的 V 架配 240px 外的 480px 长线）时，场仍保持单射、可逆、轴线不动，但线上流向的顺从质量无保证——宽版心上 12% 的轴线护罩也可能吞掉横穿轴线的长线的大段话语权。
