## 1. 范式转换

| | 旧（_AdditionalWarp） | 新（_FlowFieldWarp） |
|---|---|---|
| 线的语义 | 绝对位移约束：δ(s) = M(s) − C(s) 全矢量剖面沿弦法向扫掠 | **画下的测地线**（额外的网格等参线）：逐站相似变换 J = τ_M / τ_C 引导**本族**纹理流向 |
| 多线关系 | 按绘制顺序**链式复合** | 同族嵌套线做**关键帧插值**（外侧线权重在内侧线处衰减到 0）；正交族**互不影响**；绘制顺序无关 |
| 求解 | 逐段查表 + 端部锥灭 + 模糊金字塔 | **加权泊松积分**：min ∬ ω‖∇U − G‖²，一次共轭梯度 |
| 折叠 | 有意折叠是特性 | 正常情况**无折叠**；极端请求下的折叠如实上报，det_sign/fold_loci 一致处理 |
| 平移线对 | 全强度位移 | **惰性**（J=I ⇒ 无请求） |
| 带外 | 影响半径外精确归零 | 沿族向：坡向关键帧；沿线向：半径衰减包络；**最外侧向外保持**（见 §3） |

## 2. 三阶段管线（规格）与工程落地

### 阶段 I：动态边界扩展与预拉伸（帐篷）

越界扫描取所有线点（child+main third）超出参考架 Third 窗（版心）的量 → 每侧平移量 T。帐篷位移分段：`(|t|/B)^α` 升至原边缘处全量 T（α=2），**保持全量直到求解域边缘**，再在 ≥2T 的跨度上 smoothstep 衰减回零（钳制式剖面曾把 3000px 外的地面永久平移整个 T）。**与规格公式的两个偏离**：(a) 可分离式 `T_V·W_V(y)` 会把轴上的点沿轴滑动（实测 19px）——每个分量再乘对另一条轴的 smoothstep 渐入（钉扎带内严格为零）；帐篷逆改用阻尼 2D 牛顿。(b) **线的影响权重在原始 Third 坐标上度量**（在拉伸位置度量时影响带落到离画线一个帐篷位移远的地方，25° 请求蒸发成 1.6°）。

### 阶段 II：全局目标流场——族测地线关键帧模型（2026-08-25 重述）

**族**：child 笔画横向行程 Σ|Δx| ≥ Σ|Δy| 的线属 **H 族**（一条被移置的 H 等参线），否则属 **V 族**。

**族只发声于自己的梯度列**：H 族线的逐站相似 a+bi 只写目标梯度的 **x 列**（目标 ∂U/∂x = (a,b)）；V 族线只写 **y 列**（目标 ∂U/∂y = (−b,a)）。**正交族从不互相干扰**——各列各自与自己的环境份额（∇U_base）归一混合；仅存的耦合是可积性本身（同一张单值映射）。中性线（J≡I：纯平移对、未编辑的直线）**完全出场**。站位配对前按弦点积对齐方向；近闭合线（弦 <5% 弧长）按端点邻近对齐。

**族向权重 = 关键帧插值**（逐半平面，正交坐标 q：H 族取 y，V 族取 x）：

- **平行轴（过原点 O 的那条真轴）处为 0**——它是本族的锚测地线，权重从它向外线性上坡（falloff=quadratic 时坡取平方）；
- **内外嵌套线之间插值**：外侧线的权重在内侧相邻线处衰减到 0（内侧线局部淡出——延伸包络≈0——时，坡脚平滑交还给轴）；
- **最外侧线向外保持满权**——这就是"未勾选约束时最近的线塑造边缘"的机制；
- **被钉住的窗边是本族最外侧隐式关键帧**（勾选"约束外轮廓"且该边未被画出时）：权重向它坡到 0，而不是满强度顶着 Dirichlet 笼子（后者稀释整条向外带并在边旁折叠）；
- **求解域边界永远是最后的隐式关键帧**（数值画框，非用户可见轮廓；margin ≥ 1.5R 保证渐变平缓）；
- **沿线向**：有限笔画在自身跨度外按半径 R = 0.5·max(弦, 弧) 衰减（falloff 同样作用于此包络）；
- **正交轴旁的数值边界层**：正交轴的跨骑行/列是硬 Dirichlet，满权请求距它一格就会把拟合顶折——权重乘 4 格宽的 smoothstep（**分辨率尺度**，非旧的 12% 窗宽护罩）。层内有 ~1px 量级的谐波回弹，层外请求完整表达（实测紧贴 H 轴的竖线在 y=30 处流向 −23°/ask −25°）。

线本身贴着自己的平行轴画（q≈0）时权重恒零——记 note 提示（"(nearly) no influence"），静默无效果不可接受。

### 阶段 III：加权泊松积分

解 `∇·(ω∇U) = ∇·(ωG)`，Dirichlet `U|∂Ω = U_base|∂Ω`（消元式 D = U − U_base；内部钉扎支持**非零 Dirichlet**：E = D − pin_val 消元，见 §4 外轮廓），numpy 向量化 CG（5 点模板、矩阵自由，默认 96 格、短轴下限 48；numpy 经 `pydeps.ensure` 装载）。**通量在边上精确装配**：x 边通量拟合 x 列（H 族权重），y 边拟合 y 列（V 族权重）；环境项取 U_base 的精确边差分。**ω = 1 + 24·(该列族权占比)**：带内拟合权大，空白区最软，不可积矛盾在空旷处以平滑弯曲消化。

**割线助推**（≤3 轮）：解后在线站上量**本族列**的复数比（H 族：∂U/∂x ↔ duxx+i·duyx；V 族：∂U/∂y ↔ duyy−i·duxy），与**原始混合场 G 的同列**（固定参照）比较，按 `a* = a·target/achieved` 乘性修正（上限 4×）。参照必须是原始 G（向各线自身 ask 助推=军备竞赛；向已助推的 G 追赶=水涨船高）。站位修正随该站关键帧权重渐出（在自族轴旁/包络尾部的站位无从表达，硬顶只会对抗插值）。

**保真回撤**：助推后 det 出现负值则把助推向原始 ask 折半退让重解（≤3 次）；退无可退仍折者是诚实的能量答案，det_sign/fold_loci 一致处理。

## 3. 轴线与外轮廓

**轴线神圣**（不变）：跨骑 x=0 与 y=0 的两列/两行网格节点硬钉扎为 U=U_base（轴上恒等；帐篷死区保证 U_base 在钉扎带内就是恒等）。实测全场景轴线漂移 ≤1e-13 px。旧的 12% 窗宽"权重护罩"与"跨越半侧例外"**已删除**——族模型天然给出正确行为：线向自己的平行轴让权（插值坡），对正交轴毫不让权（族不相干；只剩几格的数值边界层）。

**约束外轮廓**（菜单勾选框 `约束外轮廓 / Constrain Outline`，默认**开**=最初设计）：

- **开**：H/V 轴线形成的版心外轮廓保持形状。钉扎是**分量式**的：左右边只钉 x（边保持直线 x=const，地面可**沿边滑动**），上下边只钉 y；两条被钉边的角同时得到两个分量、精确不动；被钉边与被释放边之间的角**沿被钉边滑动**去衔接（全分量钉扎曾与帐篷预拉伸在角部单格对撞）。钉值为"恒等 − U_base"（非零 Dirichlet，防帐篷渗漏到被钉边）。同时被钉窗边成为族的最外关键帧（§2）。
- **例外——画出边即释放**：任一侧有线点（child 或 main third）越出（恰为帐篷越界扫描的判据 t>0），该侧整边释放，跟随帐篷+流场形变（实测顶边越界时顶边抬升 ~80px，其余三边形状偏差 0.0000px，无折叠、往返精确）。
- **关**：无外轮廓钉扎、无窗边关键帧——场自由延伸，离边缘最近的 additional line 塑造边缘形状（向外保持的机制）。
- 勾选状态进入 mapper 内容指纹（切换即重建）。

## 6. 已知取舍

1. **平移惰性**：范式代价，规格原文"不再产生绝对的位移差"；
2. **可积性耦合**：正交族在权重上互不干扰，但同一张单值映射的两列梯度经泊松积分仍有物理耦合——重叠区各自小幅稀释（实测 H 线 24.2°→21.5°/ask 25，V 线同域 −15°/ask −20），无护罩时代的军备竞赛；
3. **向外保持**意味着最外侧线的话语权一直延伸到下一个关键帧（被钉窗边或求解域边界）——想局部化就在外侧再画一条线（或勾选约束）；
4. **数值边界层**：正交轴旁 4 格、被钉轴行/列本身 2 格——层内是钉扎与谐波回弹的地盘（~1px），层外才是请求的地盘；网格 96/短轴 48，亚格结构不可表达；
5. **嵌套冲突**部分顺从：对向旋转的嵌套线各保 ~90% 自身请求，中间地带过零插值（t_compose 案例 6 实测 +8.6/−7.2 对 ask ±10）；
6. **病态设定无顺从保证**：版心极小而线在许多倍距离之外时，场仍保持单射、可逆、轴线不动，但顺从质量无保证。
