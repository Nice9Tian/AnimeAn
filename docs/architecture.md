# 软件架构（architecture）

AnimeAn 的架构一句话：**Qt 基座 + Python 功能层**。C++ / Qt 是渲染和一切基础能力的基座，不变；软件的功能在 Python 里实现，随时改、不重新编译。本文只写这条核心逻辑和由它推出的分工；模块清单、事件表、文件格式、构建细节在 `mechanism/`（三级），Auto Mapping 的算法在 `auto_mapping/`（一级）。

> 状态：2026-09-28 用户拍板（一级）。

## 基座：Qt framework，不变

- **渲染**：两块画板都是 Qt 的 OpenGL 部件，笔画、填充、栅格、覆盖层、洋葱皮都由 C++ 画出来。
- **窗口与面板**：主窗口、带页签的父窗、工具栏、选项面板、图层树、时间轴、纹理面板、调色板控件都是 Qt 部件；主题也在这一层。
- **数据模型**：场景 / xsheet 模型（列、帧、资产、单元格、笔画、填充、栅格、图层组）、快照式历史、工程文件的读写。
- **嵌入 Python**：程序启动时起一个嵌入解释器，把模型、几何函数和界面门面绑定给 Python。

这一层是基座：换掉它，产品就不是这个产品。它只提供**基础函数**，不写任何功能的含义。

## 分工：C++ 写基础函数，功能在 Python

判据一句话：**C++ 里出现"这个工具是什么、这个属性叫什么、这个颜色是什么"，就是放错了地方。**

C++ 提供的基础函数（机制）：

- 画板的手势采集与路由，把手、覆盖层、视图按钮的显示与命中；
- 场景模型的读写与几何算法（路径与折线互转、命中、擦除区间、区域探测、精确贝塞尔劈分）；
- 声明式界面：按 Python 给的描述渲染选项面板、菜单、设置窗、图层右键菜单；
- 历史提交、窗口寻址、绘制颜色、光标、工具锁定这类通用开关；
- 向 Python 派发事件，接受 Python 的回传。

Python 决定的功能（策略）：一切工具的行为、属性名、颜色、数据结构、菜单内容、图层与工具的联动、Auto Mapping 的全部算法。

## 工具的归属

| 归属 | 工具 | 说明 |
|---|---|---|
| **C++ 内建（基础工具）** | 画笔 Pen、橡皮 Eraser（擦除 / 删线 / 切线）、视口缩放与平移 | 采样、防抖、抬笔拟合、擦除与切断的几何都在 C++；它们的选项面板和颜色仍由 Python 给出 |
| **Python** | Arrow 的编辑模式、Transfer（变形）、Connect、Fill 的策略、Repulsion Pad、全部 Mapping 工具（H/V 轴线、Mapping Area、附加线、Auto Mapping、视平线、To 3D）、图层与工具的联动、颜色与调色板策略、窗口策略 | C++ 只给它们把手事件、覆盖层、区域探测、变换矩阵这类基础函数 |

说明：用户口中的"放大缩小"分两件事——**视口**的缩放平移是 C++ 的基础能力；**内容**的缩放 / 拉伸 / 旋转是 Transfer 工具，属于 Python。Fill 也分两半：油漆桶的区域探测是 C++ 基础函数，点下去落在哪层、跟随哪条线稿、重复点击怎么办是 Python。

## 由此推出的结构

- **一个主画板，多个纹理。** 主画板只有一个；纹理板是纹理的容器，每个纹理有自己的场景模型和历史，以分页管理（现有实现只有一页）。Python 同时看得到全部场景；每个Auto-Mapping 单元记住自己的目标纹理页（规划），映射就是从那页读、往主画板写；多个纹理靠多个单元映射到同一块主画板。
- **帧是基本维度。** 场景模型是 xsheet：列、帧、单元格；每个工具的结果都落在某一帧上，洋葱皮和播放按帧工作。Auto-Mapping 单元将来逐帧记轴线（规划），让花纹跟着每一帧走。
- **一条事件缝。** C++ 把手势、界面动作和状态变化以事件发给 Python，Python 用绑定回写模型、叫 C++ 渲染；工具就长在这条缝上——新工具只需 C++ 一个枚举项加一个按钮，其余是一个 Python 模块。
- **脚本状态跟着文档走。** Python 的工具状态（引导线、Auto-Mapping 单元的配置、附加线、视平线、调色板）存在场景的 scriptData 里，C++ 不解释、只存，随撤销快照和工程文件一起走。
- **一切可撤销**靠整份模型的快照，所以任何来源的改动（含脚本）都能退回。
- **Python 层装的是会变的东西。** 实验性的算法、随功能扩展而变化的逻辑都放在 Python，所以改它不用重新编译；C++ 只在缺基础函数时才加。现成的库能省事就用（wheel 随包分发、首次使用自装），这是不重复造轮子，不是原则。
- **共享的数学只有一个家。** 贝塞尔劈分、屏幕与画布的换算在 C++ 和 Python 各一份镜像，调用处指回；手和眼的量按屏幕像素、作品的量按画布像素。
- **部署是一个自包含文件夹。** exe、Qt 运行库、完整 Python 运行时、脚本和 wheel 放在一起，离线可用；改脚本同步一下即生效，改 C++ 才重新构建。
