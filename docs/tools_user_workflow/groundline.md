# 地线（groundline）

> 状态：**规划，草稿，待用户拍板**（用户 2026-09-30 提出）。代码还没有。计划：`../plan/2026-09-30-地线-GroundLine-计划.md`。

Tools ▸ Mapping 的 **Ground Line**。把纹理板上的一段花纹钉到主画板上的一条线上。附加线只告诉 Auto Mapping"纹理往哪流"，不保证花纹停在哪；要花纹严丝合缝地落在某条线上，用地线。

## 在哪

- Mapping 页按钮 **Ground Line**。
- Options 面板：Mapping 页所有工具共用的运行选项块，加 **Stabilizer**、**Width**。
- 附加线可以转换成地线（入口待定）。

## 怎么用

1. 先有两块板的 H/V 轴线（现阶段）。
2. **画**：在纹理板上沿着要钉住的花纹画一条线。主画板上同步出现它现在落在的位置，两端各有一个图钉。画完什么都不变：它只是把这段花纹钉在当前位置，之后再加附加线、再改别的，这段花纹都不会被带走。也可以在主画板上画，纹理板上同步出现对应的那段。
3. **选中**：点一下地线，它出现发光描边。点空白处或按 Esc 取消选中。
4. **移动**：选中之后再画一条线，这条地线在这块板上的形状就换成新画的。在主画板上重画，花纹跟到新位置；在纹理板上重画，换一段花纹来钉。没有选中任何地线时画线，是新建一条。
5. **转换**：把一条附加线转换成地线，两块板上的线形不变，含义从"引导流向"变成"钉住位置"。
6. **删除**：点任一侧的 ×，两块板上的这一对一起删。

## 会看到什么

- 地线上的花纹整条落在主画板的那条线上，按弧长比例逐点对应，不是只对两端。
- 地线两端有图钉；选中时发光；颜色与附加线不同。
- 移动地线时，它带着周围一圈地面一起走，这一圈的宽度大约是移动距离的两倍，越靠近地线跟得越紧；H/V 轴线和图案外框在这一圈里跟着弯，圈外不动。
- 附加线在地线附近服从地线：两者要求不一样时，地线说了算，附加线的效果在那里让位。
- 单元有焦点时画完 / 移动完立即重跑。

## 边界

- 地线是硬钉。移动一条地线本身不会折叠，它周围的地面和轴线都会让路；两条地线要求互相矛盾时才会折叠，折叠按 Auto Mapping 的折叠处理（裁断、正面 / 背面），并在 Python Debug 提示。
- 现阶段仍需要 H/V 轴线。规划中用户可以不画轴线，只画一个被透视扭曲的矩形，轴线由它解析出来。
- 改动 H/V 轴线会让地线的坐标失效，下次构建时从画布位置重推。

规格（一级）：施工时在 `../auto_mapping/` 下起草地线一页。
