# 附加线（additional_line）

Tools ▸ Mapping 的 **Additional Line**（粉）。在 H/V 轴线之外再画几条线，告诉 Auto Mapping"纹理往哪流"。

## 在哪

- Mapping 页按钮 **Additional Line**。
- Options 面板：Mapping 页所有工具共用的运行选项块，加 **Stabilizer**、**Width**，最后一行嵌着纹理板。
- 菜单 **Auto Mapping ▸ Additional Line Falloff**（Linear / Quadratic）、**约束外轮廓 / Constrain Outline**。

## 怎么用

1. 先有两块板的 H/V 轴线。
2. 在任一块板上画一条粉色线，另一块板上同步出现它的"弦"（拉直后的对应线）。一条线就是一条你想要的网格等参线：把它画弯，本族（横向或纵向）的纹理就顺着它流动；画直线等于中性标记，什么都不改。
3. 在另一块板上拖动或重画对应的线，两边的差异就是形变。在已有线附近重画即替换那一条。
4. 多条线：同族嵌套的线之间平滑过渡，外侧线在内侧线处让权；横向族与纵向族互不影响；画的先后顺序无关。
5. **约束外轮廓**勾上时图案外框钉在参考架上（形状不变，可沿边滑动）；线画出哪一侧边界，哪一侧自动释放。不勾时外框随场自由延伸，最近的线塑造边缘。
6. 删除：点任一侧的 ×，两块板上的这一对一起删。

## 会看到什么

- 单元有焦点时画完 / 拖完立即重跑；主画板的参考网格（View ▸ Mapping Refer Rect）显示含附加线的最终 Auto Mapping 结果，粉线弯到哪网格就弯到哪。
- 线越出参考架范围时求解域自动撑大，不报错。

## 边界

- 纯平移的一对线不产生形变，位移只能由弯曲或旋转表达。
- 改动 H/V 轴线会让附加线的坐标失效，下次构建时从画布位置重推并在 Python Debug 提示。
- 线画过所在板参考架的折叠边缘时，跨过折叠的部分被丢弃并提示。
