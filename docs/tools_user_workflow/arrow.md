# 箭头（arrow）

Tools ▸ Painting 的第一个图标，工具提示 "Select strokes and points"。选择、拖动和编辑锚点都在这里。

## 在哪

- Painting 页图标 **Arrow**。
- Options 面板：**Edit Mode**（Default / Artist / Debug）。
- 菜单栏 **Arrow ▸ Outline Display Settings…**：选中轮廓的颜色和线宽。

## 怎么用

1. **Default**：点一下笔画或填充区域，它被勾出轮廓（先命中笔画，再命中填充）；在轮廓里按住拖动，整个对象平移。点空白处取消选择。
2. **Artist**：选中后只显示眼睛分得开的关键点（曲率显著的地方）；拖一个点，笔画在它附近平滑地局部变形，影响范围到相邻关键点为止。放大能看到更多点，缩小点变少。
3. **Debug**：显示存储的每个锚点和控制柄（三次段的两个端点、两个柄；直线段的两端；折线的每个顶点），切向臂用线画出。拖哪个点就改哪个点。
4. 三种模式随时切换，选中的对象不丢，只重画把手。
5. 选中填充区域时（Artist 和 Debug 一样）每个边界顶点一个把手，拖动直接改区域边界。
6. 在任一块板上点一下也把它变成活动板（画布边缘出现蓝色描边）。

## 会看到什么

- 每种模式都画选中轮廓，颜色和线宽在 Arrow 菜单的设置窗里改。
- Auto Mapping 的引导线、附加线、红色手柄、视平线都可以在 Arrow 下直接拖，不用切工具。选中 Auto Mapping 按钮时，画布手势也是 Arrow 的，但只拖引导，不选笔画。

## 边界

- 跟随线稿的填充层上，Arrow 是不会被锁掉的两个工具之一（另一个是 Fill）。
- 撤销 / 重做后选择被清空。
- Arrow 不处理栅格层：栅格没有顶点可编辑，也不会被点选；栅格的缩放平移用 Transfer。
