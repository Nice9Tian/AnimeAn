# Free Out Line（free_out_line）

Tools ▸ Mapping 的 **Free Out Line**。在纹理板和主画板上各画一条闭合轮廓，说明这块花纹在主画板上占什么形状。轮廓画完就是地线，花纹贴着它走。

## 在哪

- Mapping 组按钮 **Free Out Line**。
- Options 面板：Mapping 组所有工具共用的运行选项块，加 **Stabilizer**、**Width**。

## 怎么用

1. 在纹理板画好 H、V 轴线。
2. 选 Free Out Line，在纹理板上沿花纹外缘画一圈。松手时终点自动连回起点。
3. 在主画板上画这块花纹变形后的外形。方向、起点都随意。
4. 两条都画好后，两块板自动配对：轮廓变成彩色，红点落在配对的角上，主画板上没画过的 H、V 轴线由轮廓自动生成，Auto Mapping 就地重跑。
5. 要改形状：用 Deform 拖动，配对不变；要换一条：重画，新线替换旧线并重新配对。
6. 删除：点轮廓外框右上角的 ×。

## 会看到什么

- 两块板上颜色相同的位置是花纹上的同一点。
- 轮廓上的红点是配对的角点，两块板上是同一个花纹点。圆角也算角。
- 只画了一块板时，红点标这条轮廓自己的角，还没有颜色，也不影响 Auto Mapping。
- 改纹理板的轴线、拖动轮廓后，主画板的自动轴线跟着更新。
- 轮廓默认是地线。用 Choice Line 选中后取消「地线」勾选，它就只用来生成轴线。

## 边界

- 每块板一条。纹理板的轮廓不能自相交，太小或太短的笔画不接受。
- 第一次配对在几个相近的朝向里挑一个。接近矩形的轮廓可能挑错，这时颜色对应是错的，重画一条即可；配对之后不会再变。
- 主画板上跟随轮廓的轴线按 × 删不掉，删完会立刻重建。要让它停在某个形状，拖动或 Deform 它，之后它不再跟随。
- 主画板的轮廓可以自相交，那里按折叠处理。
