# 变形（transfer）

Tools ▸ Painting 的 **Transfer**。当前图层这一帧的全部内容被一个框套住，缩放、拉伸、平移、旋转。

## 在哪

- Painting 页图标 **Transfer**。
- Options 面板：**Alt / Ctrl / Shift**（Keep ratio / lock axis 或 No constraint）。

## 怎么用

1. 选中工具，内容被框住：四角、四边中点各一个把手，四角外侧各有一段旋转环。
2. 拖**角把手**：以对角为锚缩放；按修饰键锁定比例（按长边算，长边不超过鼠标拉出的框）。
3. 拖**边把手**：只沿这条边的方向拉伸，对边不动；按修饰键改成关于中心对称拉伸。
4. 在**框内**拖：平移；按修饰键锁到先动的那个方向（水平或垂直），和画笔画直线的规则一样。
5. 拖**角外的环**：绕框中心自由旋转；按修饰键才吸附到固定角度。
6. 松手即提交：框按新的内容范围重新套上，角度归零，可以继续下一次。
7. Options 选 **No constraint** 后，修饰键不再锁比例 / 锁轴。

## 会看到什么

- 光标随所在区域变化（缩放、拉伸、平移、旋转各不同）；不能旋转的对象上环不响应、光标也不提示旋转。
- 每次松手一条 Transfer 历史记录；不动就松手不产生记录。

## 边界

- 栅格单元格不能旋转（只能缩放、平移）。
- 锁定的图层不变形；跟随线稿的填充层上 Transfer 被锁。
- 变形的是当前层当前帧的全部内容，不是选中的一部分。
