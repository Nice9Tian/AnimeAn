# Deform（deform_line）

Tools ▸ Mapping 的 **Deform**。按住一条线的某一处拖动，这一处跟手，两边渐渐减弱。

## 在哪

- Mapping 组按钮 **Deform**。画布交互事件是 Arrow 的，不会画线。
- Options 面板：**Radius**（10–300 像素，缺省 60）；下面是 Refer Rect 选项。

## 怎么用

1. 调 Radius：影响沿线延伸多远。
2. 按住 H 轴线、V 轴线、附加线或轮廓上的一点，拖到想要的位置，松手。
3. 轮廓是闭合的，影响会绕过起点继续走。

## 会看到什么

- 拖动时只有这条线在动；Auto Mapping 的结果、参考网格和气泡停在拖动前，松手后才更新。
- 拖轮廓时配对不变，同色的点还是花纹上的同一点，红点跟着线走。
- 主画板的自动轴线被 Deform 后不再跟随轮廓。
- 一次拖动是一步撤销。

## 边界

- Deform 只改形状，不改线的方向和含义。
- 切换工具或帧会取消进行中的拖动，线回到原位。
- 拖得太大时花纹可能折叠，画板上会有气泡提示，见 `auto_mapping.md`。

规格（一级）：`../auto_mapping/closed_contour.md`。
