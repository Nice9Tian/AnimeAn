# 视平线（horizon_line）

菜单 **Auto Mapping ▸ 视平线 / Horizon Line**。一条可拖的橙色虚线，告诉 To 3D 哪一端远。

## 在哪

- 勾上菜单项，主画板出现一条横贯整页的橙色虚线。
- 单元的 Advanced Settings 里 **Horizon Line** 决定这个单元是否显示它。

## 怎么用

1. 勾上菜单项，虚线出现；用 Arrow 上下拖到画中的视平线位置（世界里水平的线在远处会向它收拢的那条线）。
2. 点它的 × 或取消勾选即删除。
3. 之后 To 3D 用它判断每根横向导引线哪一端远：离视平线近的一端远。

## 会看到什么

- 只能上下拖，不能左右。
- To 3D 运行时 Python Debug 里说明视平线是否被采用；导引线与视平线等高、横跨视平线两侧、或明显倾斜时会弃权并说明原因，结果与不放视平线相同。

## 边界

- 只在主画板上有，纹理板没有。
- 只影响 To 3D 的凹凸符号，不影响二维的 Auto Mapping。
- 随撤销和工程文件保存。
