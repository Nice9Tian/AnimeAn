# To 3D（to_3d）

菜单 **Auto Mapping ▸ To 3D**。把当前 Auto Mapping 的结果反推成三维浮雕，在浏览器里看一眼，用来核对 Auto Mapping。

## 在哪

- 菜单栏 Auto Mapping 的最后一项。结果是一个 HTML 文件，写在系统临时目录，自动用默认浏览器打开。

## 怎么用

1. 先把 Auto Mapping 准备好：两块板的轴线，纹理板上**带填充**的图案——填充区域就是"实体"，没有填充不能重建。
2. 可选：放一条视平线（见 `horizon_line.md`）。
3. 点 **To 3D**。Python Debug 打印顶点数、面数、披挂的笔画数、浮雕跨度和文件路径；浏览器打开查看器。打不开时按路径手动打开。
4. 查看器里：拖动旋转、滚轮缩放（正交相机）；浮雕高低滑条；翻转凹凸；线框开关；**Transfer Grid** 把参考网格披到曲面上，看整个变形后的参考系；**original camera** 回到与主画板一致的视角。

## 会看到什么

- 一张按填充轮廓三角化的曲面，顶点带纹理板的填充色；笔画作为带宽度的条带贴在曲面上。
- 从原始视角沿视线看，画面与主画板一致。

## 边界

- 整体凹凸方向原则上不可知：没有视平线时靠折叠处的叠放和"最小浮雕"猜，可用翻转开关纠正。
- 沿导引线方向的透视缩短被弧长参数化抹平，单峰形状常呈"帐篷"状；竖直方向的后退不参与判断。
- 需要 numpy 与三角化库，首次使用自动从随包 wheel 安装；缺库时退回纯 Python 实现，慢但可用。
- 查看器离线可用（three.js 已内嵌）。导出的是此刻文档的快照，没有持久的笔画 id，不能反向编辑。

规格（一级）：`../auto_mapping/auto_mapping_2_spec.md` 第 11.6 节。
