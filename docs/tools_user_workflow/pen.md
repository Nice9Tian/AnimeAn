# 画笔（pen）

Tools ▸ Painting 的 **Pen**。画一笔，抬笔时自动拟合成平滑曲线。

## 在哪

- Painting 页图标 **Pen**。
- Options 面板：**Color**（调色板控件）、**Stabilizer**、**Width**。
- 菜单栏 **Draw ▸ Draw Setting…**：**Stabilizer**、**Simplify**、**Corner** 三个滑条。

## 怎么用

1. 选颜色：在调色板控件里点已存色块，或用色轮 / HSV / RGB 调；新颜色可以加进色块集，色块集跟文档保存。Pen 记住自己上次用的颜色，切别的工具再回来颜色不变。
2. 按下拖动画一笔。画的过程中实时防抖：Stabilizer 越高越稳、也越滞后。抬笔时整笔拟合成线段加曲线。
3. Draw Setting 里 **Simplify** 决定拟合出多少节点（越高越少），**Corner** 决定多急的转折算尖角（尖角处切向断开）。这两个是文档级偏好，不是每笔的手势。
4. 按住 **Alt** 或 **Shift** 再拖：从按下修饰键的那一点起，线锁成水平或垂直（哪个方向位移大锁哪个）；松开修饰键立即恢复自由，一笔之内可以多次切换。
5. 按下后**停住不动**一小会儿：这一笔塌成从起点到光标的一条直线，之后跟着鼠标走直到松开；直线模式下 Alt / Shift 仍可用。
6. 在**独立填充层**上，Pen 变成区域刷：画过的封闭区域都被填成当前颜色，笔迹本身不留下。

## 会看到什么

- 画的过程中显示的就是抬笔后会提交的形状：远端已经定型，只有笔尖附近还在算。
- 每一笔一条历史记录，Ctrl+Z 退一笔。

## 边界

- 跟随线稿的填充层上 Pen 被锁（图标变暗，自动退回 Arrow）。
- 纹理板的 Changable Texture 关着时 Pen 画不上去，只有引导线工具能画。
- Width 是画布像素，缩放后视觉粗细跟着变；防抖的手感按屏幕算，缩放不影响。
