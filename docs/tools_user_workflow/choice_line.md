# Choice Line（choice_line）

Tools ▸ Mapping 的 **Choice Line**。选中一条线，决定它是不是地线。

## 在哪

- Mapping 组按钮 **Choice Line**。画布交互事件是 Arrow 的，不会画线。
- Options 面板：**地线** 勾选，标题里写着选中的是哪条线；下面是 Refer Rect 选项。

## 怎么用

1. 点 H 轴线、V 轴线、附加线或轮廓中的任意一条，它出现一圈光晕。
2. 在 Options 里勾上 **地线**：这条线上的花纹被钉住。取消勾选就恢复原来的含义。
3. 单元有焦点时，勾选后立即重跑。

## 会看到什么

- 地线上有红点：开放的线在两端，轮廓在配对的角上。
- 没选中任何线时，勾选框写着「先点一条线」，勾了没有效果。
- 附加线是一对线，在任一块板上选中都算这一对。
- 换到选线工具以外的工具，光晕收起；回来时还选着这条线。

## 边界

- 附加线设成地线后不再引导流向，只钉位置。
- 勾选和撤销、重做、存档一起保存。
- 地线之间互相矛盾，或把线挪过平行的轴线时会折叠，见 `groundline.md`。
