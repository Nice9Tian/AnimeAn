# 曲线（curve）

> 草稿，待用户拍板（Agent 2026-11-03 起草）。行为来自用户 2026-11-02 在浏览器 demo 里定下的做法，已按此实现（issue #100）。

Tools ▸ Painting 的 **Curve**。点一下放一个锚点，工具把锚点之间连成平滑曲线。

## 在哪

- Painting 组图标 **Curve**。
- Options 面板：**Width**（和 Pen 共用）、**Snap**。

## 怎么用

1. 左键点画板放下锚点。放到第二个锚点时线就落在当前层，之后每放一个锚点线就长一段，曲线从每个锚点穿过。
2. 右键：这条线在最后一个锚点结束。只放了一个锚点就右键，这个点不留下。
3. 光标靠近一条结束了的曲线的两端时会吸过去，左键从那里接着画，接上的还是同一条线。
4. 画到一半吸到另一条曲线的端点，左键就把两条线接成一条；吸到这条线自己的起点（至少三个锚点）就闭合成环。
5. 按住 **Alt** 点击不吸附，用来在别的线端旁边开一条新线；Options 的 **Snap** 关掉就一直不吸附。
6. 线的颜色是 Pen 的颜色，粗细是 Width。

## 会看到什么

- 光标跟着一段蓝色预览：下一次点击会改的那一段和新的一段，点下去就是这个形状。
- 已放的锚点是小方块，结束了的线两端是琥珀色菱形，吸住时有一圈蓝环。
- 每放一个锚点一条历史记录：Ctrl+Z 收回最后一个锚点，还能接着从前一个锚点画。

## 边界

- 只吸这个工具画的曲线的端点；Pen 画的线不吸。
- 曲线被橡皮擦过、切过或被别的工具改过以后，就不再当曲线续画，只是一条普通笔画。
- 两条线只能在同一层、同一格里接。
- 跟随线稿的填充层和独立填充层上 Curve 被锁。
