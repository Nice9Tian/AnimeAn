# 圆角（round_corner）

> 草稿，待用户拍板（Agent 2026-11-03 起草）。行为来自用户 2026-11-02 在浏览器 demo 里定下的做法，已按此实现（issue #100）。

Tools ▸ Painting 的 **Round Corner**。把线上的尖角拉成平滑的圆角。

## 在哪

- Painting 组图标 **Round Corner**。
- Options 面板：**Shape**（圆角饱满的程度，下一次拖动起作用）。

## 怎么用

1. 光标靠近线上的尖角时吸到角上（琥珀色菱形）。
2. 按住往外拉，从角上拉出一条控制线：拉得越远线越长，圆角越宽越平滑；上下移动转动这条线，它是圆角顶点处的切线方向，线一歪，圆角就偏向一边。你抓着的那一端一直在光标下。
3. 拉回角尖会吸住，线长为 0，恢复尖角；拉回这次按下的位置会吸住，圆角回到按下前的样子。
4. 按住 **Shift** 两边一样长。拖动中右键取消，恢复按下前的样子。
5. 倒过圆角的角平时显示一条灰色控制线，抓它任一端可以再调。

## 会看到什么

- 拖动时：原来的尖角是灰色虚线，两个切点是蓝色小方块，控制线是蓝色。
- 每次拖动一条历史记录；只按不拖什么都不改。

## 边界

- 两段在接点的方向差超过一定角度才算尖角，平滑的地方不吸。
- 每边最多切到这一段的另一端；那一端已有圆角时让给它。
- 其他工具的线（轴线、附加线、轮廓这类带属性的线）不能倒圆角。
- 线被别的工具改过以后，原来的圆角不能再调，现在的尖角照样能倒。
- 跟随线稿的填充层和独立填充层上 Round Corner 被锁。
