# 画板动画：填充铺开、连接线画出、映射淡入（2026-11-03）

## 目标

软件演示动画（`demo/animean_demo.html`，另一个 worktree 里的演示稿）给 Fill、Connect 和映射都加了动画，软件里没有。用户 2026-11-03 要求给软件加上真实的动画：

- Fill：颜色从点下的位置铺开到区域边缘；
- Connect：新线从第一点画向第二点；
- 画完轴线或轮廓线时，映射结果淡入（用户补充）。

## 已定决策

- 承诺写进 `../product_features.md`「绘画工具」（二级，用户的要求即拍板）。工具用法页（一级）不改：怎么用没变，只是结果落下时多了动画；要不要在 `../tools_user_workflow/fill.md`、`../tools_user_workflow/connect.md`、`../tools_user_workflow/auto_mapping.md` 的「会看到什么」里加一句，由用户定。
- 按 `../developer_guide.md` 的分工：效果的种类、时机、时长是 Python（`pyfile/board_effects.py`）；C++ 只加一个通用调用 `board.effect`，把画布几何换成画板像素并转发；网页只画。渲染器不改。
- 只在「画完」时淡入：`run_center_line_tool`、`run_proxy_contour_tool` 触发的重算淡入；拖动、改选项、附加线的实时重算不淡入，免得跟不上手。
- 时长与缓动照演示：Fill 750 ms 缓入缓出，Connect 450 ms 匀速，淡入 800 ms 缓入缓出。这些是三级参数，写在 `../mechanism/painting_tools.md`。

## 设计

见 `../mechanism/painting_tools.md`「画板动画」。要点：网页在效果到达时拷下当前画面（还是改之前的），叠一层 canvas 盖住，带改动的帧落到下面后按效果的形状把旧画面一点点拿掉。所以工具要在改模型之前请求效果。

## 施工顺序

1. `pyfile/board_effects.py`：路径转扁平格式、铺开半径、三种效果，出错不影响工具。
2. C++ `board.effect`（`backend/session/backendsession.cpp`），`emitUiEvent` 加 `replay` 参数，效果不留作重连重放。
3. 网页 `webui/src/board/effects.ts` 与 `app.js` 接线、`shell.css` 的 `.board-effects`。
4. 接进 `fill_tool.py`、`connect_tool.py`、`auto_mapping.py`。
5. 测试与文档。

## 风险

- 效果和带改动的帧的先后：靠「钩子返回后才画帧」。黄金录制里逐条核对过（见回填）。
- 淡入是整块画板的交叉淡化：画完新轴线时，旧轴线和新轴线会同时半透明一下。新画的轴线在旧画面里本来就有手画的那一笔，所以第一次画轴时看不出；重画时能看到旧的淡出。
- 动画期间盖住的区域里，画板别的变化要等动画结束才看得到（最长 800 ms）；一按下就结束，不挡下一笔。

## Argon 审查（第一轮）与修正

四条全部核实属实，已修：

1. 映射淡入在 `_perform_mapping` 判断能不能映射之前就发了：没凑齐引导线时也淡入（把刚画的笔迹和轴线按钮淡出淡入），或者主画板没有新帧、覆盖层白等 4 秒。改为 `_run()` 返回是否映射出东西，映射出来以后再要淡入（仍在钩子里，帧还没发）。黄金录制里 auto_mapping 场景从 4 次淡入（两次没有改动）降到 1 次，就是真有输出的那次。
2. Fill 同色重复点、目标层隐藏时画板不变，没有帧，覆盖层白等，之后的撤销帧会把它启动，看起来像撤销在倒放铺开。改为这两种情况不要效果；等帧上限从 4 秒降到 1 秒。
3. 纹理板在 `ui.refresh()` 里可能自动适配视口，效果的几何按旧视口换算。改为该画板的 `viewport/<view>` 状态一变就结束效果（也覆盖了滚动条和 Fit View）。
4. 只有画板上的按下和滚轮会结束动画，Ctrl+Z、菜单、History 面板、滚动条不会。改为页面上任何地方按下、按键或滚轮都结束。

## 追加：面板滑动（用户 2026-11-03 补充）

用户要求拖动窗口自动排版时也有自然的过渡动画（演示里面板拖出、停靠时其余面板和画板滑过去）。

- 承诺加在 `../product_features.md`「画板与工作区」；机制在 `../mechanism/windows_theme.md`「面板滑动」。
- 文件：`webui/src/dock_glide.ts`（新）、`webui/src/player.ts`（`applyViews` 里比较停靠形状、记旧框、启动滑动）；`webui/vf/` 不动。
- 只在停靠形状变了时滑，改尺寸跟手不滑；画板 canvas 滑动期间钉在最终尺寸。
- 测试：`webui/tests/dock_glide.test.ts`（5 条）。无头 Edge 里关掉 Tools 面板：中央区宽度 982 → 1035 → 1063 → 1078 → … → 1092 px，约 240 ms 到位，期间画板只发了一次 resize。
