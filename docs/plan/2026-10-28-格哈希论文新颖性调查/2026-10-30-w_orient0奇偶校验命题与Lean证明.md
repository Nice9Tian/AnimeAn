# w·orient0 与原像个数的奇偶：命题、证明、反例与 Lean 核验

2026-10-30。任务（用户原话）：「证明：由于用 w·orient0，就可以判断正面像和像总数的奇偶。这可以不使用高精度小数来进行容差合并，通过检测外延长部分像的数量和正反，判断双曲平面内正面像和像总数的奇偶。回退：如果无法证明，请给出反例。结论：使用 Lean 进行证明。复核：1. 使用 Argon 进行整体审查 2. 使用 Argon 审查 Lean 证明中的命题部分。」

结论先行：原话拆成四条子命题，**两条成立、两条不成立**。成立的是「像总数的奇偶」（含外延的总数由 w·orient0 决定，面内的总数由 w·orient0 加外延原像个数决定）；不成立的是「正面像的奇偶」（含外延的、面内的都不成立，弯 100 px 装置上有具体反例）。能替代它的真命题是整数恒等式 f − b = w·orient0 及其面内版本：正面数以**带符号差**的形式被外延计数定出，知道像总数后再被**精确**算出。守恒律本身（f − b = w·orient0，说明页第 4、5 节，Brouwer 度）是输入假设，本文和 Lean 都不重证。Lean 4 核心库（不依赖 Mathlib）证明了全部成立的命题和两个反例，Argon 两轮审查的意见已按第 7 节采纳。用户随后追问「那是否就不能靠奇偶解决容差合并」：第 8 节的回答是奇偶只能当校验和，能替代距离阈值的是每个解的**朝向**——相距小于容差的两个解同向即同一个根的重复、反向即跨折缝的两个真根；共边情形是定理，格角处只有尖点、双折缝两类盲区，前者的错误守恒律必能发现，后者在说明页七套装置上不出现。

记号沿用 `w_orient0_explainer.html`。原话里的「双曲平面内」这里理解为**画出的面内**（两条导引线都在画出的弧长范围里的那些小格），与「外延」相对：说明页立体视图里画出的那张纸是马鞍形的曲面，口语上容易叫成双曲面；若用户指的是别的，请指出。

## 1 记号与前提

- 一副轴线 H、V，各是一条折线，在交点 O **横截相交**（O 落在节点上时取弧长增大方向的后一段，说明页第 2 节）。hv(ℓh, ℓv) = H(ℓh) + V(ℓv) − O，两线两端沿首段反向、末段方向直线**外延**到无穷远。
- 参数平面被分成有限多个**小格**：面内小格（两个弧长都在范围内）、边格（一个超出）、角格（两个都超出）。边格、角格合称外延。每个小格的像是一个平行四边形（外延的是半无限条带或锥），旋向 orient = sign(r_i × q_j) ∈ {+1, −1}；外延是沿末段（首段反向）直走，所以**边格、角格的 orient 与贴着的那个面内小格相同**（说明页第 4 节）。
- 前提一：**没有退化小格**（任何一段 H 与任何一段 V 不平行）。前提二：**相邻两个端向不反向**（d₁ 与 e₁、e₁ 与 −d₀、−d₀ 与 −e₀、−e₀ 与 d₁ 都不正好反向），否则 w 没有定义、守恒律不成立（说明页第 3 节）。前提一蕴含四个角格不退化，但不蕴含前提二以外的东西，所以两条都要写明。
- orient0 = O 所在小格的 orient；w = 四个端向连成的环绕原点的圈数，w ∈ {−1, 0, +1}。记 **k := w·orient0 ∈ {−1, 0, +1}**，它是这副轴线的常数。
- **正则点** A：不落在任何小格边、顶点的像上。正则点在每个小格里最多有一个原像（小格内 hv 是仿射双射），所以它的原像清单就是「哪些小格被点中」。以下命题都是对正则点说的；A 落在折缝的像或面与外延分界边的像上时，f − b = k 和面内 / 外延的互斥划分都不适用。
- 对一个正则点 A：正面原像数 f（orient = orient0）、背面原像数 b（orient = −orient0），两者都含外延。再按位置拆开：面内 f_in、b_in，外延 f_ext、b_ext。个数 N = f + b，N_in = f_in + b_in，N_ext = f_ext + b_ext（都不看正背）。
- **守恒律**（说明页第 4、5 节）：对每个正则点，f − b = k。

## 2 命题

用户原话前半句「判断正面像和像总数的奇偶」说的是含外延的 f 和 N；后半句「通过检测外延部分像的数量和正反，判断（双曲平）面内正面像和像总数的奇偶」说的是 f_in 和 N_in，输入是 k 和外延计数。按字面拆成四条，对任意正则点 A：

| 编号 | 原话拆出的子命题 | 结论 |
|---|---|---|
| P1 | 像总数（含外延）的奇偶由 k 决定：N ≡ k (mod 2)，即 N 为奇数 ⇔ w ≠ 0 | **成立** |
| P1b | 正面像数（含外延）的奇偶由 k 决定 | **不成立**（第 4 节：同一副轴线上 f = 1 与 f = 2） |
| P2 | 面内像总数的奇偶由 k 和外延原像的**个数**决定：N_in ≡ k + N_ext (mod 2) | **成立**，而且不需要外延原像的正反 |
| P4 | 面内正面像数的奇偶由 k 和外延的正背计数决定 | **不成立**（第 4 节：外延计数相同而 f_in = 1 与 f_in = 2） |

不成立的两条有替代的真命题 **P3**（不是原话拆出来的，是守恒律实际给出的东西）：

- 整数恒等式 f − b = k，以及 **f_in − b_in = k − (f_ext − b_ext)**：只检测外延就能定出面内正背之**差**。特别地 k − (f_ext − b_ext) > 0 时面内至少有一个正面原像；这是说明页第 5 节「k = +1 时每点必有正面原像」的面内版本。
- 由差到数：2·f = N + k，2·f_in = N_in + k − (f_ext − b_ext)。知道像的**个数**（不看正背）就能精确算出正面数，不只是奇偶。但 N_in 本身要数面内的原像，超出了「只检测外延」的输入范围；只检测外延得不到 f_in，连它的奇偶也得不到（P4）。

所以用户原话里「像总数的奇偶」那一半对（P1、P2），「正面像的奇偶」那一半错（P1b、P4）；正面像数要么作为带符号差出现，要么在知道像总数之后被精确算出。

## 3 证明

全部是守恒律的整数算术推论，前提见第 1 节。

**P1。** N = f + b = (f − b) + 2b = k + 2b，所以 N ≡ k (mod 2)。k ∈ {−1, 0, 1}，k 为奇 ⇔ k ≠ 0 ⇔ w ≠ 0（orient0 = ±1 不改变是否为零）。

**P3。** f = f_in + f_ext，b = b_in + b_ext（面内 / 外延互斥、合起来是全部），代入 f − b = k 得 f_in − b_in = k − (f_ext − b_ext)。N_in = f_in + b_in 与之相加得 2·f_in = N_in + k − (f_ext − b_ext)，相减得 2·b_in = N_in − k + (f_ext − b_ext)；含外延的版本同理 2·f = N + k。差大于零时 f_in = b_in + (正数) ≥ 1。

**P2。** N_in = (f_in − b_in) + 2·b_in ≡ f_in − b_in = k − (f_ext − b_ext) (mod 2)。而 −x ≡ x 且 f_ext − b_ext ≡ f_ext + b_ext (mod 2)，所以 N_in ≡ k + N_ext (mod 2)，只用到外延原像的个数。

**P1b、P4 不成立**由第 4 节的反例给出。机理：探针在面内跨过一条折缝时，面内同时多出一正一背两个原像，f − b 不变、外延不变，而 f 和 f_in 各加 1，奇偶翻转。

**守恒律本身**不在本文重证：说明页第 4 节分两步初等地证了 Σ orient = w（远处的点只落在四个角锥里，锥的 orient 等于环上对应弧的转向；A 连续移动时穿过同旋向两格的公共边原像只是搬家、穿过折缝两个原像同生同灭，Σ 不变），第 5 节代入正面 orient = orient0、背面 orient = −orient0 得 f − b = w·orient0。这是 Brouwer 度的基本性质在逐格仿射映射上的具体化。`verify_section_numbers.py` 十套装置 × 3000 点、说明页七套装置 × 400 点无一例外。

## 5 对「不用高精度容差合并」的评估

这几条命题是**校验码**，不是替代容差合并的算法。

- **能发现什么。** 正确的清单一定满足整数恒等式 f − b = k（面内版本 f_in − b_in = k − (f_ext − b_ext)）和奇偶式 N ≡ k、N_in ≡ k + N_ext。一个原像落在两个同旋向小格的公共边附近被两边各算一次，或者漏掉一个原像，f − b 就偏离 k 一个单位，恒等式和奇偶式都报错。
- **发现不了什么。** 奇偶式对偶数个错误失明（一次重复加一次漏掉、两次重复）。恒等式 f − b = k 强一级，但对三类错误失明：(a) **多算一正一背**——折缝附近两格旋向相反、像叠在公共边像的同一侧，探针落在零层那侧但离折缝不到容差时会同时点中两格；(b) **同旋向一重一漏**——一处多算一正、另一处漏算一正；(c) **面内与外延的归属错位**——说明页的几何代码（`solve`）里边格、角格不是另一套小格，而是把首末段小格的参数范围放宽到无穷、再用 `onSheet` 标志区分面内外延，所以面与外延的分界边附近不会算两次，只会把面内判成外延或反之，f_in ± 1、f_ext ∓ 1 而 f 不变，P1、P2、P3 全都看不见。两种校验都说不出错在哪个小格。
- **外延那一半的计数不是免费的。** 外延格也要判点在不在平行四边形（条带、锥）里，同样是浮点比较；外延格之间也有 2(n + m) 条公共边（射线），原像落在附近时同样有重复计数的问题。省的是数量：外延只有 4 个角格加 2(n + m) 个边格，面内有 n·m 个；离面远的点只落在角锥里，角锥的判定是两个叉积的符号。P2 还说明：只要面内像总数的**奇偶**，外延只需要个数，不需要正反。
- **把奇偶变成精确值的路。** 面内各小格的正、背分别数好后，用 P3 的 f_in − b_in = k − (f_ext − b_ext) 当整数校验，比只校验奇偶更有用；反过来用 N_in 推 f_in（2·f_in = N_in + k − (f_ext − b_ext)）在逻辑上成立，但 N_in 本身就是要去重的量，没有省掉容差。
- 说明页里的去重容差 1e-4 px（`DEDUP`）和正式实现里的处理不受本文影响；这里只说明校验能替哪一部分把关。替代距离阈值的判据见第 8 节。

## 6 Lean 核验

目录 `lean_w_orient0_parity/`，Lean 4（`leanprover/lean4:v4.35.0`，本机 elan 已装），**只用核心库，不依赖 Mathlib**；在该目录运行 `lake build` 约 2 分钟（第 8 节新增的 `Bow100Corners.lean` 用 `decide +kernel` 核对 529 个格角，占约 100 秒；其余约 3 秒），构建产物 `.lake/` 已忽略。

模型（`WOrient0/Parity.lean`）：

- `Cell`：小格，字段 `id`、`orient : Int`、`inner : Bool`（在面内 / 在外延）。边格、角格合并成 `inner = false`，因为命题只区分面内和外延。
- `Rig`：一副轴线，字段 `cells`、`orient0`、`w`，加三条假设：每个小格 `orient = ±1`（前提一）、`orient0 = ±1`、`w ∈ {−1, 0, 1}`（说明页第 3 节）。Argon 指出 P1～P3 其实只需要**被点中的**小格不退化，`orient_pm` 对全部小格要求是偏强的；为了定义简单保留了全称形式，这里记下。
- `Probe R`：一个正则点的原像清单 `hit : Cell → Bool`，加假设 `law : Σ_{hit} orient = w`——**守恒律在 Lean 里是假设，不是定理**；好处是任何 `Probe` 实例（包括反例）构造时都被迫核对守恒律。
- 计数 `f`、`b`、`fIn`、`bIn`、`fExt`、`bExt` 是「被点中且满足条件的小格个数」；`n`、`nIn`、`nExt` 是**不看正背**的个数，各自独立定义（不是 `fIn + bIn` 的缩写），`n_eq`、`nIn_eq`、`nExt_eq` 再证明它们等于正背之和（这一步用到小格不退化）。

| Lean 定理 | 命题 |
|---|---|
| `sum_orient_eq` | Σ_{hit} orient = orient0·(f − b)（对小格表归纳） |
| `Probe.count_split` / `f_split` / `b_split` | f = f_in + f_ext，b = b_in + b_ext |
| `length_filter_split_pm` / `Probe.n_eq` / `nIn_eq` / `nExt_eq` | n = f + b，n_in = f_in + b_in，n_ext = f_ext + b_ext |
| `Probe.f_sub_b` | f − b = w·orient0（说明页第 5 节） |
| `Probe.total_parity`、`Probe.total_odd_iff` | P1：n mod 2 = (w·orient0) mod 2；n 为奇 ⇔ w ≠ 0 |
| `Probe.inner_signed` | P3：f_in − b_in = w·orient0 − (f_ext − b_ext) |
| `Probe.inner_parity` | P2：n_in mod 2 = (w·orient0 + n_ext) mod 2，两边都不看正背 |
| `Probe.fIn_recover`、`Probe.bIn_recover`、`Probe.f_recover` | P3：2·f_in = n_in + (w·orient0 − (f_ext − b_ext))，b_in 同理；2·f = n + w·orient0 |
| `Probe.fIn_pos_of_pos` | P3：w·orient0 − (f_ext − b_ext) > 0 ⟹ f_in > 0 |
| `fIn_parity_not_determined`、`f_parity_not_determined` | P4、P1b 的否定：∃ 轴线 R、探针 P₁ P₂（共用同一个 R），外延计数相同而 f_in 一奇一偶；f 一奇一偶（五个小格的缩影 `toyRig`） |
| `Bow100.*`（`WOrient0/Bow100.lean`） | 弯 100 px 的全部 676 个小格（含外延；orient 由页面代码导出）和第 4 节两个探针的清单；`decide +kernel` 核对守恒律成立、计数为 (1,0,0,2) 与 (2,1,0,2)、含外延 (f,b,n) 为 (1,2,3) 与 (2,3,5)、f_in 与 f 都一奇一偶；`cells_grid_wf` 核对 676 个编号恰是 0..675 无重无漏、`inner` 标志与 26×26 的首末行列一致 |

两个 Probe 共用同一个 Rig，表达的是「同一副轴线上的两个正则点」，比只要求 k 和外延计数相同更强。`toyRig` 证的是逻辑独立性（只凭 Rig、Probe 的假设推不出 f_in 的奇偶），`Bow100` 证的是真实装置导出的数据确实给出这样一对点。

`#print axioms` 对上表每条定理**至多**给出 `propext`、`Classical.choice`、`Quot.sound` 三条标准公理（`cells_grid_wf` 不依赖任何公理）：没有 `sorry`，没有 `native_decide`。Lean 的 `%` 在 `Int` 上是欧几里得取模（(−1) % 2 = 1），所以 `total_parity`、`inner_parity` 的等式恰好就是模 2 同余；`Nat` 上的 `%` 与之一致。

**Lean 没有覆盖的部分**，都写成了结构字段里的假设或留在 Lean 之外：守恒律（Brouwer 度，说明页第 4 节的初等证明）；w ∈ {−1, 0, 1}（第 3 节的角度论证）；`Bow100.lean` 里「那几个小格确实是 A 的原像」和「676 个小格的 orient 确实是这副轴线的叉积符号」——这是浮点几何，由页面代码算出，Lean 只核对这份数据满足守恒律、编码良构，并数出计数。要把守恒律本身形式化，需要平面上逐格仿射映射的度数理论，Mathlib 目前没有现成的 Brouwer 度（`README.md` 已记此判断），不在本任务范围。

## 8 朝向配对判据：同向即重复、反向即折缝对

第 5 节的结论是这些命题只是校验码，替代不了容差合并。用户追问「那就是说不能靠奇偶来解决容差合并？」——答案分两半：奇偶（以及更强的守恒律）只能当校验和；真正能替代距离阈值的离散判据是**每个解的朝向**，它本来就随每个解一起算出。本节证明这条判据，算出它的盲区，再在说明页的七套装置上逐格角核对。

### 8.1 容差合并难在哪

说明页的 `solve` 和正式实现 `pyfile/chord_intersect.py` 都是逐格求解：每个小格里 hv 是仿射的，解出 (t, u) 后按 t、u ∈ [−EPS, 1 + EPS] 接受。落在两格公共边上（EPS 带内）的一个根会被两格各报一次，所以要去重；两个实现原来都按 (ℓh, ℓv) 的距离去重（页面 DEDUP = 1e-4 px，正式实现 1e-6 px），不看朝向；2026-10-30 起改为 8.7 的朝向配对。

距离去重的容差 τ 要同时满足两个相反的要求：**大于**求根误差，否则同一个根的两份报告合不起来；**小于**跨折缝两个真根的间距，否则把它们合成一个。后一个间距随探针靠近折缝像而趋于零，所以不存在对所有点都合适的 τ——「要高精度」的根源在这里，不在算得准不准。

### 8.2 判据与两条引理

**判据。** 两个解在 (ℓh, ℓv) 里相距小于 τ 时：旋向相同，是同一个根被相邻两格各找了一次，合并；旋向相反，是跨折缝的两个真根，都保留。

记相邻两格 L、R 共一条边，像分别是 C + r₁·t + q·u（L 在公共边的 t ≤ 0 一侧）和 C + r₂·t' + q·u'（R 在 t' ≥ 0 一侧）；q 是公共边的方向，r₁、r₂ 是两格另一组边的方向，三者都不为零且 r₁、r₂ 都不与 q 平行（前提一）。

**引理 A（同向 ⟹ 单射）。** r₁ × q 与 r₂ × q 同号时，两格的公共像点只有公共边上的同一个参数点：t = t' = 0 且 u = u'。证明：两像点相等的式子两边叉乘 q，消去 u、u'，得 (r₁ × q)·t = (r₂ × q)·t'；系数同号而 t ≤ 0 ≤ t'，左边与右边一个 ≤ 0、一个 ≥ 0，只能都是 0，于是 t = t' = 0，再由 q ≠ 0 得 u = u'。所以在精确的小格上，任何点在同向相邻两格里合起来至多一个原像（公共像点只在公共边 t = t' = 0、u = u' 上）；带 EPS 接受带的求解器在同向相邻两格里各报一次时，只能是公共边附近的同一个真根被两格重复报告。（Lean：`cross_eliminate`、`same_sign_shared_edge`，整数坐标；论证只用到有序环里乘法的符号规则和消去律，对实数逐字成立。）

**引理 B（反向 ⟹ 像叠合）。** r₁ × q 与 r₂ × q 异号时，取 t = r₂ × q、t' = r₁ × q、u = 0、u' = −(r₁ × r₂)，两格给出同一个像点，且 t 与 t' 异号：两格的像在公共边像的同一侧叠合，叠合区里的正则点有两个旋向相反的原像，这就是折缝。实数情形把 (t, u, t', u') 同乘一个与 r₁ × q 同号的小实数（并把 u、u' 平移到公共边的内点附近），就在 t < 0 < t' 即两格内部得到任意靠近公共边的公共像点；这一步要实数。证明是二维恒等式 a·(b × c) + b·(c × a) + c·(a × b) = 0。（Lean：`triple_identity_x/y`、`opposite_sign_shared_edge`、`opposite_sign_witness_sides`。）

**推论（共边情形的判据）。** 对正则点 A，在 EPS 接受带之外（A 离折缝像不止接受带的宽度，见 8.5 末条），来自共边两格的两份报告：同向 ⟹ 重复（引理 A：同向两格不可能各有一个不同的原像都贴在公共边附近）；反向 ⟹ 两个真根（同一个根被两格各报一次时它在公共边上：公共边不是折缝，两格同向，两份报告就同向；公共边是折缝，A 就落在折缝像上，不是正则点。所以正则点的两份反向报告一定是两个不同的根）。这部分不依赖 τ 的大小。A 落在折缝像零层一侧的接受带内时，两格会各报一个略出界的假根、旋向相反，这不在推论的范围里。

### 8.3 格角：判据的盲区

两个解相距小于 τ ≪ 小格尺寸时，两格要么共边（上一小节），要么只共一个格角。格角 C = (s_{i+1}, t_{j+1}) 周围四格 SW = (i, j)、SE = (i+1, j)、NE = (i+1, j+1)、NW = (i, j+1)；从 C 出发的四条半边的像方向按逆时针依次是 −r_i（W）、−q_j（S）、r_{i+1}（E）、q_{j+1}（N）。每格的像在 C 的像处是一个扇形，带符号的张角 θ_X ∈ (−π, π) 的符号就是该格的 orient；四个张角之和是 2π·W，W 是这四个方向向量绕原点的缠绕数，也等于 C 像附近任一正则点的（#正 − #背）——这是第 4 节守恒律的局部版本。四格旋向的符号模式只有五种：

| 模式 | W | C 像附近正则点的原像 | 判据的表现 |
|---|---|---|---|
| 四格同向 | ±1 | 恰 1 个（四个张角同号、各小于 π，和只能是 ±2π：PL 同胚） | 精确：相近的解都是同一点的重复 |
| 两相邻格异于另两格（折缝直穿 C） | 0 | 0 或 2 个，一正一背（同向的两格共边，引理 A 说它们合起来至多 1 个） | 精确 |
| 一格异于其余三格，W = 0（折缝在 C 转角） | 0 | 0 或 2 个，一正一背 | 精确 |
| 一格异于其余三格，\|W\| = 1（**尖点**） | ±1 | 1 或 3 个；3 个里**两个同向**，出现在奇格像扇形这个楔形里 | 楔形里错合一对同向真根，少一个根：守恒律差 1，**能发现** |
| 两对角格异于另两格（**双折缝**） | 0 | 0、2 或 4 个；4 个是两对同向，出现在四格像叠合的楔形里 | 错合两对，少一正一背：守恒律不变，**发现不了** |

原像个数的推导：W = #正 − #背，每格至多出一个原像，奇格至多贡献 1。四格同向时 #背 = 0、#正 = W = 1。一格异于其余三格时 W ∈ {0, ±1}（三个同号张角与一个异号张角之和落在 (−π, 3π) 或其镜像里）：W = 0 则两种旋向各 0 或 1 个；|W| = 1 则多数旋向比奇格多一个，奇格出原像（探针在奇格像扇形里）时就是 3 个、其中两个同向。双折缝时 W = 0（两正两负张角之和落在 (−2π, 2π) 里），两种旋向个数相等，可到 2 + 2；四格叠合的楔形总不空：SW 与 NE 两个同号格的像扇形，前者从 θ₀ 起张开 |θ_SW|，后者从 θ₀ + |θ_SW| − |θ_SE| 起张开 |θ_NE|；后者的起点在前者终点之前（差 |θ_SE| > 0），后者的终点在前者起点之后（差 |θ_SW| − |θ_SE| + |θ_NE| = |θ_NW| > 0），所以两扇形相交，交的张角是四个张角绝对值中最小的那个；W = 0 使交里两个背面格也都覆盖。

**符号判据。** 一格异于其余三格时，W 是 0 还是 ±1 由一个额外的符号决定。记 σ 为三个同向格的旋向：奇格是 SW 时 |W| = 1 ⇔ σ·(q_j × q_{j+1}) > 0；SE 时 ⇔ σ·(r_i × r_{i+1}) < 0；NE 时 ⇔ σ·(q_j × q_{j+1}) < 0；NW 时 ⇔ σ·(r_i × r_{i+1}) > 0。证明（奇格 SE）：沿 W→S→E 经过 SW（符号 σ）和 SE（符号 −σ），两个张角异号、各小于 π，和落在 (−π, π) 内，所以就是从 −r_i 到 r_{i+1} 的主值角 ψ；沿 E→N→W 经过 NE、NW 两个符号 σ 的格，和落在 σ·(0, 2π) 内且 ≡ −ψ (mod 2π)。σ = +1 时，ψ < 0 则后者是 −ψ、总和 0；ψ > 0 则后者是 2π − ψ、总和 2π。所以 W = 1 ⇔ ψ > 0 ⇔ (−r_i) × r_{i+1} > 0 ⇔ r_i × r_{i+1} < 0；σ = −1 对称地得 W = −1 ⇔ r_i × r_{i+1} > 0，合起来就是 σ·(r_i × r_{i+1}) < 0。另三个位置是转 90° 的同一论证，主值角分别取在半边对 (N, S)、(S, N)、(E, W) 上。ψ = 0 或 ±π（H 在节点 i+1 恰好反向或恰好直行）不会出现在这个模式里：直行时 SW 与 SE 同向，反向时 NE 与 NW 异向。

尖点为什么会出现：折缝是沿格边走的阶梯；两段相邻折缝边的像方向反平行时（例如 H′ ≈ −V′ 处的折缝、两线在该节点同向转弯），折缝的像在格角处掉头，掉头处里面多出两个原像，与光滑映射的 Whitney 尖点同构造。它是把导引线取成折线带来的，不是数值误差。双折缝的几何条件：SW 与 SE 异向、NW 与 NE 异向，说明 q_j、q_{j+1} 都落在 r_i 与 r_{i+1} 张成的角（张角 α，即 H 在该节点的折角）或它的对顶角里；SW 与 NW 异向，说明两者分处这两个对顶角，于是 q_j 与 −q_{j+1} 同在一个张角为 α 的角里，夹角 π − β < α（β 是 V 在该节点的折角），即 α + β > 180°：两条导引线在同一节点的折角之和超过 180°，导引线上得有尖刺。

### 8.5 结论

- **判据的地位。** 共边情形是定理（引理 A、B）；格角情形除两类盲区外精确，盲区都只在格角像周围半径约 τ 的范围内。
- **盲区与校验的配合。** 尖点盲区的错误是少一个根，守恒律必定发现（`sum_eraseIdx_ne`：从 ±1 的清单里去掉一项，和一定变）；双折缝盲区的错误是少一正一背，守恒律发现不了，但双折缝要求导引线在同一节点的折角之和超过 180°，七套装置上一个也没有，弯 100 px 在 Lean 里核对（`no_double_crease`）。
- **对「不用高精度」的回答。** 配对之后 τ 不再有「小于折缝对间距」这个趋于零的上界；它的上界放宽到小格尺寸的量级（判据只对共边、共角的两格有定理保证，τ 必须小于不相邻两格里同向真根的间距），而且 τ 决定尖点盲区的半径；下界仍只是大于求根误差。这就是能不用高精度的那部分；守恒律负责在尖点楔形里兜底。第 5 节说的归属错位（面内 / 外延）和「同旋向一重一漏」仍然看不见，与本节无关。
- **对实现的含义。** 页面与正式实现的距离去重在折缝像附近（δ 小于约 1e-5 px）会合掉折缝对、违反守恒律，在尖点楔形里会把三个根合成一个。改成配对只需在去重条件里加一句「且旋向相同」（`chord_intersect.py` 第 555 行、页面 `solve` 的 `kept` 循环），同时两处都要改成和所有已保留的报告比、不只和上一条比。2026-10-30 已按此修改，见 8.7。
- **两种做法都管不了的点。** 探针在折缝像没有覆盖的那一侧、离折缝像不到 EPS 接受带（约 EPS × 段长 × sin 夹角）时，折缝两侧的格各接受一个略出界的假根，原像数在 0 与 2 之间无法分辨、守恒律也不变。两格的带宽一般不等（EPS 限的是段参数，换到画布上随两格的边长和夹角而变），探针落在两条带宽之间时只有一格接受，多出一个假根，守恒律差 1——能发现，但去重无能为力。这是接受带的问题，不是去重的问题（8.7 的验收里单独计数）。

### 8.8 接受带的改法：研究结论（2026-10-30，未改代码）

用户要求让一个 Fable（高推理强度）子 Agent 和 Argon 研究怎么改。两边拿到同一份问题描述（`research_eps_band/PROBLEM.md`），独立作答：Fable 在草稿目录里写原型、做测量，没有动仓库；Argon 只读分析。材料都在 `research_eps_band/`：Argon 原文 `research_eps_band/argon_research.md`，Fable 的测量汇总 `fable_results_summary.txt`，原型模块、两份 diff 和探针脚本在 `prototype/`（脚本按草稿目录的布局写，路径要调整才能在这里跑）。

**先更正一处。** 8.7 交付时的说明和研究用的问题描述里都写了「非折缝边上同样的不等宽只造成同向重复，已被去重合并」，这不对（8.7 的验收只测了折缝边，没有暴露它）。一格在接受带内把 t 夹到 1 后，它的弧长停在节点上；邻格若很薄，同一个根在邻格里的弧长离节点约 EPS·|r_i|·sinθ_i / sinθ_{i+1}，可以超过去重容差，两条同向报告就合不上，Σ 差 1。Fable 在弯 100 px 的 Python 装置上测到非折缝边 14/10400 个探针违反守恒律（近平行薄格装置上 1815/5300），我在仓库现有代码上复现了格 (55, 34)|(56, 34) 的例子：两条报告的 ℓh 相差约 1.6e-6，三个距离上 Σ = −2。另外，8.7 里尖点处的 3746 个偏差大部分不是接受带造成的：接受带修好后还剩 3472 个，全部是去重把两个同向真根合成一个（8.3 的尖点盲区）。

**两边的结论一致：** 不要让两格各自用自己的 (t, u) 判断是否越过公共边，而让共边两格对**同一条边**算**同一个**判定量。

- 做法：格 (i, j) 的四条内部边各写成一个以两个节点 N = h[a] + v[b] 为端点的有向面积（叉积）。共边两格对公共边算的是同一个浮点表达式、同样的操作数，结果逐位相同。非折缝边两侧恰好一格接受（值为 0 时两格都接受，由去重合并）；折缝边两格要么都接受、要么都不接受。所以单边假根和零层一侧的假根对都没有了，接受带也就不需要了。首末段的导引线端那条边保持开放（外延），`on_sheet` 只看导引线端。
- Argon 的推荐是只用浮点符号、零容差（Fable 称 B）。Fable 推荐在 B 上加精确符号（称 C）：先用 Shewchuk orient2d 的误差界做浮点过滤，落在误差界内时 Python 用 `Fraction`、JS 用 BigInt 精确判定。这样格就是「舍入节点网格」上的闭合四边形，共边、共角都精确，整个平面被精确铺满；B 只在格角 ±1 ulp 以内可能出现几何上不可能的符号组合。实测 B 与 C 只在专门造的 ±ulp 格点探针上差 4 条同向重复（已被合并）。
- Fable 否掉的方案 A（每格参数带改成共边取较窄者）：浮点上两格仍从不同节点算 t，没有一致性保证；实测折缝边中点好了，格角仍有 85241 条假报告、尖点漏 114 个根。Argon 否掉的「在 `_finish` 里丢掉折缝上越界的根」：恰在折缝上的点会被两格都判越界而漏掉。
- 两边都指出 numpy 路径与逐格路径本来就不逐位一致（numpy 用展开式算 t），Fable 测到 500 个探针里 391 个原始 (i, j, t, u) 不逐位相同；现有测试只要求 1e-9。方案 C 让三条路径的最终判定都走同一个 `_test`，实测逐位一致。

- 恰在折缝或尖点上的根：舍入后的点若落到零层一侧，两个根成对消失，Σ 不变。这些是临界点，正则点为 0。Fable 的推测：只在折缝边上给一个共享的小容差 τ，可保住这些根，代价是零层一侧 τ 以内出现成对假根（Σ 不变），不会再有单个假根。

- 被剔除的近平行格在网格上留洞，与现在相同。
- `fold_inverse_explainer.html` 的外延族区间没有余量，网格模式在条带边界上恰好的点可能漏判，这是原有问题。

### 8.9 方案 C 的两个遗留问题（2026-10-30，分支 argon/crease-cusp-roots）

- **恰好落在折缝或尖点上的根：不改。** 舍入后的点落到零层一侧时，精确网格上的真值就是 0 个局部根，求解器没有错。下游输入的都是画布点，连续笔画穿过折缝时两支在折缝上汇合、成对消失。Argon 否定了「折缝上给共享容差 τ」：折缝在节点处转折时，两格各自的横向边截平移后的折缝线于不同点，楔区里只有一格接受，单个假根又回来了。

- **唯一剩余：** 查询点恰好等于尖点格角节点本身时，三个局部根在参数平面重合成一点，按不带重数的集合数，Σ orient 差 1。这是临界值，正则点不受影响。整数网格实测（`research_eps_band/cusp_node_probe.py`）：恰有一个奇格的角点共 5339 个，节点上都报一正一负两行，落在同一参数点，位置正确，矩阵与网格路径一致。其中局部卷绕数 W = 0 的 2647 个里 2635 个没有偏差；|W| = 1 的 2692 个里 2664 个偏差恰为 −W。其余 40 个另有 ±1，没有逐个核对。`pyfile/` 里没有调用方读这个和，所以不修。
