w·orient0 是什么：一个正负号怎么预告"有没有正面原像"

给第一次接触这个问题的读者。w·orient0 是一个只取 +1、0、−1 的正负号，由一副轴线算出来，是这副轴线的一个常数：画布上几乎每一点的"正面原像数减背面原像数"都等于它。所以它是 +1 时，每一点都至少有一个正面原像。读完你应该能说出：orient0 是哪里的旋向，w 数的是什么东西绕了几圈，为什么两者相乘就是那个差。每一节都有一张能动手的图，所有数字由页面现算。

0 · 先说问题出在哪

AnimeAn 是给动画师用的工具，核心功能叫 Auto Mapping：动画师画好一张图案，想把它贴到一个会弯、会动的区域上。做法是在图案所在的纹理板上画一对导引线（也叫轴线），一条偏横叫 H，一条偏纵叫 V，交于一点 O；主画板上另画一对导引线对应过去。图案上每一点用两个弧长记位置，到了主画板按同样的弧长找回去。本页只讨论纹理板这一侧的问题，下文把纹理板所在的平面叫画布平面，两个弧长所在的平面叫参数平面。

先定方向：每条导引线从首端画到末端，这是它的正方向。从 O 沿 H 往末端走弧长记正、往首端走记负，得到 ℓh；沿 V 同样得到 ℓv。走过首端或末端之后，就分别沿首段的反方向或末段的方向直线走下去，这部分叫外延。把两个弧长变成画布上一点的规则是：从 O 出发，先加上沿 H 走的位移，再加上沿 V 走的位移。

hv(ℓh, ℓv) = O + (H(ℓh) − O) + (V(ℓv) − O) = H(ℓh) + V(ℓv) − OH(ℓ) 表示从 O 沿 H 走弧长 ℓ 到达的点。当 ℓh、ℓv 取遍两条线各自的弧长范围时，hv 在画布上张出一张网格状的"面"。

这是正向。实际工作里更常要反着来：画布上给一点 A，问哪些 (ℓh, ℓv) 会落到 A。这些 (ℓh, ℓv) 叫 A 的原像。两条线都是直线时答案只有一个；线一弯，这张面可能在某处折叠，同一个 A 就可能有 3 个原像，也可能一个都没有。

折叠处的原像又分两种：面没翻过来的那层叫正面，翻过来的那层叫背面。"翻没翻过来"怎么用数学判断，是第 1、2 节的事；这里先记两个数：A 的正面原像有 f 个，背面原像有 b 个（两者都把落在外延上的原像算在内）。裁断规则是：画布上一点连一个正面原像都没有，就不往这一点贴图案，把它裁掉。所以裁断要知道的是 f 是不是 0。

w·orient0 回答的是：对这副轴线，f − b 是哪个常数。它是 +1 时，每一点都有 f ≥ 1，裁断根本不会发生；它是 −1 或 0 时，一定有些点 f = 0，具体是哪些点仍要逐点算。算这个常数只用六个方向向量——四条外延伸出去的方向，也就是 H、V 各自首段的反方向和末段的方向；再加上 O 所在那一段 H 和那一段 V 的方向，即 hv 在 O 处的两个偏导数——和一次乘法。准确定义见第 2、3 节。"几乎每一点"的例外只有小格边界的像，第 4 节叫它们非正则点，它们只占零面积。

一套 H、V 叫一个"装置"（下文也叫"架"）。这个下拉框控制全页的图。在左图里移动或点击鼠标，右图显示那一点的全部原像。

1 · orient：每个小格自己的旋向

导引线在程序里是折线，从首端到末端依次分段编号。H 的第 i 段是一个向量 ri，V 的第 j 段是向量 qj，都指向弧长增大的方向。参数平面以 ℓh 为横轴（向右）、ℓv 为纵轴（向上），由这两段围成的小矩形叫小格 (i, j)。按 hv 的规则，小格里的点映到画布上是"沿 ri 走一部分，再沿 qj 走一部分"，所以小格的像是一张以 ri、qj 为边的平行四边形。

平行四边形有正反两面：先沿 ri 走再沿 qj 走，是向左拐还是向右拐。这由二维叉积的符号决定：

orient(i, j) = sign( ri × qj ) = sign( rix qjy − riy qjx )取 +1 或 −1。叉积为 0 说明两段平行，平行四边形压成一条线段，这种退化小格在求原像（判断 A 落在哪些小格的像里）时直接跳过。

在参数平面里，每个小格都是"先向右再向上"，都朝同一面。像里如果相邻两个小格的 orient 不同，就是面在它们的公共边上翻了过来，那条边的像就是一条折缝（第 0 节左图的粗线）。

拖动两个箭头的端点，看平行四边形和叉积的符号。弧线上的箭头是从 r 转到 q 的转向

本页按数学习惯把 y 轴画成向上，叉积为正等于逆时针。程序里画布的 y 向下，相当于镜像：每个小格的 orient、orient0 和下面的 w 会一起变号，所以 Σ orient = w 两边同时变号仍然成立，w·orient0 不变。

换个更直观的说法：参数平面是一张方格纸，hv 把它贴到画布上。orient = +1 的小格贴的是纸的正面，−1 的小格是纸翻过来、背面朝上，两种小格的交界就是折缝。下面这张图把这张纸沿 ℓh 抬起来，叠在一起的几层就分开了；转到侧面看，能看清纸是怎么翻过去的。颜色按第 2 节的约定：O 所在的小格算正面。

拖动旋转，滚轮缩放，单击纸面或地面放探针 A（竖线，经过点中的那一点）。纸的正面 纸的背面；探针每穿过纸一次就是 A 的一个原像，圆点按穿过的那一面染色。画出的面用实色，外延用同样两色的淡色；外延本是无限的，这里画到盖住 A 的全部原像为止。粗线是导引线 H、V（颜色同第 0 节），细线是小格的边，色的是折缝，地面上的小球是其它交点

抬起量为 0 时就是第 0 节左图：几层纸压在同一个平面上。抬起后 z 与 ℓh 成正比，只为把层分开，没有几何含义；V 留在地面上，H 跟着纸抬起。弯 100 px 的装置里纸在中间折了两道，面中央三层叠在一起，探针放到那里会穿过三层。

2 · orient0：以交点 O 为准，定哪一面算正面

"正面""背面"需要一个参照。最自然的参照是动画师亲手画的交点 O：图案在 O 附近肯定是正着贴的。于是

orient0 = orient 在 O 所在的那个小格 (i0, j0) 上的值 = sign( ri₀ × qj₀ )ri₀、qj₀ 就是 H、V 在 O 处的切向。叉积 ≥ 0 记 +1。O 恰好落在折线节点上时，取弧长增大方向的后一段；本页假定两线在 O 处横截相交。

一个原像落在小格 (i, j) 里，它是正面还是背面，就看 orient(i, j) 是否等于 orient0。第 0 节的 f、b 就是这样数出来的。

orient0 只是个约定：把 H、V 的角色互换，所有小格的叉积一起变号，orient0 也变号，"同号不同号"一个都不变，正面背面的划分不受影响。第 0 节左图里 O 处的小扇形画的就是 orient0：从 H 的切向（蓝箭头方向）转到 V 的切向（紫箭头方向），逆时针是 +1。

O 在哪个交点。弯得厉害的导引线会交不止一次：弯 60 px 和弯 100 px 的 H、V 各交三次（左下、中央、右上），第 0 节左图用虚线小圈标出了没被选中的交点。正式实现（pyfile/chord_intersect.py 的 polyline_crossing，与 auto_mapping 的 _polyline_intersection 是同一条规则）取沿 H 从首端数第一个碰到的交点，本页默认照此。所以弯 100 px 的 O 在左下角那个交点上，不在图中央最显眼的那个——这一点容易看错。中央颜色最深的地方是三层纸叠在一起，按默认的 O，三层里两层正面一层背面。用第 0 节的"交点 O"下拉框换成中央的交点，全页跟着重算：orient0 变号，正面背面的颜色互换，w·orient0 从 −1 变成 +1。同一副轴线，O 放在哪一层，哪一层就算正面，这正是"orient0 只是个约定"的意思；而 w 只看四个端向，换 O 不变。

3 · w：四个端向连成的环绕了原点几圈

导引线两端外延的方向简称端向：H 末段方向 d₁、首段方向 d₀，V 的 e₁、e₀，都取单位长度，起点都放到同一个原点 (0, 0) 上比较。在参数平面上沿四条坐标轴走到无穷远，画布上的像分别朝四个方向跑出去：

  • ℓh → +∞（东）：像沿 d₁
  • ℓv → +∞（北）：像沿 e₁
  • ℓh → −∞（西）：像沿 −d₀（走过首端是沿首段反向直走）
  • ℓv → −∞（南）：像沿 −e₀

沿两条坐标轴之间的方向走呢？比如在第一象限朝 θ 方向走到距离 R，ℓh、ℓv 都是正的大数，像大约是 R(cos θ·d₁ + sin θ·e₁)，是两个端向的正系数组合。两个向量的正系数组合只会落在它们之间小于 180° 的那个夹角里。所以在参数平面上绕一个很大的圈（逆时针：东、北、西、南），像的方向就依次扫过 d₁ → e₁ → −d₀ → −e₀ → 回到 d₁，每一步走的是两个方向之间小于 180° 的那段弧。四段弧接起来是一个闭合的环，它绕原点转的净圈数就是缠绕数 w。

w = ( 转角(d₁→e₁) + 转角(e₁→−d₀) + 转角(−d₀→−e₀) + 转角(−e₀→d₁) ) / 360°转角逆时针记正、顺时针记负，每个取 (−180°, 180°) 里的那个。四步走完回到 d₁，总转角一定是 360° 的整数倍；每步不到 180°，总和的绝对值不到 720°，所以 w 只能是 −1、0 或 +1。

w 只看四个端向，与线中间怎么弯无关。两条直线：d₀ = d₁ = d，e₀ = e₁ = e，环是 d, e, −d, −e，正好绕一圈，方向与 d × e 同号，而这个符号也正是 orient0。所以直线架上 w·orient0 = +1，永远如此。线一弯，端向就可能转到别的象限去，w 可能变号，也可能变成 0：比如环上四个向量都落在同一个半平面里，方向就在圆上来回折返，净圈数为 0。

有一种情形 w 没有定义：相邻两个端向正好反向（比如 d₁ 与 e₁ 相反）。这时参数平面第一象限里有一条射线，沿它走像不跑向无穷远而是缩回 O，方向角突变 180°，不知该算 +180° 还是 −180°。页面显示"—"，后面的守恒式对这种架不成立。

P 的像 hv(P) 相对 O 的方向（蓝点）和四个端向。圆外的四段灰弧是环的四步转角；轨迹画成螺旋线是为了看清圈数，半径没有含义

4 · 守恒式：所有原像的旋向之和恒等于 w

先把 orient 和 w 连起来（第 5 节再代入 orient0）。要证的是：对画布上任何一个正则点 A（不落在任何小格边的像、顶点的像和退化小格的像上，剩下的点都是正则点），

ΣA 的全部原像 orient = w

这里的"小格"包括外延：参数平面在矩形的面之外被划成四个角格（两个弧长都超出范围）和四条边格（只有一个超出），它们是无限大的小格，整个参数平面就这样无缝拼起来，连面最外圈的边也是面内小格和边格的公共边。外延是沿末段（或首段反向）直走，所以边格、角格的 orient 和它贴着的那个面内小格相同。分两步证，都是初等的。

第一步：离得很远的点，直接数

取一个方向 û，不等于四个端向中的任何一个，把 A 放到从 O 沿 û 走很远的地方。四条边格的外延是沿端向伸出去的半无限条带，宽度有限；A 的方向避开了端向，走得够远后到每条条带的距离都趋于无穷，碰不到它们，也碰不到有限大的面。于是 A 的原像只能在四个角格里。角格 (末, 末) 是两条线都走过了末端，像是以 d₁、e₁ 为两边、从面的一角张开的锥；另外三个角格同样是锥，两边按环的顺序分别是 (e₁, −d₀)、(−d₀, −e₀)、(−e₀, d₁)。

每个锥在远处恰好覆盖它两条边之间那段小于 180° 的弧里的方向。A 落在某个锥里，就在那个角格里有且只有一个原像。这个角格的 orient 按第 1 节是"H 的段 × V 的段"，而按环的顺序取锥的两条边做叉积，得到的正是同一个符号，四个角格逐一验算：

  • (末, 末)：d₁ × e₁，就是 orient(末, 末)。
  • (首, 末)：e₁ × (−d₀) = −(e₁ × d₀) = d₀ × e₁ = orient(首, 末)。
  • (首, 首)：(−d₀) × (−e₀) = d₀ × e₀ = orient(首, 首)。
  • (末, 首)：(−e₀) × d₁ = −(e₀ × d₁) = d₁ × e₀ = orient(末, 首)。

往反方向外延时参数也朝负方向走，两个负号抵消，所以每个锥的 orient 正好等于环上对应那段弧的转向：逆时针 +1，顺时针 −1。于是

远处的 Σ orient = 环上盖住 û 的各段弧的转向之和 = 环从 û 这根射线上净穿过的次数 = w环每逆时针绕原点一整圈，就从任何一根射线上净穿过一次（来回穿过的一正一负抵消），所以"射线净穿过次数"就是总转角除以 360°。û 避开端向也保证了射线不经过环的顶点。

拖动远处的点 A（蓝点）：亮起的锥是 A 所在的角格外延，各带自己的 orient；细虚线是从 O 指向 A 的射线

同一时刻的环：A 的方向是一根射线，哪些弧盖住了它。四段弧错开半径画，是为了看清重叠

锥的顶点在面的四角，射线从 O 出发，两者在有限距离上有一点偏差，A 越远越一致；A 离面近时锥的计数失效（边格或面也有原像），但精确求交得到的 Σ orient 不变。本节还没讲正背面，颜色按第 5 节的约定预先涂好了。

第二步：从远处往里走，和不会变

让 A 从远处连续地移到任何位置。它的原像清单只在 A 穿过某个小格边的像时才会变，而相邻两格共用一条边，只有两种情况：

  • 两格旋向相同。两张平行四边形在公共边的像的两侧，A 穿过去时原像从一格搬进另一格。个数不变，符号不变。
  • 两格旋向相反（折缝）。两张平行四边形叠在公共边的像的同一侧，像一张纸折过来。A 从没被这两格盖住的一侧穿到被盖住的一侧，一下多出两个原像，一个 +1 一个 −1；反向穿过就一起消失。和不变。

"两侧"还是"同一侧"为什么由旋向决定：以竖的公共边为例，它的方向是 qj。右边小格 (i, j) 的点是从这条边再沿 +ri 走过去的，相对这条边落在 sign(ri × qj) = orient(i, j) 那一侧；左边小格 (i−1, j) 的点是沿 −ri−1 走过去的，落在 −orient(i−1, j) 那一侧。两格同号就分在两侧，异号就叠在同一侧。横的公共边同理。

略过的情形：小格顶点的像是孤立的点，退化小格的像是线段或射线，几条边的像也可能重合（穿过时各对相邻格的变化叠加，和仍不变），绕开它们走就行；这就是要求 A 是正则点的原因。于是 Σ orient 在整个平面上处处相同，等于远处算出的 w。

这条性质在数学里叫映射的拓扑度（Brouwer 度），"远处的圈数等于每一点的带符号覆盖次数"是它的基本定理。这里的映射逐格仿射（每个小格内部是一个线性变换加平移），所以两步都能手算。

画布平面：A 的路线（蓝虚线）穿过折缝（粗线）

参数平面：当前 A 的原像

下方曲线：灰线是原像总个数（含外延），每次跨过折缝的像跳 2；蓝线是 Σ orient，始终是一条平线。穿过面和外延的分界时原像只是从外延搬进面内，总数不变。

5 · 换成正面背面，就是 f − b = w·orient0

正面原像的 orient 都等于 orient0，背面的都等于 −orient0。把守恒式按正背拆开：

f·orient0 + b·(−orient0) = w　⟹　(f − b)·orient0 = w　⟹　f − b = w·orient0最后一步两边乘 orient0，因为 orient0² = 1，乘和除是一回事。

w·orient0 只能取三个值，每个值说一件事（f、b 都计入外延上的原像；软件允许图案沿外延自然延伸，所以正面原像落在外延上也算有）：

w·orient0 = +1：f = b + 1
任何正则点至少有一个正面原像。弯 30、弯 60、教学模型、两条直线都是。这种架上裁断不会发生，面上面外都不会。非正则点也不例外：正面小格（含外延）像的并集是有限个闭集的并，是闭集，又包含了稠密的正则点，所以就是整个平面。
w·orient0 = −1：b = f + 1
每个正则点至少有一个背面原像，而正面原像可以是 0 个。弯 100 px 的正弦架就是（w = −1，orient0 = +1）：面外两条端射线之间的"翼"里，点只有一个背面原像，会被裁掉。面上的点（至少有一个原像落在面内的点）实测都至少有一个正面原像，但其中一部分的正面原像在外延上；这是实测，不是守恒式保证的。
w·orient0 = 0：f = b
正面背面成对出现，可以都是 0，也就是一个原像都没有。发夹形和钩形是这种：钩形架在右侧折缝边界（画布 x = 160）之外一个原像都没有。

−1 和 0 的架上"一定有点被裁掉"也能从环上看出来。设 orient0 = +1，环上逆时针转的弧总共转了 P 度，顺时针的转了 N 度，那么 P − N = 360°·w，P + N < 720°。w = −1 时 P < 180°，w = 0 时 P < 360°：正面的锥盖不满所有方向，没盖到的方向上远处的点 f = 0。这只保证远处某个扇区里的点被裁掉，不是整个面外。

6 · 实测：每套装置随机 1500 个点

装置worient0w·orient0f − b 全部符合面上：有正面原像面上：面内就有正面原像面外：有正面原像一个原像都没有

点取在交点 O 周围 ±300 px 的方块里，O 按正式实现的规则取第 1 个交点（第 2 节）。"面上"指至少有一个原像落在画出的面内；"面外"指没有任何原像落在面内（原像全在外延上，或没有原像）。w·orient0 = +1 的架两列都是 100%；弯 100 px 的面外只有约三成有正面原像；0 的架有大片点没有任何原像。

7 · 这个符号的用处和边界

  • 画完就能判断。六个向量（四个端向、O 处两条切向）定出 w 和 orient0，不用解任何一点。+1 的架整条裁断计算可以跳过；−1 或 0 的架可以提前提醒"轴线两端折回，面外的图案会有一部分被裁掉"。
  • 裁断判据有了精确形式。现行实现用牛顿迭代逐点反解，靠"残差不超过阈值"判断该不该裁。+1 的架上牛顿解不出的点并不是没有正面原像，只是没收敛到；换成"存在正面原像"就不会误裁。−1 或 0 的架上，面外确实有一部分点没有正面原像，两种判据在那里都会裁。
  • 可以当求解器的检验。任何反解算法给出的原像清单，旋向之和必须等于 w；多找一个、漏掉一个都会破坏它。
  • 边界。只对正则点成立，折缝的像本身上原像会合并；只说"存在"，不说该取哪一个，取哪支由裁断规则定（面上优先、离初值最近）；w 没定义（相邻端向反向）时不适用；它讨论的是纹理板轴线的反解，主画板轴线的折叠另有判定。

参数平面上 ℓh、ℓv 都在画出的线的范围内的那个矩形，以及它在画布上的像。

走过线的末端沿末段直走、走过首端沿首段反向直走的部分；hv 靠它定义在整个参数平面上。参数平面在面之外分成四个角格和四条边格。

H 的第 i 段与 V 的第 j 段围成的参数矩形；像是一张平行四边形。
