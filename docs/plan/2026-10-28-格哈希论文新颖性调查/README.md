## 两份意见的异同

**一致的部分**（证据在 `sonnet_report.md` 1.2 节分层表、2.1～2.3 节、附录 A）：

- 方法的机制层每一环都有先例：反解写成折线求交是闵可夫斯基和的定义级事实（Lozano-Pérez 1980，构形空间）；hv = H + V − O 是平移曲面（Velichová 2009）；折线之和是段对平行四边形之并（Boost.Polygon 教程）；均匀格 + 候选 + 格内精确判定是 1984 年起的点定位常识（Edahiro–Kokubo–Asano 1984 桶法、Franklin 等 1989、Teschner 等 2003 空间哈希），现代有限元 / 可视化库（MFEM `BBoxTensorGridMap`、Mittal 等 2025、VTK-m、libigl）就是同一架构。
- 应用层（手绘导引线的二维动画图案映射里做反解、折叠处列全部原像）本次检索没见到先例；但应用文献（Heckbert 1994 起到 Igarashi / Fukusato 一系）没有人把反解当主题，Coons 型变形难反解、折叠使逆多值在 Wolberg–Boult 1989、Heckbert 1994 里是已知事实。
- 速度对照不构成新颖性：对手是自家纯 Python 牛顿，微秒级，没有 C++ / GPU 数据，没有强基线。
- 最合理的去处都是：**AnimeAn 主论文（`../../../paper/paper_src.md`）里半页一节 + 附录**，把式 (7) 的裁断判据从"残差 ≤ 0.4 px 且行列式同号"改写成组合判据"存在同旋向原像"，附录给算法与对照表。
- Lean：对本项目不值得。P1～P3（判定正确、格 = 矩阵、外延索引完备）在实数上平凡，Lean 覆盖不到浮点与去重；P5/P6 是度数论，Mathlib 里 Brouwer 度未确认存在。

**Argon 另指出、主 Agent 核过属实的两点**：

- 代码里叫"格哈希"，实际是**密集均匀格**（没有哈希函数）。论文或文档里用 uniform grid / bucket 更准确；本仓库文档沿用"格哈希"只是项目内叫法。

## Sonnet 的新发现（Argon 核过成立）

**符号原像数恒等于端射线环的缠绕数 w。** 把 hv 沿端段直线延拓到整个参数平面记为 F；四个端向（H 首末段方向 d₀、d₁，V 首末段方向 e₀、e₁）拼成端射线环 g(θ)，它绕原点的缠绕数 w ∈ {−1, 0, +1}。对每个正则点 A，所有原像的 orient 之和 = w（Brouwer 度；F 逆紧 ⇔ g 不过原点）。Sonnet 在 7 套装置 × 3000 点上全部验证成立，Argon 复核了推理、补了 w 的闭式与"只对正则值成立"（折痕顶点是非正则点，不算反例）。推论：

- w·orient0 = +1 的架上每个正则点（计入外延）必有同旋向原像；w·orient0 = −1 的架上面外几乎没有（本仓库文档里"远点只有 248/1803 有同旋向外延原像"正是这个：S 线与弯 100 px 的 w = −1）。
- `../2026-10-27-弦段求交矩阵算法.md`「须知」第一条"没有原像不会发生"**需要 w ≠ 0**；发夹形架（四个端向朝同一侧）w = 0，3000 个随机点里 1990 个没有任何原像。该句已在本次改为带条件（三级文档，Agent 可改）。
- Σ orient = w 可以当测试 oracle（不依赖矩阵路径）。尚未加进 `tests/t_chord_intersect.py`，列为后续。

这是整组里唯一有分量的命题，但它是经典定理在该映射上的具体化，撑不起独立论文；放进主论文附录合适。

## 最终判定

1. **以「利用格哈希算法解决二维映射」为题写独立论文：不做。** 两份意见对"机制层全是既有技术"没有分歧，分歧只在短文门槛；按更严的一方办。基线比较、复杂度分析在"主论文一节"的尺度上才值得做（K1 全矩阵、K2 牛顿、K4 每点对 H 建桶的简单强基线、C++ 计时），Lean 证明对本项目不值得。
2. **可交互 HTML：不按"介绍格哈希算法"做。** 两份意见都是"有条件值得"，条件是改定位：作为主论文的补充材料 / 项目技术文档，展示的是"弯曲导引线如何折叠 → 参数域矩形格映成画布上多层重叠的平行四边形 → 一个点有几个原像、正背面如何分 → 缠绕数 w 决定面外有没有解"，格查表只是其中一步。这是另一件事，由用户定。
3. **动画演示：同上。** 作为主论文伴随视频里 10～20 秒"折缝处原像从 1 变 3、裁断怎么发生"的片段，或由第 2 项录屏生成；不为"方格查表"单独做动画。
