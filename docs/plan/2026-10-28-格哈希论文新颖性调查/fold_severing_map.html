裁断在哪里发生：旋向守恒式怎么决定一个点有没有正面原像

裁断的判据是"这个点没有与交点同旋向的原像"。全部原像的旋向之和是一个常数 w，所以哪些点会被裁掉，在画导引线的那一刻就定了。下面用真算出来的地图说明。

先更正一句话。我之前说"正弦折叠架上 w·orient0 = +1，面上每个点都有同旋向原像，裁断从不发生"。核过数据后，前半句是错的：弯 100 px 的正弦架 w = −1、交点旋向 orient0 = +1，乘积是 −1。后半句只对面上的点成立，而且是实测结果，不是定理：面外的点在这套架上大多被裁掉。下面的地图里能直接看到。

1 · 守恒式：Σ 旋向 = w

把 X(s, t) = H(s) + V(t) − O 沿首末段直线延拓到整个参数平面。参数跑向无穷远时，X 跑向四个方向之一：H 末端方向 d₁、V 末端方向 e₁、H 起点方向的反向 −d₀、V 起点方向的反向 −e₀。把它们依次连成一个环，环绕原点的圈数就是缠绕数 w，只能是 −1、0 或 +1。

对每个正则点 A： Σ原像 orient = w, orient = sgn det[r_i, q_j]（原像所在小格两条边的叉积符号）

"正面"指 orient 等于交点处的旋向 orient0。记正面原像 f 个、背面 b 个，守恒式就是 (f − b)·orient0 = w，也就是

f − b = w · orient0
  • w·orient0 = +1：f = b + 1，任何正则点至少有一个正面原像。裁断在这种架上永远不发生，面上面外都不。弯 30、弯 60、论文的教学模型都是。
  • w·orient0 = −1：b = f + 1。允许 f = 0、b = 1，也就是只有一个背面原像的点，这样的点被裁掉。弯 100 px 的正弦架、手画的 S 线都是这种：面外的点多数只有一个背面的延伸原像。
  • w = 0：f = b。可以 f = b = 0，一个原像都没有。发夹形架和论文表 1 的钩形架是这种。

3 · 两张图的关系：远处定下总数，交点定下正负，中间的地图只能照办

右图画的是无穷远处：参数 (s, t) 朝某个方向走到无穷远，画布上的像 X(s, t) 就沿着四个端向之一跑出去。对所有方向跑一圈，得到环 g(θ)（紫线）；它绕原点几圈，就是 w。这一圈只取决于两条导引线的四个端向，与线中间怎么弯无关。

左图画的是每一点的结果。两者由同一个数连着：对画布上任何一个正则点，所有原像的旋向之和恒等于 w。原因是拓扑度——延拓后的 X 把整个参数平面映到整个画布平面，它在无穷远处绕原点的圈数（右图）等于它在任何一个点上的"带符号覆盖次数"（左图那一点的 f − b 乘以 orient0）。度是常数，所以左图上走到哪里 f − b 都不变：

  • 穿过一条折缝的像（面叠起来的边缘），原像成对出现或消失，一正一背，f 和 b 同加一或同减一，f − b 不变；
  • 穿过画出的面的轮廓（虚线），只是原像从"面上"换到"延伸部分"，颜色从深变浅，f − b 也不变。

交点 O 处的旋向 orient0 是把"旋向之和"翻译成"正面还是背面"的那把尺：正面就是与 O 处同号。于是 w 定了总数的正负，orient0 定了哪一侧算正面，两者相乘就是左图每一点的 f − b。右图里 w 的圈数方向与 O 处两条切向的叉积同号（右图中心的小角标），左图就处处至少一个正面原像；异号，左图就一定有只剩背面原像的区域——它们落在四条端射线之间的"翼"里，因为延伸部分在那里是翻过去的一面。

所以两张图不是并列的插图，而是同一个数的两种读法：右图一眼看出 w，左图看它落实到每个像素上。切换装置时先看右图的紫环绕不绕原点、绕哪个方向，再看左图有没有砖红色，就能验证这条关系。

4 · 正弦折叠架上，面上为什么没有裁断

弯 100 px 时 w·orient0 = −1，守恒式允许"一个背面原像、零个正面"的点存在，地图上也确实大片都是：它们在画出的面之外，是延伸部分翻过去的那一面。面上的点不同：面是一张连续的矩形贴片，折叠处它叠了三层（两层正面、一层背面），没折叠处一层正面；面上也有"只被背面小格盖住"的点，但它们的正面原像落在延伸部分，判据仍然满足。所以在这套架上沿着面画一笔，一路都保留，只有离开面才被裁掉。

这是对 2000 个随机点的实测（面上的点全部有正面原像），不是定理：守恒式本身不禁止面上出现 f = 0 的点，换一条导引线就可能出现。要让裁断真的切在面上、切在折叠轮廓上，用论文 3.10 节的钩形架：H 轴折回去，轮廓 x = 160 之外的点一个原像都没有（w = 0，f = b = 0），笔画在那里被裁断。

6 · 这条性质的现实意义

它把"这个点有没有正面原像"从一个要逐点求解才知道的事，变成画完导引线就知道的事。四个端向和交点处两条切向，六个向量，O(1) 的计算。

  • 画完就知道会不会裁断。w·orient0 = +1 的纹理板参考架，平面上每个正则点都有正面原像，纹理板一侧的裁断根本不会发生，整条裁断计算可以跳过。现行实现只有一个"两条轴线都是直线就跳过"的闸门，这条性质给出一个更宽的闸门，而且是精确的，不靠采样。
  • 可以提前提醒用户。w·orient0 = −1 或 w = 0 的架，画出的面之外一定有大片点没有正面原像：图案超出轴线范围按线性外推的部分会在那里被裁掉，发夹形的架连面上都可能有洞。系统现在已经会在两个参考架旋向相反时提示用户反向重画一条轴线；同一类提示可以加一条"轴线两端折回，面外的图案会被裁掉"，依据就是这个符号。
  • 裁断判据有了精确的形式。判据从"残差 ≤ 0.4 像素且行列式同号"（靠迭代收敛与否间接判断"原像存在"）改成"存在同旋向原像"后，牛顿没收敛的点不再被误裁：折叠架上牛顿没解到的 316 个点每一个都有正面原像，这条性质解释了为什么——那套架 f = b + 1 恒成立。
  • 给求解器一个不依赖参考实现的检验。任何一种反解（矩阵、方格、牛顿加枚举）算出的原像清单，旋向之和必须等于 w；少找一个原像和多找一个原像都会破坏它。本页和仓库的复算脚本都用它当测试预言，十套装置各 3000 个随机点无一例外。
  • 告诉你折叠处叠了几层。f − b 固定，所以原像个数只能按 w·orient0 + 2b 这样跳：+1 的架上是 1、3、5 层，−1 的架上面外 1 层背面、面上 2 或 3 层。层数直接对应输出里正面层与背面层的数目，是"折叠显式保留"这一设计的计数依据。

边界也要说清：它只对正则点成立，折缝的像本身是非正则点，那里的原像局部度为 0；它说的是"存在正面原像"，不说该取哪一个，分支的选择仍由裁断准则定（面上优先、离弦基初值最近）；它针对纹理板轴线的反解，主画板轴线的折叠是正向映射的事，另有一套判定。
