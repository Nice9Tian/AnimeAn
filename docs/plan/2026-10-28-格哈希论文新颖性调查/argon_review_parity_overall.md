#### 4. 第 5 节关于校验能力的评估

- **判定**：**基本成立（核心判断准确、无夸大，但有两处不周密和一处笔误）**
- **理由与依据**：
  1. **「能发现什么」与「折缝附近一正一背」的说法成立，无夸大**：
     - 单个原像在同旋向两相邻小格的公共边附近被两边各算一次（净多算 1 个）或漏算 1 个时，$f - b$ 偏离 $k$ 达 $\pm 1$，$N \bmod 2$ 也翻转，两种校验均能捕获（[`doc.md`] 第 60 行）。
     - 在折缝（相邻两格旋向相反，$\text{orient}$ 一正一负）附近，两格的像叠在公共边像的同一侧（[`page_sections_2_to_5.txt`] 第 42～43 行）。若探针落在零层一侧但距折缝小于容差 `EPS`，不做容差处理会同时点中这两格，恰好「多算一正一背」（$\Delta f = +1, \Delta b = +1$），使 $\Delta(f - b) = 0$、$\Delta N = +2$，因此 $f - b = k$ 和奇偶校验确实都对此失明（[`doc.md`] 第 61 行）。
  2. **三处需要补充或修正的细节**：
     - **面内与外延分界边附近的「归属错位」与页面代码的实际行为**：[`doc.md`] 第 60 行写「`一个原像落在面内小格与边格……的公共边附近，被两边都算一次`」。但在说明页的实际几何代码 [`page_geometry_lines_314_408.js`] 第 79～86 行中，边格/角格并不是独立于面内首末段小格的另一套 `F.cells` 元素，而是直接把首末段小格（`c.i === 0` 或 `lastI`、`c.j === 0` 或 `lastJ`）的参数范围放宽到 `±Infinity`，再用 `onSheet` 布尔值区分面内与外延。因此在页面代码里，面与外延的分界边上**不会发生「面内小格与边格各算一次」**，只会发生 `onSheet` 把面内判成外延（或反之）的**归属错位**；而对于「面内与外延之间的归属错位」（$f_{\text{in}} \pm 1, f_{\text{ext}} \mp 1$，总和 $f$ 不变），$f - b = k$、P1、P2、P3 全部失明。此外，对 $f - b = k$ 失明的错误除了「多算/少算一正一背」外，还有「同旋向的一重一漏」（一处多算一正、另一处漏算一正）。
     - **外延格之间本身也有公共边容差合并问题**：[`doc.md`] 第 62 行指出外延有 $4$ 个角格加 $2(n+m)$ 个边格，也要做浮点比较；其实还应指出：这 $2(n+m)+4$ 个外延格之间也有 $2(n+m)$ 条半无限公共边（射线），若原像落在外延格之间的公共边附近，检测外延本身同样面临重复计数/容差合并问题，并非「检测外延就不需要容差合并」。
     - **第 62 行末句笔误**：[`doc.md`] 第 62 行写「`P2 还说明：只要面内的像总数，外延只需要个数，不需要正反`」，其中「只要面内的像总数」漏了「**的奇偶**」三字（P2 只能给出 $N_{\text{in}} \bmod 2$，给不出 $N_{\text{in}}$）。
