# 附加线跨轴放行：被跨过的轴放开沿轴滑动（施工计划，2026-09-30）

状态：**已完成（2026-09-30，提交 e811348）。** 施工时有三处与草稿补丁不同，见文末回填「施工时的补充」，其中第 2 处待用户确认。分析记录（现象、原因、草稿副本上的实验数据）在 `2026-09-29-附加线跨轴凹槽.md`；本文是施工输入。

## 目标

- 附加线跨过 H/V 轴线时，跨越处的请求照常兑现。样本 `../../tests/fixtures/additional_line_axis_notch.anproj` 上：跨轴处凹槽 < 0.5 px，线各站残差均值 < 10 px（草稿实测 6.6），流场无折叠。
- 轴线的形状不变：两条轴的法向漂移 ≤ 1e-9 px；原点两个分量都不动。
- 没有线跨过的轴一切照旧：现有回归里所有"轴上探针总位移 < 0.01"的非跨轴案例继续为 0；六个附加线脚本除下文列出的两处断言外不改。
- 对称：H 族线跨 V 轴与 V 族线跨 H 轴行为一致。

## 已定决策（用户 2026-09-30）

1. 被附加线**真正跨过**（child 站位在该轴的正交坐标变号）的轴，在线所在的那半边放开**切向**分量：跨越点的地面按画的位置沿轴滑动。法向分量永远钉死（轴这条曲线不变形），原点永远钉死。
2. 没被跨过的轴维持两个分量都钉。全局放开切向已否决：不跨轴的线的影响带靠这条轴的切向钉扎定位置，草稿实验里全局放开让 `t_flowfield` 第 3 例、`t_additional` 第 2 / 8 例、`t_twofix` 第 5 例的地面漂 3–53 px。
3. 正交轴旁 4 格缓冲不动（0 格让 `t_flowfield` 第 12 例"诚实折叠"的夹具不再折叠，收益只有样本残差 6.6 → 3.5）。
4. 分族、关键帧插值、基础映射不动。
5. 一级文档措辞随之改，本决定即授权，范围限于下列句子：`../auto_mapping/flow_field_warp.md` §3「轴线神圣」、§2 正交轴边界层条、§6 第 4 条；`../auto_mapping/auto_mapping_2_spec.md` §11.5「轴线神圣与外轮廓」；`../tools_user_workflow/additional_line.md`「怎么用」第 2 步与「边界」第一条；`../user-workflow.md` 第 6 步；`../glossary.md` 附加线条目。二级：`../product_features.md` Additional Line 条目与待办行。2026-09-30 刚补进去的"跨过轴时不生效"措辞全部换成新语义。

## 施工顺序

### 1. 代码

`pyfile/auto_mapping.py`，`_FlowFieldWarp._build` 里

```python
pinned_x = axis_pinned.copy()
pinned_y = axis_pinned.copy()
```

两行换成下面的写法（草稿副本上验证过；`active` 是同函数里已有的非中性线列表，`ln["child"]` 是 Third 坐标站位；`gx` / `gy` 是网格节点坐标，`X[i, j]` 第 0 维对应 `gx`、第 1 维对应 `gy`，和现有钉扎代码的索引方式一致）：

```python
pinned_x = axis_pinned.copy()
pinned_y = axis_pinned.copy()
on_v = np.abs(gx) <= du * 0.999          # V 轴列（l_h = 0）
on_h = np.abs(gy) <= dv * 0.999          # H 轴行（l_v = 0）
rel_h = np.zeros(gx.shape[0], dtype=bool)   # H 轴上放开 l_h 的节点
rel_v = np.zeros(gy.shape[0], dtype=bool)   # V 轴上放开 l_v 的节点
for ln in active:
    pts = ln["child"]
    for a, b in zip(pts[:-1], pts[1:]):
        if a[1] * b[1] < 0.0:                 # 跨 H 轴
            xc = a[0] + (b[0] - a[0]) * (-a[1]) / (b[1] - a[1])
            if xc != 0.0:
                rel_h |= (np.sign(gx) == np.sign(xc))
        if a[0] * b[0] < 0.0:                 # 跨 V 轴
            yc = a[1] + (b[1] - a[1]) * (-a[0]) / (b[0] - a[0])
            if yc != 0.0:
                rel_v |= (np.sign(gy) == np.sign(yc))
pinned_x[np.ix_(rel_h, on_h)] = False     # 被跨过的 H 轴：这半边可沿轴滑
pinned_y[np.ix_(on_v, rel_v)] = False     # 被跨过的 V 轴：这半边可沿轴滑
pinned_x[on_v, :] = True                  # V 轴保形（l_h 钉死）
pinned_y[:, on_h] = True                  # H 轴保形（l_v 钉死）
```

后面外轮廓的 `pinned_x |= edge_v` / `pinned_y |= edge_h` 不动。注释同步到新语义：`AXIS_GUARD` 说明块（"the axes must not drift, ever"）、族模型注释里 "a V-like line crossing the H axis keeps its voice beside H naturally"、钉扎块注释 "BOTH grid columns/rows straddling each axis line hold D = 0"。`_ADDITIONAL` 无新选项，mapper 指纹不变（线的几何已在指纹里）。

## 风险与边界

- **浮动**：与跨轴线同一半边、伙伴两端不重合的不跨轴线（例如绕一端旋转 25° 的直线，`t_flowfield` 第 2 例那种），原先靠这条轴的切向钉扎定住积分常数，放开后可能整体沿轴漂移。草稿六个脚本里没有这种组合出现在被放行的半边。`t_axis_crossing.py` 可加一例量它的漂移并钉上限，不作为阻塞；写进 §6 已知取舍。
- 跨越点恰在原点（xc == 0）不放行；一条线跨两条轴、或来回跨同一条轴，按各自变号分别放行；原点始终钉死。
- 网格数组轴向别对调：V 轴列用 `[on_v, :]`，H 轴行用 `[:, on_h]`。
- 帐篷（`_tent_cross`）死区依赖"钉扎带内 U_base 恒等"，法向仍钉，不受影响；草稿里帐篷相关的第 6、10、11 例全过。
- 外轮廓分量式钉扎与轴钉扎用 `|=` 叠加，顺序不变。

## 回填（2026-09-30 施工）

- 实现方法：`_FlowFieldWarp._build` 的钉扎块。`on_v` / `on_h` 选出跨骑两轴的网格列 / 行，`axis_pinned` 由它们组成；新增内部函数 `crossed_halves(k, t_neg, t_pos)`，沿每条非中性线的 child 站位找该轴正交坐标变号处（恰落在轴上的站位跳过；跨越点取轴上的站位，没有就取相邻两站的线性插值），返回被跨过的半轴符号；`rel_h` / `rel_v` 用 `np.isin(np.sign(gx 或 gy), 符号)` 选出。钉扎：`pinned_x` / `pinned_y` 从 `axis_pinned` 复制，`pinned_x[np.ix_(rel_h, on_h)] = False`、`pinned_y[np.ix_(on_v, rel_v)] = False`，再 `pinned_x[on_v, :] = True`、`pinned_y[:, on_h] = True` 保住两条轴的法向和原点；外轮廓的 `|=` 在后，顺序不变。注释同步：`AXIS_GUARD` 说明块、族模型注释、正交轴 relief 注释、钉扎块。`_ADDITIONAL` 无新选项，mapper 指纹不变。
- 施工时的补充（与草稿补丁不同的三处）：
  1. **恰落在轴上的站位照样算跨过。** 草稿的 `a[1] * b[1] < 0` 在重采样站位恰为 0.0 时漏判（对称的合成夹具常见，手画的线几乎碰不到）。草稿里 `t_flowfield` 第 6、16、20 例因此都被当成不跨轴，"六个脚本只有两处断言读到滑动"的结论有一部分来自这个漏判。现在先跳过轴上的站位再判变号：过零的线算跨过，碰到轴又折回的不算，跨越点恰在原点仍不放行。
  2. **被画出去的那一侧不放行（待用户确认）。** `t_flowfield` 第 6 例的线在版心外（y = 250）跨过 V 轴的延长线。把它挪开 0.5 px（手画的线都属于这种情况），草稿补丁就会放开 V 轴上半：帐篷在轴上阻尼为零，放开的轴去填帐篷的阻尼凹陷，V 轴在 y = 150 处滑 42 px、版心顶边处滑 84 px、跨越点滑 105 px（画的请求 +42）。在版心内跨轴、同时画出同一侧版心边的线也一样：合成夹具上沿轴滑 92 px 对 36 px 的请求、线残差 30 → 61 px，另一例反向滑。现在被跨过的半条轴通向的那一侧有帐篷越界（T > 0）时，这半条轴仍两个分量都钉，与改前一致；版心外跨延长线的情形随之不放行。另一半照常判。代价：这类线的跨越处仍是改前的凹槽。另试过"只在版心范围内放行"：残差 26–29 px，但其中一例出现折叠，未采用。
  3. **`t_flowfield` 第 20 例的断言也改了。** 两条线都在版心内跨过 V 轴（中点站位恰为 0，草稿漏判），按拍板的语义属跨轴案例。每条线绕自己的跨越点旋转，被放开的 V 轴上半没什么可滑，实测 0.03 px（这个夹具在改前的场里离轴处就有同量级的数值不对称）。断言改为形状 < 0.01、V 轴切向 < 0.1；没被跨过的 H 轴仍查总位移 < 0.01。
