# 附加线跨越正交轴处的凹槽（2026-09-29）

状态：**已定位，未修。** 修法要动一级算法（`../auto_mapping/flow_field_warp.md` 第 3 节「轴线神圣」的钉扎方式），等用户拍板后再开工。承诺侧记在 `../product_features.md`「Auto Mapping」的待办里。

## 现象

用户 2026-09-29 测试后提交的样本：`../../tests/fixtures/additional_line_axis_notch.anproj`。纹理板上一条近水平的附加线，在 Third 空间里沿 ℓ_v 方向延伸（属 V 族），跨过 H 轴（ℓ_v = 0）。跨轴处，附加线本应带来的位移被压成零，图案和参考网格在那里出现一道凹槽。用户怀疑 V 轴也一样：按机制看是对称的，H 族线跨 V 轴会得到同样的凹槽（未另做样本）。

## 复现

```powershell
py tests\diag_additional_axis_notch.py
```

离线加载样本的单元资产，建两个映射器（带 / 不带附加线），量「带附加线 − 不带附加线」的位移。跨轴的图案笔画（样本里的 stroke 1）在跨轴处的位移，主画板像素：

| 位置（Third ℓ_v） | 位移 |
|---|---|
| 轴一侧 ≈ +39 | 8.6 |
| ≈ +16 | 4.9 |
| ≈ +10 | 1.6 |
| 钉扎带内（ℓ_v 在 ±6 以内） | 0.00 |
| ≈ −11 | 2.1 |
| ≈ −19 | 3.8 |
| 另一侧 ≈ −36 | 4.8 |

过跨轴点的网格等参线（ℓ_h = 165.3）上同样：两肩 4.4–4.7 与 7.0–8.3，轴带 |ℓ_v| ≤ 5 精确为 0，**凹槽深约 6 px**（两肩均值 6.2），到 |ℓ_v| ≈ 25 才基本恢复。流场本身在 Third 空间的位移是 6.0 / 0 / 10.6 px（两肩 / 轴上）。网格格宽 10.9 Third px（窗 96 格）。

排除项：

- 去掉附加线后同一条笔画没有凹槽，基础映射（只有 H/V 轴）无关。
- 保存的输出里主画板 (241, 282) 处有一个 171° 的折返，与凹槽无关：对应的纹理笔画自己在 y ≈ 316.5 处折返了一次（x 434 → 425 → 434），映射在那里是忠实的（雅可比行列式为正）。那是画的时候手回了一下，不是缺陷。

## 原因

`pyfile/auto_mapping.py` 的 `_FlowFieldWarp._build`：

1. **轴带全分量硬钉。** `axis_pinned` 选出离 ℓ_v = 0 与 ℓ_h = 0 一格以内的网格行 / 列，然后 `pinned_x = pinned_y = axis_pinned`：两条轴上 U 的两个分量都被钉成恒等（Dirichlet）。
2. **正交轴旁的 4 格缓冲。** `o_t = clip(|o_pt| / (4·o_cell))` 的 smoothstep 乘进每条线的权重，V 族线在 H 轴两侧各约 4 格（≈ 44 Third px）内声音渐弱到零。
3. **这条线偏偏要把位移带过轴。** 配对在跨轴处的请求几乎全是沿 ℓ_h 方向的（≈ −47，切于 H 轴），法向只有 ≈ +6；解出来的位移两侧各 5–11 px。钉扎带把它压成 0，于是位移在轴两侧各有一个肩、中间一个谷。

设计文档的说法是"V 族线跨 H 轴时声音不被 H 静音（正交族互不干扰）"，但钉扎是全分量的、缓冲又是按格数的，实际把线在轴带内静音了。`../auto_mapping/flow_field_warp.md` 第 6 节第 4 条已把"正交轴旁 4 格是钉扎与谐波回弹的地盘（约 1 px）"列为已知取舍；本样本里这个取舍的代价是 5–9 px，肉眼可见。`tests/t_flowfield.py` 里检查的是正交轴旁的倾斜是否保留，没有断言位移跨轴连续，所以没有测试拦住它。

## 候选修法（都动一级，需拍板）

1. **轴钉扎改成分量式**，和第 4 节外轮廓同一逻辑：H 轴行只钉 ℓ_v 分量（轴作为曲线不动），放开沿轴滑动的 ℓ_h；V 轴列只钉 ℓ_h。跨轴的 V 族线就能把它的 ℓ_h 位移带过轴，本例的凹槽主体消失（请求几乎全在 ℓ_h）。配套要看：`_tent_cross` 的死区是否仍需全分量、`o_t` 缓冲能否收窄到钉扎带本身、轴漂移不变量改为"法向漂移 ≤ 1e-9"。
2. **只缓冲法向分量**：`o_t` 只乘到写入正交轴法向的那一列，切向请求不打折。作用比 1 小，实现更局部。
3. **维持现状，写成已知限制**：附加线不要跨轴，跨轴处分两段画。

建议 1：最贴近"轴线神圣"的本意——轴的形状不变，地面可以沿轴滑动，外轮廓已经这么做了。

验证要求：`tests/t_flowfield.py` 加一例"V 族线跨 H 轴"，断言跨轴处位移连续（凹槽深 < 0.5 px）、轴的法向漂移仍在机器精度；全量 `py -m unittest discover -s tests` 通过；用本样本目测参考网格（17 分度）。

## 不做

- 不改基础映射（H/V 轴的 Coons 复合），它与此无关。
- 不改附加线的族判定和关键帧插值。
