# Mapping 工具（Free Out Line、Choice Line、Deform）

2026-11-01 至 11-02。状态：已完成，PR #51。Refs #9、#12，这两个 issue 没有因此完成。

## 目标

把代理图形和地线的求解器接成能在 Tauri 版里试手感的真实工具。

## 用户的决定

- Tools ▸ Mapping 加 Free Out Line、Choice Line、Deform，轮廓显示成彩色，同色即同一点。
- Free Out Line 的轮廓自动是地线，不用勾选。
- 代理图形不支持流向引导。
- Coons 是保留项，除非遇到限制，一直走 warp。
- 拖动时松手再重算。
- Refer Rect 的选项放到 Tool Options，能向外延展。
- 折叠处显示气泡，只显示在折叠发生的板上，位置要准。
- 一级、二级文档和 `FOLD_NOTE_*` 常量由 Agent 写入并确认；`CORNER_WINDOW` 在 issue #52 另行确认。

## 文件

- 工具：`pyfile/line_tools.py`、`pyfile/proxy_shape.py`、`pyfile/auto_mapping.py`、`pyfile/toolcontrol.py`、`pyfile/extra_tools.py`。
- 按钮和图标：`webui/design/`。
- 气泡：覆盖层新增 `label` 字段（`pythonbind/`、`openglwidget.*`、`mainwindow.cpp`、`backend/session/`）；`backend/main.cpp` 给 offscreen 平台指字体目录。

## 过程里修掉的问题

| 现象 | 原因 |
|---|---|
| H、V 轴线跑到一起 | 每次改轮廓都重新配对，选中了相差九十度的候选 |
| 撤销后轮廓消失 | `_sanitize_assets` 不认识新字段 |
| 拖动卡 | 每个鼠标事件都重建映射和网格 |
| ✕ 点不中 | 线穿过自己的 ✕，外圈被判成抓线 |
| 删轴线后网格和气泡消失 | 自动重建轴线时没有清缓存 |
| 气泡不显示 | 曲线轴的弧长表和展平点数不等；圆滑回弯、短钩子漏检 |
| 红点不在角上 | 红点是四等分点；圆角漏检（issue #52） |
