Tools 面板：分组方案

去掉 Painting / Mapping 两个分页，两组工具同时放在 Tools 面板里，每组可以单独折叠。审核稿，还没有合进软件。

试一试

点分组标题折叠，点工具选中，拖面板右边缘改宽度（吸附到整列）。折叠一个有选中工具的分组，标题右边会留一个蓝点。

各种状态

和现在的区别

现在两个分页，同一时间只能看到一组，用 Mapping 工具要先切页。
分组后两组同时可见，不用切页；用不到的一组收起来，下面的内容自动上移。
层级toolsDock 下直接是 paintingHeader、paintingBody、mappingHeader、mappingBody，比现在少两层（toolsTabs、toolsPages 和两个页都没有了）。
步进Painting 组继续按整列排；Mapping 组的文字按钮占满一行，不分列。

需要你决定

  1. Mapping 组现在用文字按钮。图形画好后，要不要换成和 Painting 一样的图标格子？换了之后两组都能按列步进，代价是看不到文字。
  2. 折叠状态要不要下次启动时还记得？这份稿子里每次启动都是两组全开。
  3. 选中的工具落在折叠的组里时，要不要自动展开？现在有一条规则是“Auto-Mapping 单元里的层切到 Mapping 页”，分页没了以后它可以变成自动展开 Mapping 组。这份稿子里不展开，只在标题上亮蓝点。
