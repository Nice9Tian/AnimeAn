# 地线（Ground Line）：钉住花纹的线（计划草稿，2026-09-30）

状态：**草稿，待用户拍板。** 用户 2026-09-30 提出并定了六条方向，2026-10-01 第 10 条定稿（正交轴让路、平行轴不动、影响沿线延长），第 11 条外轮廓待确认；本文把它们落成可施工的计划，附草稿副本上的可行性实验。承诺侧的草稿在 `../product_features.md`「Auto Mapping」（规划），用法草稿在 `../tools_user_workflow/groundline.md`。未动仓库代码。

## 来由

附加线跨轴放行（`2026-09-30-附加线跨轴放行施工计划.md`）之后暴露出一件事：附加线只给求解器"纹理往哪流"，不给"花纹停在哪"。一条线跨轴放开了半条轴，同一半边上别的线贴着画的那段花纹就会整体挪开（实测 9–31 px）。用户的判断：附加线的目的本来就只是引导流场，不保证花纹位置；要保证位置，得有另一种线。

## 用户已定的决策（2026-09-30）

1. **引入地线（groundline）。** 地线是锚定在具体花纹上的线；附加线可以转换为地线；地线两端画图钉，让人看出它钉住了花纹。
2. **钉整条线**，不是只钉两个端点。
3. **硬钉。** （我建议过强权重软钉以避免折叠；用户选硬钉。后果见「风险」第 1 条。）
4. **移动地线的交互**：先画一条地线 → 用某种交互选中它（例如点一下，出现发光描边）→ 这时再画一条线，才表示"移动"这条地线。
5. **移动代表用户的意图，可以把 H/V 轴线带弯。** 优先级：地线 > H/V 轴线 > 附加线。
6. **所有附加线在地线附近都服从地线。**
7. **Mapping 页增加 Ground Line 按钮。**
8. **H/V 轴线的地位。** 在用户的交互里 H/V 轴线不是必须的；在模型的计算里它是基础，是为了方便计算的中介物。地线才是模型里最底层的东西，H/V 轴线只是图案中心的两条地线。将来用户可以不显式画轴线，而是像三维动画里的代理模型那样，画一个被空间透视扭曲的矩形，由它解析出 H/V 轴线。
9. **附加线的浮动与"滑动对不上支点"不再修。** 附加线只引导流场；位置交给地线。（这条是我对用户原话"它只是在引导整个流场"的理解，已同步记到跨轴放行计划的待用户项下。）
10. **正交轴让路，平行轴不动（2026-10-01，用户三次修正后的定稿）。** 地线归属一个轴向（按走向分族，同附加线）。它沿自己的方向**延长**出去的影响、以及它身后被带动的地面，穿过**正交**轴时不能被截断：正交轴在地线所在的那半边放开（两个分量），跟着地面走。**平行**轴照旧钉死：它本身就是一条中心地线，不能被别的地线推走。影响是沿线延长，不是围着线画一圈的晕圈（晕圈会横着铺到另一条轴上）；也不"推着前方的地面走"（前推把平行轴顶走了，用户否决）。只有别的地线的硬带和平行轴能挡住地线的影响。
11. **地线操作时外轮廓应当会变（2026-10-01，语义待确认）。** 实验一直勾着"约束外轮廓"，外框始终是矩形；用户指出移动地线时外轮廓应该跟着变。待定：有被移动的地线时外轮廓整体不钉（A），还是只在地线影响范围内让路（B，现状）。见待用户回答第 7 条。

## 模型

现有管线：Child →（子系轴线反解）→ Third →（流场 U，Third → Third）→（主系轴线重建）→ Main。U 由 `_FlowFieldWarp` 在 Third 网格上解一张加权泊松方程得到：附加线给梯度目标，轴线和外轮廓给 Dirichlet 钉扎。

- **地线是位置约束。** 一对地线（纹理板上的 G_c、主画板上的 G_m）按弧长比例逐点对应。换到 Third 空间：`U(third_child(p)) = third_main(q(p))`，对线上每一点成立。它不写梯度目标，也不分族、不参与关键帧插值。
- **硬钉的做法。** 沿用轴线的"跨骑两行 / 两列都钉"：离地线一格以内的网格节点，两个分量都钉成"最近的线上点所要求的位移"（非零 Dirichlet，求解器已支持 `solve(rhs, pin_val, mask)`）。带内是一条随线走的刚性窄带，线本身精确落位。
- **延长到边缘。** 线在两端沿自己的切向一直延长到求解域边缘，末端的位移沿延长段按 smoothstep 渐弱、到边缘归零；延长段是软约束（求解器加对角项 κ(x)·(U − 目标)，κ 随之渐弱；SPD 不变，CG 照用）。只延长半个线长不行：延长段末梢把位移压回零，而周围被带动的地面不是零，末梢处出弯折（见「风险」第 1 条）。两端不动的线没有延长。
- **正交轴让路，平行轴不动。** 正交轴在地线所在的半边（按站位均值判定）两个分量都放开，随地面走，延长段穿过它、线身后的地面越过它都不被截断；平行轴两个分量都钉死；外轮廓按决策 11。伙伴恒等（位移不到半格）的地线没有延长，也不放开任何轴。
- **外轮廓（待确认）。** 移动地线时外轮廓跟着变：A. 有被移动的地线时整块版心不受"约束外轮廓"钉扎；或 B. 只在地线影响范围内让路。
- **附加线服从地线。** 地线的节点是 Dirichlet，附加线的梯度目标在那里不起作用；交点和近旁由钉扎说了算。
- **现阶段仍需要 H/V 轴线。** 地线活在流场这一步，Child→Third→Main 的扫掠骨架不变。第 8 条是方向，不是这一期的内容。

## 可行性实验（2026-09-30，草稿副本，仓库未动）

复制 `pyfile/auto_mapping.py`（含已合并的跨轴放行），按上面的做法打补丁（补丁要点见文末附录），用环境变量把某一对线当作地线。网格 96 格，合成夹具里一格约 9–10 px。

**用户样本**（`../../tests/fixtures/additional_line_axis_notch.anproj`，把那条附加线当地线）：

| | 附加线（现行） | 地线，轴不让 | 地线，被碰到的半条轴放开 |
|---|---|---|---|
| 纹理线的落点离画的线，均值 / 最大（主画板 px） | 4.22 / 9.88 | 0.07 / 1.42 | **0.07 / 1.42** |
| 线各站残差，均值 / 最大（Third px） | 6.58 / 15.06 | 0.10 / 2.56 | 0.10 / 2.57 |
| 折叠 | 无 | 43 个探针格，min det −3.47 | **无**，min det 0.506 |
| H 轴 | 沿轴滑 47，法向 0 | 只有跨越点被拽走，两侧撕裂 | 沿轴滑 47、法向抬 6.2，从原点平滑起坡 |
| V 轴 | 不动 | 不动 | 不动 |

**合成夹具**（直轴线，H 长 600、V 长 400）：

| 情形 | 结果 |
|---|---|
| 地线跨 H 轴，整条平移 (−30, +25) | 线残差 0.00；H 轴在跨越处抬 24.3、滑 29.2，平滑；V 轴不动；线端 1 个探针格 det −0.027 |
| 浮动：附加线 A 跨 +H；另有一段花纹 G 在同一半边上方 | G 不是地线时，G 处花纹被带走 32.3 px；G 设为地线后 **0.00 px**，无折叠 |
| 同上，G 与 A 的线相交 | A 让位：跨越点滑动 42.4 → 16.4，A 残差 4.5 → 21.9 |
| 同上，G 在 A 旁边、不相交 | A 滑动 30.5，A 残差 8.1 |
| 地线（钉在原处）与一条旋转 25° 的附加线相交 | 地线上位移 1e-13；无折叠（min det 0.317）；附加线两侧流向 22.5° / 21.1°（请求 25） |
| 同上，附加线在地线旁加 4 格缓冲 | 附加线被过度压制（两侧位移 25.9 / 21.9 → 0.8 / 12.8），不采用 |
| 不跨轴的地线在开阔处整体挪 25 px | 无折叠（min det 0.432） |
| 同上，挪 50 px / 80 px | 线两端 4 格（−0.136）/ 50 格（−0.818）折叠 |
| 离 H 轴 40 px 的地线朝轴挪 25 px（不碰轴） | 线两端 6 格（−0.052） |
| 同一条线挪过轴 60 px：轴不让 / 轴让 | 289 格（−1.525）/ 4 格（−0.235），轴被推下 24–47 px |

结论：

1. **硬钉整条线可行。** 样本上花纹线落到画的线上，均值 0.07 px。
2. **轴线必须让，而且让得动。** 不让就在轴上撕裂；放开被碰到的半条轴后平滑弯过去，另一条轴不受影响。
3. **"碰到"要把主画板侧也算进去。** 只看纹理侧站位会漏掉"线整体被挪过轴"的情形。
4. **地线消掉了浮动。** 被地线钉住的花纹分毫不动；和它冲突的附加线让位。
5. **附加线在地线旁不需要额外缓冲。**
6. **硬钉的代价在线的两端，已由"延长到边缘"解决。** 延长到求解域边缘、正交轴在线这一半放开、平行轴不动之后，全部夹具无折叠；只有线穿过自己的平行轴必然折。见「风险」第 1 条的表。

实验没覆盖的：帐篷越界（线画出版心）、约束外轮廓关闭、逆映射表与折叠裁断管线的配合、多条地线互相矛盾、交互与存档。

## 交互（草稿，细节见 `../tools_user_workflow/groundline.md`）

- **画**：Ground Line 工具在纹理板上沿花纹画一条线；主画板上出现它**当前映射到的位置**，两端带图钉。画下不改变结果，只是把这段花纹钉在现在的位置。在主画板上画则反过来，纹理板上出现它的原像。（"画下即钉在当前位置"是我对第 4 条三步流程的理解，待确认。）
- **选中**：点一下地线，发光描边。点空白处或按 Esc 取消。
- **移动**：选中之后画一条线，这条地线在该板上的形状换成新画的。在主画板上重画 = 花纹挪到新位置；在纹理板上重画 = 换一段花纹来钉。没有选中时画线 = 新建。
- **转换**：附加线 → 地线，保留两块板上的几何，语义从"引导流向"换成"钉住位置"。
- **删除**：任一侧的 ×，一对一起删。
- **显示**：线色与附加线区分；两端图钉；选中发光。

## 风险

1. **两端折叠（2026-10-01 定稿：延长到边缘 + 正交轴放开 + 平行轴不动，全部夹具无折叠，只剩穿过平行轴一种）。** 一条刚性硬带被整体推着走，两端旁边、前进方向一侧的自由地面要在一两格内从"跟着走"过渡到"不动"，挪得远了就折（不平滑时本夹具 50 px 起）。草稿副本上试过的平滑（折叠数为 5 px 探针格数）：
   - **只沿线延长**（末端位移沿切向延长段渐弱）：折叠在线两端**前方**（它移向的那一侧）的地面上，不在线端之外，延长本身挡不住。
   - **围着线画一圈的软晕圈**：开阔处有效，但把影响横着铺到了另一条轴上，用户否决。
   - **推着前方的地面走**：全部夹具无折叠，但把平行轴顶走了，用户否决。
   - **延长只到半个线长**：延长段的末梢把位移压回零，而它周围被带动的地面并不是零，末梢处出一个弯折（用户在图上指出的"奇怪的弯折"；线所在行的最大弯折 6.1 px，位置正在延长段末梢），挪 80 px 时两端仍折 44 格。
   - **定稿：延长到求解域边缘、正交轴在线这一半放开、平行轴不动、外轮廓自由**：弯折消失（线所在行最大弯折 0.2 px），线身后的地面越过正交轴不再有转角（正交轴左 / 上 / 右 −63.0 / −63.5 / −64.0），正交轴形状不变，原点不动，平行轴一格不动；全部夹具无折叠，只剩"线穿过自己的平行轴"一种。

   | 情形 | 不平滑、轴全钉 | 定稿（延长到边缘、正交轴放开、平行轴不动） |
   |---|---|---|
   | 开阔处挪 25 / 50 / 80 / +40 px | 0 / 4 / 50 / 0 格 | **0 / 0 / 0 / 0 格**（min det 0.70 / 0.39 / 0.03 / 0.67） |
   | 离 H 轴 40 px 的线朝轴挪 25 px | 6 格 | **0 格**（min det 0.10） |
   | 同一条线挪过自己的平行轴 60 px | 4 格（轴让时） | 587 格：平行轴不让，线穿不过去 |
   | 跨 H 轴的线整体平移 (−30, +25) | 1 格 | **0 格**，H 在跨越处抬 24 |
   | 跨两条轴的斜线平移 (+20, −20) | 0 格 | 21 格：它也穿过自己的平行轴 |
   | 用户样本 | 0 格 | **0 格**，min det 0.37 |
   | 被挪的地线旁有跨轴附加线 | 0 格 | **0 格** |

   延长到边缘意味着一条被移动的地线影响整行：它像一条横贯纹理的测地线，线身后整条带子跟着走，离线越远越弱，到求解域边缘归零（挪 80 px 时，线外 280 px 处仍有约 20 px）。残留的折叠只有"线穿过自己的平行轴"，两条地线互相矛盾，按折叠管线处理并在 Python Debug 提示。延长段的渐弱形状留到第三期按真实画法调。
2. **多条地线互相矛盾**（交点处要求不同、或挤得太近）必然折叠。需要规则：后移动的优先，或直接提示。
3. **轴线被带弯后的显示。** 主画板上画的轴线引导线还在原处，而花纹的中心线已经不在那里了。
4. **放开的半条轴失去锚点。** 这半边上没被地线钉住的附加线会像现在一样浮动；地线本身不受影响。

## 附录：草稿补丁要点

`_FlowFieldWarp._build` 里，在外轮廓钉扎之后、`weighted_div_lap` 之前。`grounds` 是地线对（`child` / `main` 为 Third 站位），`X` / `Y` 是节点坐标，`ub_x` / `ub_y` 是帐篷基场。

```python
# 每条地线：每个节点到线的最近点、该点要求的位移
c = np.array(ln["child"]); m = np.array(ln["main"]); d = m - c
ax, ay = c[:-1, 0], c[:-1, 1]
ex, ey = c[1:, 0] - ax, c[1:, 1] - ay
ee = np.maximum(ex * ex + ey * ey, 1e-12)
PX, PY = X.ravel(), Y.ravel()
t = np.clip(((PX[:, None] - ax) * ex + (PY[:, None] - ay) * ey) / ee, 0.0, 1.0)
qx = PX[:, None] - (ax + t * ex); qy = PY[:, None] - (ay + t * ey)
d2 = qx * qx + qy * qy
seg = np.argmin(d2, axis=1); rows = np.arange(PX.shape[0]); tt = t[rows, seg]
dist = np.sqrt(d2[rows, seg])
dx = d[seg, 0] * (1 - tt) + d[seg + 1, 0] * tt
dy = d[seg, 1] * (1 - tt) + d[seg + 1, 1] * tt

# 轴线让位：纹理侧或主画板侧站位跨过该轴，或某个站位被带过该轴
def touch(ln, k):                      # k = 1: H 轴；k = 0: V 轴
    o = 1 - k
    spots = cross_spots(ln["child"], k) + cross_spots(ln["main"], k)   # 跳过恰在轴上的站位
    for cc, mm in zip(ln["child"], ln["main"]):
        if cc[k] * mm[k] < 0.0:
            spots += [cc[o], mm[o]]
    return spots
for xc in touch(ln, 1):
    if xc != 0.0:
        half = (np.sign(gx) == np.sign(xc)) & ~on_v
        pinned_x[np.ix_(half, on_h)] = False
        pinned_y[np.ix_(half, on_h)] = False
for yc in touch(ln, 0):
    if yc != 0.0:
        half = (np.sign(gy) == np.sign(yc)) & ~on_h
        pinned_x[np.ix_(on_v, half)] = False
        pinned_y[np.ix_(on_v, half)] = False

# 硬钉：离线一格以内的节点两个分量都钉成最近点要求的位移
near = (dist <= 1.0 * max(du, dv)).reshape(X.shape)
pin_x = np.where(near, X + dx.reshape(X.shape) - ub_x, pin_x)
pin_y = np.where(near, Y + dy.reshape(X.shape) - ub_y, pin_y)
pinned_x |= near
pinned_y |= near
```
