# 线条与圆角工具

2026-11-02 起。状态：浏览器 demo 阶段，没有接进软件。issue #100。

## 目标

两个画线工具：曲线工具点锚点画平滑曲线，圆角工具把尖角变平滑。先在浏览器 demo 里试手感，用户定下行为后再起草二级承诺和一级工具页，然后接进软件。

## 用户的决定

- 曲线工具：左键点击放锚点，工具把锚点之间平滑；右键中断在最后一个锚点；能从中断的线末端吸附续画。
- 平滑用 Catmull-Rom。Hobby 样条留作归档：`../../../old_history/hobby_spline.js`。
- 圆角工具：光标自动吸附在尖角上，点击后拖动鼠标调节平滑程度和方向。
- 现在只做浏览器 demo，不接进软件。

## 曲线工具 demo

`curve_tool_demo.html`，单个页面，直接用浏览器打开。

**算法**：向心 Catmull-Rom（α = 0.5），每段转成三次 Bezier，和软件的笔画模型一致。开放端没有自己的切向，端段取进入 `m[1]` 的抛物线。曲线穿过每个锚点，锚点处切向连续；向心参数化在段内不会出尖点或自交。放新锚点只改原来的最后一段，前面的不动。平滑度滑条把控制点往折线的三等分点收，0 就是折线。

**Agent 定的，待用户试过后确认**：

| 行为 | 现在的做法 |
|---|---|
| 哪些线端能吸 | 中断的线两端都能吸，从线头续画时整条线反向，形状不变 |
| 画线途中吸到别的线端 | 两条线合成一条，画完停在中断状态 |
| 画线途中吸到自己的起点 | 闭合成环，至少 3 个锚点 |
| 想贴着线端开新线 | 按住 Alt 点击，不吸附 |
| 只放一个锚点就中断 | 保留这个点，之后能吸上去续画 |
| 续画时原来的最后一段 | 末端切向要对齐新段，所以会微调，和连续放点时一样 |
| 双击 | 离上一个锚点 3 屏幕像素以内的点击不放点 |
| 吸附半径 | 屏幕像素，默认 16，离开时放宽到 1.35 倍防止在边上闪 |

预览就是提交结果：蓝色的预览段和点击后的形状由同一份锚点算出。

**实测（2026-11-02）**：页面里跑随机锚点（2 × 2 × 200 组，开放和闭合）核对曲线过锚点、锚点处 G1；共线锚点出直线；反向后曲线不变；加一个锚点只改最后一段。真实鼠标走通续画、从线头续画、接线、闭合、Alt 不吸附、双击不重复放点、撤销，控制台无报错。

## 圆角工具 demo

`corner_round_demo.html`，打开就有四条示例线：折线（直腿）、三角形（闭合，接缝也是角）、叶子（两段弧，弯腿）、钩子（弧接直线）。另有一个折线工具，用来画新的尖角试。

**模型**：笔画保留画出的 Bezier 段，每个倒了圆角的接点记两段长度 `L1`、`L2` 和用户抓的是控制线哪一端：圆角从进入段倒数 `L1`（弧长）处开始，到离开段 `L2` 处结束，用 de Casteljau 切片，不重拟合。中间补一段三次 Bezier，两端分别和两条腿相切，手柄长度是 κ 乘对应的切掉长度（「圆角形状」滑条，默认 0.55，接近圆弧）。原线不改，圆角可以反复调。

**拖动的映射：控制线（用户 2026-11-02 定）**：想象角上有一条线，用户通过调这条线来控制圆角。从角上往外拉出这条线：拉得越远（线越长），圆角越宽越平滑；上下移动鼠标转动线的角度，这是圆角顶点处的切线方向，切线一歪，两边切掉的长度就跟着变。抓着的一端要跟手，端点就在鼠标下（用户反馈）。

实现：线就是两个切点之间的弦（方向和半长），钉在原来的角尖上，两端是 `角尖 ± 弦/2`；直腿上它和圆角顶点的切线平行。用户抓着的一端始终就是鼠标的位置，按 `L2·u2 − L1·u1 = 2·(端点 − 角尖)` 解出两边长度，u1、u2 是两条腿在角上的方向；弯腿用 Levenberg-Marquardt 在真实的弦上求解，拖动时从上一刻的结果接着解。线没有方向，两端都能抓；倒过圆角的角平时显示一条灰色控制线，光标靠近哪一端就吸到哪一端。线转过了两条腿允许的范围时，圆角全部偏到更近的那条腿上。

为什么钉在角尖而不是圆角顶点（2026-11-02 试过）：顶点会随圆角变大往里沉。线跟着顶点走时，要让抓着的一端留在鼠标下，水平拉也会得到很偏的圆角，稍往上拉就把一条腿整条切光；端点不留在鼠标下又不跟手。钉在角尖后两者都解决：水平拉就是对称圆角，端点始终在鼠标下。代价是线浮在圆角顶点上方，离开的距离是顶点沉下去的深度。

前两版：圆角中点跟着鼠标往角里拖（提交 a899c74），用户改成控制线；控制线画在顶点上、从角尖量鼠标（提交 068abdf），用户反馈不跟手。

**Agent 定的，待用户试过后确认**：

| 行为 | 现在的做法 |
|---|---|
| 什么算尖角 | 两段在接点的切向差超过 15° |
| 吸附 | 光标靠近尖角（琥珀菱形）或控制线的端点时吸过去，屏幕像素，默认 16 |
| 按下后不动 | 移动不到 2 屏幕像素就松开，什么都不改，不进撤销 |
| 抓已有的圆角 | 抓控制线的任一端，按下时不跳 |
| 拉回角尖 | 用户 2026-11-02 定：抓着的一端拉回角尖附近（吸附半径内）会吸住，线长为 0，恢复尖角 |
| 拉回起点 | 用户 2026-11-02 定：拉回这次按下的位置附近会吸住，圆角精确回到按下前的样子，松手不留撤销步 |
| 起点就在吸附范围里 | 按下时就在角尖或起点的吸附范围里，要先离开一次才会吸，小幅微调不被吸住 |
| Shift | 两边等长 |
| 取消 | 拖动中右键或 Esc，恢复按下前的样子 |
| 线转得太歪 | 超过两条腿允许的切线范围时，圆角全偏到更近的腿上，另一边为 0 |
| 腿不够长 | 每边最多切到这一段的另一端；那一端已有圆角时让给它，两个圆角之间留 0.5 像素 |
| 一条腿跨几段 | 现在只在相邻的一段里切 |

**观察**：线的半长是圆角宽度的一半，两条腿越斜，切掉的弧长比线长得越多；锐角（叶尖）比钝角灵敏。

**实测（2026-11-02，钉在角尖的控制线）**：四条示例线的每个角、两侧各 4 种长度 × 5 种角度，用页面里的指针事件逐步拖动：360 次拖动全部够得到，抓着的端点离鼠标最远 0.03 像素；350 次再抓起来挪动，端点离鼠标最远 0.002 像素；直角对称的尖上水平拉得到两边相等；每次移动求解 0.11 毫秒。所有角都倒圆角后接缝全部 G1、无缝隙（上一版核对，圆角几何没变）。真实鼠标拉线后，端点和鼠标只差按下时离角尖的那点偏移。

**实测（2026-11-02，吸附角尖和起点）**：新角拉出去再拉回角尖，吸住后圆角消失，松手撤销栈不变；新角只拉 9 像素（没离开角尖范围）留下小圆角；再抓挪 5 像素照常微调；再抓拉远再拉回起点，圆角和按下前逐位相同，撤销栈不变；再抓拉到角尖，尖角恢复，多一步撤销，撤销后圆角回来。
