# 线条与圆角工具

2026-11-02 起。状态：浏览器 demo 阶段，没有接进软件。issue #100。

## 目标

两个画线工具：曲线工具点锚点画平滑曲线，圆角工具把尖角变平滑。先在浏览器 demo 里试手感，用户定下行为后再起草二级承诺和一级工具页，然后接进软件。

## 用户的决定

- 曲线工具：左键点击放锚点，工具把锚点之间平滑；右键中断在最后一个锚点；能从中断的线末端吸附续画。
- 平滑用 Catmull-Rom。Hobby 样条留作归档：`../../../old_history/hobby_spline.js`。
- 圆角工具：光标自动吸附在尖角上，点击后拖动鼠标调节平滑程度和方向。
- 现在只做浏览器 demo，不接进软件。

## 曲线工具 demo

`curve_tool_demo.html`，单个页面，直接用浏览器打开。

**算法**：向心 Catmull-Rom（α = 0.5），每段转成三次 Bezier，和软件的笔画模型一致。开放端没有自己的切向，端段取进入 `m[1]` 的抛物线。曲线穿过每个锚点，锚点处切向连续；向心参数化在段内不会出尖点或自交。放新锚点只改原来的最后一段，前面的不动。平滑度滑条把控制点往折线的三等分点收，0 就是折线。

**Agent 定的，待用户试过后确认**：

| 行为 | 现在的做法 |
|---|---|
| 哪些线端能吸 | 中断的线两端都能吸，从线头续画时整条线反向，形状不变 |
| 画线途中吸到别的线端 | 两条线合成一条，画完停在中断状态 |
| 画线途中吸到自己的起点 | 闭合成环，至少 3 个锚点 |
| 想贴着线端开新线 | 按住 Alt 点击，不吸附 |
| 只放一个锚点就中断 | 保留这个点，之后能吸上去续画 |
| 续画时原来的最后一段 | 末端切向要对齐新段，所以会微调，和连续放点时一样 |
| 双击 | 离上一个锚点 3 屏幕像素以内的点击不放点 |
| 吸附半径 | 屏幕像素，默认 16，离开时放宽到 1.35 倍防止在边上闪 |

预览就是提交结果：蓝色的预览段和点击后的形状由同一份锚点算出。

**实测（2026-11-02）**：页面里跑随机锚点（2 × 2 × 200 组，开放和闭合）核对曲线过锚点、锚点处 G1；共线锚点出直线；反向后曲线不变；加一个锚点只改最后一段。真实鼠标走通续画、从线头续画、接线、闭合、Alt 不吸附、双击不重复放点、撤销，控制台无报错。
