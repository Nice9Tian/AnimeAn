## Do not wait forever

Never leave a build command running without a timeout.

Before a real build, run a dry-run:

```powershell
& 'C:\Qt\Tools\Ninja\ninja.exe' -C 'build\Desktop_Qt_6_9_1_MinGW_64_bit-Debug' -n -d explain
```

If the dry-run says:

```text
ninja: no work to do.
```

the build is already complete. Do not run another build just to wait for output.

For an actual build, prefer Ninja directly and use a short timeout in Codex:

```powershell
& 'C:\Qt\Tools\Ninja\ninja.exe' -C 'build\Desktop_Qt_6_9_1_MinGW_64_bit-Debug' -v
```

If the command does not finish within about 15 seconds in Codex, stop and diagnose. Do not keep waiting.

## Known Codex shell issue

In the Codex Windows shell, the environment may contain both `PATH` and `Path`.
This can make PowerShell environment enumeration and `Start-Process` fail with a duplicate-key error, and it may interfere with process monitoring.

When a build appears stuck in Codex, check whether Ninja has actually started child tools.

```powershell
Get-Process | Where-Object { $_.ProcessName -in @('ninja','cmake','g++','gcc','moc','uic','cmd') } | Select-Object Id,ProcessName,CPU,StartTime | Format-Table -AutoSize
```

If only `cmd.exe` or `ninja.exe` is present and there is no `g++`, `moc`, `uic`, or `cmake_autogen` activity, treat it as an execution-environment hang rather than an application-code hang.

## Check whether work completed

Use `.ninja_log` to see whether the build is making progress:

```powershell
Get-Content -Path build\Desktop_Qt_6_9_1_MinGW_64_bit-Debug\.ninja_log -Tail 20
```

If `.ninja_log` records recent object builds or `AnimeAn.exe`, the build completed or progressed.

The following output is a successful result:

```text
ninja: no work to do.
```

It means there is nothing left to rebuild.

## Terminal syntax

This project runs on Windows. Be careful to distinguish PowerShell, cmd.exe, and Git Bash syntax.

PowerShell direct Ninja command:

```powershell
& 'C:\Qt\Tools\Ninja\ninja.exe' -C 'build\Desktop_Qt_6_9_1_MinGW_64_bit-Debug' -v
```

cmd.exe direct Ninja command:

```cmd
"C:\Qt\Tools\Ninja\ninja.exe" -C "build\Desktop_Qt_6_9_1_MinGW_64_bit-Debug" -v
```

Do not paste prompt characters into commands. Do not include leading `$` or `PS C:\...>`.

## Agent workflow

1. Inspect changes with `git status --short`.
2. Use `rg` for source search.
3. Run Ninja dry-run before an actual build.
4. Run actual Ninja only with a short timeout.
5. If it hangs, inspect child processes and `.ninja_log`.
6. If the issue is only Codex process management, report that clearly instead of continuing to wait.
